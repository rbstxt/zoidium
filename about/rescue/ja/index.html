保存できないプロジェクトを救出する

保存、復元ポイントの作成、復元ポイントのダウンロードが失敗する、または押しても反応しないときの手順です。

編集中のタブは更新したり閉じたりしないでください。保存していないプロジェクトは、そのタブの中にしかありません。そのタブで別のプロジェクトを開かず、救出が終わるまで再生と編集を止めてください。

1. 救出用ブックマークレットを登録する

下のボタンをブラウザーのブックマークバーへドラッグしてください。バーが見えない場合は Ctrl+Shift+B（Mac では Cmd+Shift+B）で表示できます。ボタンを右クリックしてリンクをブックマークしても構いません。

2. 編集中のタブで実行する

  • 保存できなくなった編集タブに切り替えて、Zoidium Rescue ブックマークをクリックします。
  • 画面右上にオレンジ色のパネルが表示され、各手順の進み具合が表示されます。
  • 完了すると、救出した .pz ファイルが自動でダウンロードされます。作成したファイルはパネルからも保存できます。パネルの Save ボタンは保存先を選ぶ方式なので、ダウンロードが動かないときでも使えます。
  • パネルには復元ポイントの一覧もあります。通常の「ダウンロード」ボタンが効かない復元ポイントも、ここから取り出せます。

3. 救出したファイルを確認する

救出したファイルを新しい Zoidium タブで開き、映像・画像・フォント・音声を確認してください。救出したファイルが正しく開け、通常どおり保存できるまで、元のタブは開いたままにしてください。画像や動画が見つからないと表示された場合は、Media > Missing assets > Locate で元のファイルを指定してください。

ブックマークレットが使えない場合

ブラウザーによってはこの大きさのブックマークを保存できません。また、デスクトップ版にはブックマークがありません。その場合は、同じスクリプトを開発者ツールの Console から実行します。

  • 上の Console 用にスクリプトをコピー を押します。
  • 編集中のタブで Console を開きます。Chrome と Edge は F12 または Ctrl+Shift+J（Mac では Cmd+Option+J）、Firefox は Ctrl+Shift+K です。デスクトップ版は View > Toggle Developer Tools を選びます。
  • スクリプトを貼り付けて Enter を押します。Chrome が貼り付けについて警告した場合は、allow pasting と入力して Enter を押してから、もう一度貼り付けてください。

エディターのエラー表示からこのページを開いた場合は、上に このページを開いた編集タブで実行する ボタンが表示されます。ブックマークなしで救出を始められます。

それでも解決しない場合は Discord でバグを報告してください

救出に失敗した場合や、救出したファイルが開けない場合は、Zoidium の Discord サーバーで報告してください。次の情報を添えてください。

  • パネルの Copy report for the bug report ボタンでコピーしたレポート
  • Settings > Debug information > Download debug log で保存したデバッグログ（デスクトップ版は Debug > Download debug log）
  • 保存できなくなったときに行っていた操作

レポートとデバッグログにはプロジェクトの内容は含まれません。.pz ファイルは、共有しても問題ない場合だけ送ってください。

救出ツールが行うこと

救出ツールは編集中のタブの中だけで動きます。プロジェクトをコピーし、添付ファイルとまとめて .pz ファイルにし、読み直せることを確認します。開いているプロジェクトの変更、復元ポイントの書き込み、ネットワークへの送信は行いません。プロジェクトの一部が壊れている場合は、壊れたオブジェクトだけを除き、パネルに一覧表示します。安全な修復を加えたコピーを最初に提示し、修復していないコピーも並べて残します。
