Rescue a project that won't save

For when Save, restore points, or restore-point downloads fail or do nothing.

Do not reload or close the editor tab. Your unsaved project only exists in that tab. Don't open another project there, and stop playback and editing while the rescue runs.

1. Add the rescue bookmarklet

Drag this button to your browser's bookmarks bar. If the bar is hidden, press Ctrl+Shift+B (Cmd+Shift+B on a Mac) to show it. You can also right-click the button and bookmark the link.

Zoidium Rescue

Loading the rescue tool...

2. Run it in the editor tab

  • Switch to the editor tab that cannot save, then click the Zoidium Rescue bookmark.
  • A rescue panel appears in the top-right corner and shows each step as it runs.
  • When it finishes, the rescued .pz file downloads automatically. The panel also offers every file it made. Its Save buttons let you choose where to save, which works even when downloads do not.
  • The panel also lists your restore points. You can download any of them from there, even if the normal Download button fails.

3. Check the rescued file

Open the rescued file in a new Zoidium tab and check the video, images, fonts, and audio. Keep the original tab open until the rescued file opens correctly and you have saved it normally. If an image or video shows as missing, use Media > Missing assets > Locate to point to the original file.

If the bookmarklet does not work

Some browsers can't store a bookmark this large, and the desktop app has no bookmarks. In those cases, run the same script from the developer Console:

  • Click Copy the script for the Console above.
  • In the editor tab, open the Console. In Chrome or Edge, press F12 or Ctrl+Shift+J (Cmd+Option+J on a Mac). In Firefox, press Ctrl+Shift+K. In the desktop app, choose View > Toggle Developer Tools.
  • Paste the script and press Enter. If Chrome warns about pasting, type allow pasting, press Enter, and then paste again.

If you opened this page from an error message in the editor, the Run in the editor tab that opened this page button appears above and starts the rescue without a bookmark.

Still not working? Report the bug on Discord

If the rescue fails or the rescued file does not open, report it on the Zoidium Discord server. Please include:

  • the report from the panel's Copy report for the bug report button,
  • the debug log from Settings > Debug information > Download debug log (in the desktop app, Debug > Download debug log),
  • what you were doing when saving stopped working.

The report and the debug log do not contain your project content. Share a .pz file only if you are comfortable doing so.

What the rescue tool does

It runs entirely inside the editor tab. It copies the project, packages it with its attached files as .pz files, and checks that each file can be read back. It never changes the open project, never writes restore points, and sends nothing over the network. If part of the project is damaged, it leaves out only the broken object and lists it in the panel. A copy with safe repairs is offered first, and an untouched copy is kept beside it.
