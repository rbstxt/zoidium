参考用の要約（これはプライバシーポリシー本文ではありません）

Zoidium はアカウント不要・無料・広告なしで、広告目的のトラッカーは使用しません。プロジェクトや編集データを Zoidium のサーバーへ送信・保管する仕組みはありません。公開 Web 版では、配信元の Cloudflare による通常の通信処理に加え、Cloudflare Web Analytics（ブラウザのネットワークタブでは Cloudflare Insights と表示されることがあります）が、サイトの利用状況・表示性能を集計するために動作します。Electron 版はローカルで動作します。

このプライバシーポリシー（以下「本ポリシー」）は、1zworks（以下「運営者」）が提供する Zoidium（以下「Zoidium」）における情報の取扱いを説明するものです。

1. Panzoidの公式Privacyについて

Panzoid のサービス、Web サイト、アカウント、または Panzoid が管理する機能を利用する場合は、Zoidium とは別に Panzoidの公式Privacy を確認してください。Panzoid の情報の取扱いは、本ポリシーの対象ではありません。Terms については Panzoidの公式Terms を確認してください。

2. Zoidium が意図的に収集しない情報

Zoidium は、次の情報を収集するアカウント機能や送信機能を提供していません。

  • アカウント情報、ログイン情報、氏名、住所、電話番号
  • 編集しているプロジェクト、映像、画像、音声、素材、書き出しファイルの内容
  • 広告用の識別子、行動プロファイル、広告目的のトラッキング情報

Zoidium は広告を表示せず、利用者の作品を運営者へアップロードすることもありません。利用者が別のサービスへ自分でアップロード・共有した場合、そのサービスのポリシーが適用されます。

3. 利用者の端末に保存される情報

ブラウザ版では、設定、プラグインの有効・無効状態、作業中の復旧用データなどが、ブラウザの localStorage などのローカルな保存領域に保存されることがあります。プロジェクトファイルは利用者が選択した場所に保存・読み込みされます。これらは運営者のサーバーに送信されるものではなく、利用者がブラウザの設定やファイル操作で管理します。

ブラウザや OS が行う保存、キャッシュ、権限管理については、それぞれの提供者の仕様が適用されます。Electron 版では、アプリと内蔵サーバーが利用者の端末上で動作します。

CM3を起動するため、Web版とElectron開発版は、キャッシュがない場合または更新を指定した場合に、設定されたCM3ソースページと同一オリジンのランタイムリソースをGit管理外の`.zoidium-resources/`キャッシュへ取得します。`npm run build:web`と`npm run dist`も、このキャッシュを再利用または作成してビルドします。このブートストラップではIPアドレスやユーザーエージェントなど通常の通信メタデータがソース提供元に届く場合がありますが、プロジェクト内容や編集データは送信しません。ローカルサーバー終了後もキャッシュは端末に残り、削除されるのは使い捨てのビルド用ツリーだけです。静的デプロイ物にはそのデプロイに必要な生成ファイルが含まれます。

4. Web 版での Cloudflare の利用

zoidium.1zworks.com の公開 Web 版では、Web 配信およびセキュリティのため Cloudflare が利用されます。また、サイトの表示性能と利用状況を把握するため、Cloudflare Web Analytics（Cloudflare Insights）が有効になっています。これは広告や個人の行動追跡のためではなく、ページの読み込み状況などを集計するためのものです。Zoidium は、この分析機能へプロジェクト内容やアカウント情報を渡しません。

Cloudflare が処理する情報や保存期間は、Cloudflare のサービス設定およびポリシーに従います。詳しくは Cloudflare Web Analytics の説明 と Cloudflare Privacy Policy を確認してください。

なお、Web サイトへ接続すると、HTTP 通信の配信・障害対応・不正アクセス対策に必要な範囲で、IP アドレス、ブラウザ情報、参照元、アクセス日時、要求された URL などの技術情報が、配信基盤またはホスティング事業者のログとして扱われることがあります。これは Zoidium が作品内容を収集することを意味しません。

5. お問い合わせ

メールでお問い合わせいただいた場合、返信に必要なメールアドレスと、メール本文に含まれる情報を受け取ります。これらはお問い合わせへの対応、確認、記録のために必要な期間だけ取り扱い、広告目的で利用しません。

情報の取扱いについての質問、確認、削除依頼などは、hello@1zworks.com まで連絡してください。Zoidium が保有する利用者情報が存在しない場合、その旨を回答します。

6. 外部リンク

本ページにはPanzoid や Cloudflare など第三者のページへのリンクがあります。リンク先での情報の取扱いは、各サービス提供者のポリシーに従います。リンクを開くことで、Zoidium からそのサービスへ移動します。

7. 本ポリシーの変更

運営者は、サービスの変更や法令への対応に応じて本ポリシーを更新することがあります。変更後の内容は、このページに掲載した時点から適用されます。重要な変更がある場合は、可能な範囲で分かりやすく表示します。
