謝辞

最終更新日: 2026年8月31日

Zoidiumは、Clipmaker Gen3（CM3）の機能を拡張するオープンソースツール集です。本ページでは、拡張レイヤーが利用する主な第三者の作品とライブラリを記載します。それぞれの作品に適用される原著作者のライセンスと通知が優先します。

CM3のソースページとランタイムのリソースグラフは、このリポジトリに保存していません。セットアップ、Web版・デスクトップ版の開発サーバー、ビルド処理だけが、必要な場合に設定されたソースグラフをGit管理外の`.zoidium-resources/`キャッシュへ取得します。生成されたデプロイ物やインストーラーには、そのビルドに必要なファイルが含まれる場合がありますが、ソースチェックアウトには含まれません。

原作ソフトウェアとクリエイティブ作品

  • Panzoid — Panzoid Clipmaker 3（Clipmaker Gen3）を作成しました。Zoidiumの拡張ツールが動作するCM3ランタイムです。PanzoidはZoidiumと提携・承認関係にありません。
  • AlipFX — Afterzoid Shader Packを作成しました。Zoidiumには、この配布物で使用しているソースパックから生成したAfterzoid Shader Pack 4プラグインが含まれており、AlipFXの作品として表示しています。

オープンソースソフトウェア

  • Source Code Pro — CM3のエディターとZoidiumの拡張レイヤーが使う等幅UIフォントです。未改変のRegular WOFF2をSIL Open Font License 1.1の下でfonts/にローカル同梱しています。全文は同梱ライセンス本文を確認してください。Panzoidから取得するものではなく、フォントCDNも使用しません。
  • Three.js r91 — CM3ランタイムが使用するWebGLレンダラーです。MIT License。ステージ化の際に設定されたCM3ソースグラフから取得されます。
  • FFmpeg — CM3がメディアのエンコード・デコードに使用するランタイムです。FFmpegの大部分はGNU LGPL version 2.1以降で許諾され、一部のコンポーネントにはMIT、X11、BSD系ライセンスが適用されます。詳しくはFFmpegの法的情報を確認してください。
  • libarchive tar — .pzプロジェクトファイルに使用しているアーカイブワーカーです。BSD 2-Clause License。
  • Electron 28.3.3 — デスクトップアプリのランタイムです。MIT License。
  • electron-builder 24.13.3 — アプリケーションのパッケージングに使用するツールです。MIT License。
  • compression 1.8.1 — 内蔵サーバーで使用するHTTP圧縮ミドルウェアです。MIT License。
  • serve 14.2.6 とserve-handler 6.1.7 — 開発時およびデスクトップアプリでのローカルHTTP配信に使用しています。MIT License。

ランタイムアセット

CM3ランタイムのフォント、テクスチャ、シェーダー、アイコン、ワーカー、ダウンロードページのファイルはリポジトリに含めず、必要な場合は設定されたCM3ステージ化処理で取得します。これらには、それぞれの権利者の利用条件と通知が適用されます。Source Code Proは上記の別ライセンスによるローカル同梱フォントで、拡張レイヤーはこのフォントを使い、フォントCDNへはリクエストしません。

本ページは主な謝辞の一覧であり、第三者作品のライセンス本文に代わるものではありません。直接使用しているJavaScriptパッケージのバージョンはpackage-lock.jsonに記録しています。間接依存パッケージには追加の通知が含まれる場合があります。
