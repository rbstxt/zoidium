Acknowledgements

Last updated: August 31, 2026

Zoidium is an open-source collection of tools for extending Clipmaker Gen3 (CM3). This page records the principal third-party works and libraries used by the extension layer. The original licenses and notices for each work remain controlling.

The CM3 source page and its runtime resource graph are not stored in this repository. The setup command, web and desktop development servers, and build jobs fetch the configured source graph into the Git-ignored .zoidium-resources/ cache when needed. A generated deployment or installer may contain the files needed by that particular build; the source checkout does not.

Original software and creative work

  • Panzoid — created Panzoid Clipmaker 3 (Clipmaker Gen3), the CM3 runtime around which Zoidium's extension tools are organized. Panzoid is not affiliated with or endorsing Zoidium.
  • AlipFX — created the Afterzoid Shader Pack. Zoidium includes the Afterzoid Shader Pack 4 plugin, generated from the source pack used for this distribution and credited to AlipFX.

Open-source software

  • Source Code Pro — the monospaced UI font used by CM3's editor and Zoidium's extension layer. The unmodified Regular WOFF2 is bundled locally under fonts/ under the SIL Open Font License 1.1; see the bundled license notice. It is not fetched from Panzoid, and no font CDN is used.
  • Three.js r91 — the WebGL renderer used by the CM3 runtime. MIT License. It is obtained as part of the configured CM3 source graph during staging.
  • FFmpeg — the media encoding and decoding runtime used by CM3. Most of FFmpeg is covered by the GNU LGPL version 2.1 or later; some components use MIT, X11, or BSD-style licenses. See the FFmpeg legal information.
  • libarchive tar — the archive worker used for .pz project files. BSD 2-Clause License.
  • Electron 28.3.3 — the desktop application runtime. MIT License.
  • electron-builder 24.13.3 — the application packaging tool. MIT License.
  • compression 1.8.1 — HTTP compression middleware used by the embedded server. MIT License.
  • serve 14.2.6 and serve-handler 6.1.7 — local HTTP serving for development and the desktop application. MIT License.

Runtime assets

CM3 runtime fonts, textures, shaders, icons, workers, and download-page files are not included in the repository; when needed, they are obtained through the configured CM3 staging process and remain subject to their respective rights-holder terms and notices. Source Code Pro is the separately licensed local font described above; the extension layer uses that bundled family and does not request a font CDN.

This is a principal acknowledgements list, not a replacement for the license text of any third-party work. Direct JavaScript package versions are recorded in package-lock.json; transitive dependencies may carry additional notices.
