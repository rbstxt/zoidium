Move a Zoidium editor window to another monitor without closing its current edit.

## Move a window out

1. Open the editor window, such as **Graph editor**, **Shader**, **Expression**, or **Trapcode Designer**.
2. In the title bar, click **Pop out**.
3. If the browser blocks the popup, allow popups for this site. Click **Pop out** again.
4. Drag the browser window to the monitor you want.

## Return a window

1. In the popup's title bar, click **Return to editor**.
2. To return through the operating system, close the browser window instead.

The floating window returns to its previous position and size. The next pop-out reuses the popup's last position and size when the browser permits it.

## Close an editor

1. To close the editor itself, click **Close** inside its title bar.
2. To close every popup, close the main Zoidium page.

Removing the edited effect or replacing its project also closes the associated editor. Unsaved text stays in the live editor when you move it between windows. To apply shader or expression text to the project, click **Apply**.
