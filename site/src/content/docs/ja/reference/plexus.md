Plexus は、デザイナーとプロパティパネルにネイティブのプロパティを持つスイートのオブジェクトです。表はスキーマの初期値を示します。プリセットとピッカーの項目が初期値を上書きする場合があります。


## Object

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Enabled** | 選択肢 | **off**, **on** | **on** | このブロックを有効にします。 |


## Geometry

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Geometry type** | 選択肢 | **layers**, **paths**, **obj**, **primitives**, **instances**, **slicer** | **instances** | 点群のソースです。 |
| **Primitive** | 選択肢 | **box**, **sphere**, **cylinder**, **plane**, **ring** | **box** | 生成する基本形状の点の形状です。 |
| **Count** | 数値 | 0 ～ 60000 | `200` | 生成を要求する点の数です。 |
| **Size** | 3D ベクトル | ≥ 0 | `[500, 500, 500]` | 生成する点群の寸法です。 |
| **Position** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | シーンの単位で指定する位置です。 |
| **Path turns** | 数値 | 0 ～ 10 | `3` | 手続き型のパスのソースの周回数です。 |
| **Layer** | アセット | image/* | なし | 点に使う画像です。 |
| **OBJ file** | アセット | .obj | なし | 読み込んだ点の形状です。 |
| **Random seed** | 数値 | 明示的な範囲指定なし | `0` | 再現可能な乱数のシードです。 |


## Effector

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Effector type** | 選択肢 | **noise**, **spherical field**, **container**, **transform**, **color map**, **shade**, **sound** | **noise** | ソースの点に適用する処理です。 |
| **Amount** | 数値 | 明示的な範囲指定なし | `100` | エフェクター全体の適用量です。 |
| **Noise amount** | 数値 | 明示的な範囲指定なし | `40` | ノイズの変位の振幅です。 |
| **Noise scale** | 数値 | ≥ 0.0001 | `1` | ノイズの空間のスケールです。 |
| **Strength[%]** | 数値 | 明示的な範囲指定なし | `50` | 球状のフィールドの強さです。割合で指定します。 |
| **Radius** | 数値 | ≥ 0 | `300` | 球状のフィールドの半径です。 |
| **Position** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | シーンの単位で指定する位置です。 |
| **Container size** | 3D ベクトル | ≥ 0 | `[500, 500, 500]` | 点のコンテナーの寸法です。 |
| **Transform scale** | 数値 | 明示的な範囲指定なし | `100` | 点群の拡大率です。割合で指定します。 |
| **Transform rotation** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 点群の回転です。度単位です。 |
| **Color map by** | 選択肢 | **index**, **height**, **distance** | **index** | Color と Color 2 の合成に使う座標です。 |
| **Color** | RGB カラー | 0 ～ 1 | `[1, 1, 1]` | 基準の RGB カラーです。 |
| **Color 2** | RGB カラー | 0 ～ 1 | `[0, 0.3, 1]` | 点の2番目の色です。 |
| **Audio layer** | アセット | audio/*,video/* | なし | オフラインの音声解析に使う音声または動画のアセットです。 |
| **Audio offset (seconds)** | 数値 | ≥ 0 | `0` | リアクターの音声の区間の遅延です。秒単位です。 |
| **Audio trim in (seconds)** | 数値 | ≥ 0 | `0` | 最初のメディアの時刻です。秒単位です。 |
| **Audio trim out (seconds)** | 数値 | ≥ 0 | `0` | 最後のメディアの時刻です。秒単位です。0 は利用可能な末尾を使います。 |
| **Sound strength** | 数値 | ≥ 0 | `100` | 音声のエフェクターの強さです。 |


## Renderer

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Renderer type** | 選択肢 | **points**, **lines**, **facets**, **triangulation**, **beams** | **lines** | 点、線、面、三角形分割、またはビームの描画です。 |
| **Point size** | 数値 | 0 ～ 10 | `4` | 点の大きさです。 |
| **Line type** | 選択肢 | **distance**, **adjacency**, **shape** | **distance** | 距離、隣接、または形状による接続です。 |
| **Max distance** | 数値 | ≥ 0 | `200` | 接続する点の間の距離の上限です。 |
| **Max connections** | 数値 | 0 ～ 10 | `5` | 各点で使う接続数の上限です。 |
| **Opacity** | 数値 | 0 ～ 100 | `80` | パーティクルの不透明度です。割合で指定します。 |
| **Ambient** | 数値 | 0 ～ 100 | `25` | 環境の陰影の寄与量です。割合で指定します。 |
| **Diffuse** | 数値 | 0 ～ 100 | `75` | 拡散反射の陰影の寄与量です。割合で指定します。 |
| **Specular** | 数値 | 0 ～ 100 | `0` | 鏡面反射の照明の寄与量です。 |
| **Color** | RGB カラー | 0 ～ 1 | `[1, 1, 1]` | 基準の RGB カラーです。 |


## 評価と制限

線は最大 12,000 点を接続に使います。面と三角形分割は最大 4,000 点と 20,000 三角形を使います。形状の入力は 16 MiB を超えるテキストまたは 500,000 頂点を超えるデータを拒否します。

Audio layer がない場合、Sound Effector は時刻に基づく再現可能な波を使います。アセットがある場合は、デコードした音声とオフセットおよびトリムの区間を使います。
