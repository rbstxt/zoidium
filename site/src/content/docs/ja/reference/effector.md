Effector は Scene+ プラグインのエディター上の名前です。オブジェクトは、その階層内の子に作用します。最上位に並ぶ兄弟は、この階層の外にあります。

## オブジェクトの種類

| ピッカー名 | 用途 |
| --- | --- |
| **Repeater** | 固定の変換間隔で元のオブジェクトを複製します。 |
| **Linear Repeater** | 始点と終点の変換の間に複製を配置します。 |
| **Random Repeater** | 範囲内でシードによるランダム変換を使って複製します。 |
| **Echo Repeater** | 明示的にサンプリングした前のフレームで複製を評価します。 |
| **Twist** | ローカル軸の周囲で子孫のメッシュをねじります。 |
| **Warp** | エフェクターの座標系で子孫のメッシュを曲げます。 |
| **Voronoi Fracture** | 子孫のメッシュを、シードによるボロノイ破片に分割します。 |
| **Plain** | 接続された部分や文字に、フィールドで重み付けした変換を適用します。 |
| **Delay** | 前の時刻のサンプルを使って、上流の動きをフィルター処理します。 |

## リピーター

リピーターのコントロールは **Repeater** プロパティセクションに表示されます。**Count** の初期値は 5 で、1 から 128 を受け付けます。

| 種類 | コントロール | 意味 |
| --- | --- | --- |
| **Repeater** | **Position**、**Rotation**、**Scale** | 複製ごとの変換間隔です。Position の初期値は 10, 0, 0、Scale の初期値は 1, 1, 1 です。 |
| **Linear Repeater** | **Position**、**Rotation**、**Scale** | 最初の複製を基準とする最後の複製の変換です。Position の初期値は 40, 0, 0、Rotation の初期値は 0, 0, 90 度です。 |
| **Random Repeater** | **Min position**、**Max position**、**Min rotation**、**Max rotation**、**Min scale**、**Max scale**、**Seed** | シードを使用する範囲です。Seed の初期値は 1 です。 |
| **Echo Repeater** | **Offset** | 複製ごとの過去方向の間隔で、フレーム単位です。初期値は 5、範囲は 0 から 100000 です。 |

Scale の最小値は各軸 0.001 です。リピーターの回転の行は度で表示します。

## Twist、Warp、分割

| 種類 | コントロールと初期値 |
| --- | --- |
| **Twist** | **Axis** は X、Y、Z で、初期値は Y です。**Angle** は初期値が 0 度で、-1440 から 1440 を受け付けます。**Offset** は軸に沿って基準点を移動します。 |
| **Warp** | **Axis** は X または Z で、初期値は X です。**Strength** は初期値が 0 度で、-720 から 720 を受け付けます。**Offset** は曲げの基準点を移動します。 |

**Subdivision** の辺の分割数は 1、2、4、8、16 で、初期値は 4 です。元の三角形 1 個につき、それぞれ 1、4、16、64、256 個の三角形を生成します。

分割の予算はメッシュごとに 400,000 三角形です。予算に収めるため、分割を段階単位で下げます。元のメッシュが既にこの数を超えている場合は、簡略化しません。

## フィールド

Twist、Warp、Voronoi Fracture、Plain は、以下のフィールドコントロールを共有します。エフェクターオブジェクトの変換が、ローカル座標系を定義します。

| コントロール | 意味と初期値 |
| --- | --- |
| **Field** | **infinite**、**linear**、**box**、**sphere**、**cylinder**、**noise** です。初期値は infinite です。 |
| **Field position** | エフェクター空間のフィールドのオフセットです。初期値は 0, 0, 0 です。 |
| **Field rotation** | 度単位の XYZ オイラー回転です。初期値は 0, 0, 0 です。 |
| **Field scale** | 変形前の入力形状の寸法に対する割合です。初期値は 100, 100, 100、最小値は各軸 0.01 です。 |
| **Falloff** | フィールド内部の滑らかな境界の幅で、0 から 100 です。初期値は 100 で、0 では硬い境界になります。 |
| **Falloff curve** | **linear**、**smooth**、**ease in**、**ease out** です。初期値は linear です。 |
| **Invert field** | 結果の重みを反転します。初期状態はオフです。 |
| **Sweep** | 線形フィールドの進行度で、0 から 100 です。0 ではどの位置にも作用せず、100 ではすべての位置に作用します。 |
| **Noise scale** | フィールドの大きさに対するノイズの波長です。初期値は 100、範囲は 0.01 から 10000 です。 |
| **Noise evolution** | シードを使用するノイズの連続的なオフセットです。初期値は 0 です。 |

Twist と Warp は頂点ごとにフィールドを評価します。破砕は変形前の破片の重心で評価するため、各破片は剛体を保ちます。cylinder フィールドは、フィールドの Y 方向を向きます。

エディターは linear、box、sphere、cylinder のフィールドとフォールオフのガイドを表示します。infinite と noise には境界ガイドがありません。ガイドは書き出しに表示されません。

**Edit field in viewport** は、一時的なエディター状態です。完了した各ドラッグは、取り消し可能な操作を 1 回記録します。選択を変更するか編集用カメラを終了すると、このモードを終了します。

## Voronoi Fracture

| コントロール | 意味と制限 |
| --- | --- |
| **Cells**、**Seed** | セル数は 1 から 1000 で、初期値は 24 です。Seed の初期値は 1 です。 |
| **Distribution**、**Cell scale** | 分布は **uniform**、**surface**、**center**、**edges** です。Cell scale はセルの各軸の比率を変更し、初期値は 100, 100, 100 です。 |
| **Inner faces** | **open** または **closed** で、初期値は closed です。元のメッシュの開いた境界は閉じません。 |
| **Fragment colors** | **material** または **random** で、初期値は random です。ランダム色はシードを使用します。 |
| **Offset fragments** | 破片間の隙間のコントロールで、0 から 100 です。初期値は 0 です。 |
| **Distance**、**Scatter**、**Spin** | 破片の移動と回転で、初期値はすべて 0 です。Distance と Scatter は -1000 から 1000、Spin は -3600 から 3600 度を受け付けます。 |
| **Direction**、**Rotation**、**Fragment scale** | 各部分の追加移動、度単位の XYZ 回転、拡大率です。初期値は移動と回転が 0、拡大率が 100 パーセントです。 |
| **Gravity**、**Randomness** | Gravity はエフェクターの -Y 方向に破片を移動します。Randomness は、シードによる値で動きの強さを減らし、0 から 100 です。初期値は両方とも 0 です。 |
| **Characters**、**Invert selection** | `1,3-5` のような 1 始まりの文字範囲と、選択の反転です。空白は数え、改行は数えません。空の Characters はすべてを選択します。空でない無効な範囲は何も選択しません。 |

フィールドの強度が最大のとき、**Fragment scale** は **Randomness** に関係なく指定した比率になります。値が 0 のとき、内側の面を含む各破片の全頂点が 1 点に集まります。フィールドの強度が中間のとき、元のサイズと指定したサイズの間を補間します。強度が 0 のとき、破片は変化しません。**Randomness** が 0 以外の既存プロジェクトでは、ランダムな拡大率ではなく指定した拡大率を使います。他の移動と回転の設定は、シードによる変動を維持します。

文字の選択には Text+ が必要です。テキスト以外のソースは文字範囲を無視します。Invert selection は、空の選択が全体を選ぶ動作を変更しません。

破砕の制限は、入力 160,000 三角形、出力 1,600,000 三角形、穴を含む凹形状の切断面の輪郭ごとに 4,096 頂点、ビルドごとに 80,000,000 回のクリッピング操作です。制限を超えるビルドでは、元の形状を破砕せずに残します。切断面の輪郭が無効または過大な場合は、開いた破片に切り替わることがあります。

不透明な破片のメッシュは、同じ描画優先度の中で元の階層の順序を使います。これにより、深度が等しい部分の重なりがマテリアルの作成順序に左右されなくなります。既存プロジェクトでは、重なりの境界にある一部のピクセルが変わる場合があります。透明なマテリアルは、元の並べ替えを維持します。

組み込みエフェクターのチェーンは、プレビューと書き出しで同じ評価処理を使います。Worker を利用できるブラウザーでは、形状の評価を Worker で実行します。Cells、Seed、元の形状を変更した後のトポロジーの初回構築も対象です。要求した結果の計算中は、プレビューは最後に表示した画像を保持し、**Fracturing...** を表示します。再生は一時的に停止するか、フレームを省略することがあります。スクラブの終了時には、要求した正確なフレームを表示します。書き出しと **Render once** は、その正確な結果を待ちます。プレビューは、元の形状や別のフレームの結果で代用しません。Worker を利用できない環境では、同期的に評価します。

## Plain と Delay

Plain には **Position offset**、**Rotation offset**、**Scale offset**、**Uniform scale** があります。初期値は 0 です。回転は度単位です。Scale offset が 0 の軸は変わらず、1 では 2 倍になります。

Plain は、接続された個別の部分、文字、上流の破砕で作った部分を変換します。Delay は上流のエフェクターの階層内に置き、対象の元オブジェクトは Delay の中に置きます。

| Delay のコントロール | 意味と初期値 |
| --- | --- |
| **Mode** | **Blend** は指数重み、**Average** は等しい重み、**Spring** は減衰する振動カーネルを使用します。初期値は Blend です。 |
| **Strength** | フィルター結果との混合率で、0 から 100 です。初期値は 75 です。 |
| **History frames** | 1 フレーム間隔の過去サンプル数で、1 から 24 です。初期値は 12 です。 |

入れ子の Delay 履歴は、メッシュごとに合計 96 サンプルの予算を共有します。破砕のトポロジーが異なるサンプルは除外します。サンプリングは前に描画したフレームではなく、過去の上流プロパティ、フィールド、標準オブジェクトの変換を評価します。

## 旧プロジェクト

Twist、Warp、破砕の数値型 7、8、9 は、名前空間を持つ Effector クラスに移行します。Effector+ はこれらの数値型との互換性を提供し、新しいピッカー項目は追加しません。

古いフィールドと分割の設定は、互換動作を保つ場合があります。破砕の文字選択が有効な場合も、保存した旧分割方式を適用します。新しいコントロールは、現在の割合に基づくフィールドと均等分割モデルを使用します。

手順は [Effector でオブジェクトを複製・変形する](/docs/ja/features/effector/)を参照してください。
