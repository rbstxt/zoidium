Animated GIF は GIF87a と GIF89a の画像アセットに対応し、透過とインターレースを含みます。

## 時間

デコードされたアニメーションはループし、負のメディア時間にも同じ規則を使います。クリップのメディア時間がフレームを選択します。

GIF の遅延は 100 分の 1 秒単位です。保存された遅延が 0 または 1 の場合は 0.10 秒になります。2 以上の場合はエンコードされた値が保たれるため、遅延 2 は 0.02 秒です。

## デコーダーの制限

| 制限 | 値 | 結果 |
| --- | --- | --- |
| フレーム数 | 512 | 上限でデコードを停止します。 |
| キャンバスの面積 | 67,108,864 ピクセル | これを超える GIF キャンバスはデコードに失敗します。 |
| フレーム面積の累計 | 67,108,864 ピクセル | キャンバス全体の各フレームが予算を消費します。残りの予算が 0 以下になるとデコードを停止します。 |

各デコードフレームはキャンバス全体の面積で予算を消費します。

これらは入力デコードの制限です。Animated GIF は GIF の書き出し形式を追加しません。

読み込みの手順は[アニメーション GIF を使う](/docs/ja/features/gif-support/)を参照してください。
