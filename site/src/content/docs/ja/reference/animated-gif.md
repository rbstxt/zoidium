Animated GIF は GIF87a と GIF89a の画像アセットに対応します。デコーダーはパレット、透過、インターレース、0 から 3 の破棄方式に対応します。

GIF の検出には、画像アセットのファイル名または URL の `.gif` 拡張子を使用します。大文字と小文字、末尾のクエリやフラグメントは区別しません。

## 時間

デコードされたアニメーションはループし、負のメディア時間でも同じ規則を使います。クリップのメディア時間がフレームを選択します。クリップのコンテキストがない場合は、プロジェクトのフレームをシーケンスのフレームレートで割った時間を使用します。

GIF の遅延は 100 分の 1 秒単位です。保存された遅延が 0 または 1 の場合は 0.10 秒になります。2 以上の場合はエンコードされた値を維持するため、2 の遅延は 0.02 秒です。

フレームは、実時間の経過や描画の順序ではなく、メディア時間で決まります。

## デコーダーの制限

| 制限 | 値 | 結果 |
| --- | --- | --- |
| フレーム数 | 512 | 上限でデコードを停止します。 |
| キャンバスの面積 | 67,108,864 ピクセル | これを超える GIF キャンバスはデコードに失敗します。 |
| フレーム面積の累計 | 67,108,864 ピクセル | キャンバス全体の各フレームが予算を消費します。残りの予算が 0 以下になるとデコードを停止します。 |

ピクセル予算は、フレームが小さな矩形だけを更新する場合も、デコードした各フレームについて GIF キャンバス全体の寸法を数えます。最後のフレームにより、面積の累計が予算を超える場合があります。

これらは入力デコードの制限です。Animated GIF は GIF の書き出し形式を追加しません。

読み込みの手順は[アニメーション GIF を使う](/docs/ja/features/gif-support/)を参照してください。
