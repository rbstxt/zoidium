Graph Editor 2 は、有効な間、標準のグラフパネルを置き換えます。Graph+ はこのプラグインの別名です。

## 開き方と選択

| 操作またはコントロール | 動作 |
| --- | --- |
| Ctrl+G またはエディターのグラフボタン | 独立したグラフウィンドウを 1 つ開くか、既存のウィンドウにフォーカスします。 |
| **Show in Graph Editor** | 選択への追従がオフの場合も、プロパティのカーブを表示し、グラフ内に収めます。 |
| Alt+Shift+G | フォーカス中のプロパティ行を表示します。 |
| **Follow selection** | 初期状態はオンです。プロパティの選択でカーブを置き換え、Ctrl または Shift キーを押しながらのクリックで追加します。オフでは表示中のカーブを固定します。 |

ベクトルと色のプロパティは、すべての成分を表示します。オブジェクトやレイヤーを選択すると、入れ子のマテリアル、ジオメトリ、プラグインを含むアニメーション中のプロパティに追従します。エクスプレッションで駆動されるプロパティは、アニメーション中のプロパティの自動収集から除外します。

追従の設定と独立ウィンドウの位置・大きさは、ローカルに保存されます。カーブを開く操作や追従は、プロジェクトの履歴に記録しません。プラグインを無効にすると独立ウィンドウを閉じ、標準のグラフパネルと開き方に戻します。

## 補間と接線のツール

| ツールバーのラベル | 動作 |
| --- | --- |
| **Linear** | 選択したキーに線形イージングを適用します。 |
| **Step** | 次のキーまで前の値を維持します。 |
| **Ease** | cubic in-out イージングを適用します。 |
| **Custom easings** | ホストのイージングプリセットを一覧表示します。 |
| **Break Tangents** | 選択した接線の方向を独立させます。 |
| **Auto Tangents** | 選択した接線を連続させます。 |
| **Bezier** | Bezier 補間と線形補間を切り替えます。 |
| **Link** | 接線の連続性を切り替えます。 |
| **Flat** | 選択したハンドルをリセットします。 |

キーの編集は、標準のプロパティ操作と取り消し履歴を使用します。Easing+ と Graph Editor 2 は、同じ Bezier ハンドルを読み書きします。

## 表示と編集のコントロール

これらのショートカットは、グラフにキーボードのフォーカスがある場合に適用します。テキスト入力欄では通常どおり入力できます。

| ツールバーのラベル | ショートカット | 動作 |
| --- | --- | --- |
| **Pan** | H | 左ドラッグでグリッドを移動します。Space キーを押しながらのドラッグでも移動できます。 |
| **Marquee** | V | 左ドラッグでキーを選択します。Shift キーを押しながらのドラッグは、どちらのツールでも選択します。 |
| **Fit** | Backslash | すべてのカーブを収めます。 |
| **Frame** | F | 選択したキーを収めます。 |
| **Norm** | N | キーの値を変更せず、カーブの表示の高さを正規化します。 |
| **Snap** | S | ドラッグを再生ヘッドとキーにスナップします。 |
| **+Key** | K | 表示中のカーブの再生ヘッド位置にキーを追加します。 |
| **Del** | Delete または Backspace | 選択したキーを削除します。 |
| **Bezier** | I | 選択したキーの補間を切り替えます。 |
| **Link** | T | 接線の連続性を切り替えます。 |
| **Flat** | R | 選択したハンドルをリセットします。 |
| **Copy**、**Paste** | Ctrl+C、Ctrl+V | 選択したキーをコピーし、再生ヘッド位置に貼り付けます。Command+C と Command+V も使用できます。 |
| **Labels** | なし | カーブのラベルを切り替えます。 |

Ctrl+X はキーを切り取り、Ctrl+A はすべてのキーを選択します。Command+X と Command+A も使用できます。矢印キーはキーを少しずつ移動します。Shift キーで移動量は 1 から 10 単位になります。水平方向の単位はフレームです。垂直方向の移動量は、グラフのピクセルを値に変換して求めます。

マウスホイールは、ポインターを中心に拡大・縮小します。グラフのルーラーは再生ヘッドを移動します。グラフのダブルクリックはキーを追加します。

手順は [Graph Editor 2 でアニメーションカーブを編集する](/docs/ja/features/graph-editor-2/)を参照してください。
