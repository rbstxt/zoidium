Node Effect はグラフをネイティブの Custom Shader エフェクトにコンパイルします。Parameter の欄を除き、数値と色の欄にはピクセルごとのソケットがあります。接続された入力はローカルの欄を置き換えます。

数値は有限で、絶対値が `100000000` 以下である必要があります。表は、より狭いエディターの範囲が指定されている場合にその範囲を示します。UV 座標は正規化します。Pixel Coordinate と Radius はピクセル単位です。角度はラジアン単位です。


## Layer Color

入力: なし

出力: **Color**, **Alpha**

エフェクトの入力から Color と Alpha をサンプリングします。


## UV

入力: なし

出力: **UV**

## Time

入力: なし

出力: **Seconds**

ネイティブのクリップの時刻を秒単位で出力します。トリムと時間の再マッピングに従います。


## Parameter

入力: なし

出力: **Value**

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Name** | テキスト | テキスト | `Amount` | 公開するネイティブのプロパティのラベルです。 |
| **Type** | 選択肢 | **Float**, **Color**, **Vector2 point** | **Float** | Float、Color、Vector2 point のパラメーターです。 |
| **Default** | 数値 | 明示的な範囲指定なし | `0.5` | ノードが使う数値です。 |
| **Default color** | RGB カラー | 明示的な範囲指定なし | `#ffffff` | パラメーターの初期の RGB カラーです。 |
| **Default X** | 数値 | 明示的な範囲指定なし | `0.5` | X 成分の初期値です。 |
| **Default Y** | 数値 | 明示的な範囲指定なし | `0.5` | Y 成分の初期値です。 |
| **Minimum** | 数値 | 明示的な範囲指定なし | `0` | 公開するコントロールの下限です。 |
| **Maximum** | 数値 | 明示的な範囲指定なし | `1` | 公開するコントロールの上限です。 |

ネイティブのアニメーションプロパティを作成します。Name の上限は48文字です。名前を変えてもノードの識別情報を保持します。

## Blur

入力: **UV**, **Radius (px)**, **Angle**, **Center X**, **Center Y**

出力: **Color**, **Alpha**

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Type** | 選択肢 | **Box**, **Gaussian**, **Directional**, **Radial** | **Box** | このノードの処理方法です。 |
| **Samples** | 数値 | 1 ～ 32 | `9` | 要求するソースのサンプル数です。 |
| **Radius (px)** | 数値 | 明示的な範囲指定なし | `8` | 周辺のサンプリングまたは汚れの細部の半径です。 |
| **Angle** | 数値 | 明示的な範囲指定なし | `0` | 模様またはサンプリングの方向です。ラジアン単位です。 |
| **Center X** | 数値 | 明示的な範囲指定なし | `0.5` | 正規化した UV 座標の水平の中心です。 |
| **Center Y** | 数値 | 明示的な範囲指定なし | `0.5` | 正規化した UV 座標の垂直の中心です。 |

Box と Gaussian は最大5×5の正方形の格子を使います。Directional と Radial は1から32サンプルを使います。

## グラフとサンプリングの制限

グラフの上限は128ノード、256接続、196608文字の JSON です。循環と同じ入力への重複した接続は無効です。出力へ接続するノードのソースのサンプル数の上限は、出力の1ピクセルあたり256です。
