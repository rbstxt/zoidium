---
title: Assets
---
**Assets** タブとウィンドウは、プロジェクトのファイル、組み込みリソース、プラグインのリソース、埋め込みリソース、コンポジションを一覧表示します。

## 種類、状態、使用箇所

種類のフィルターには、プロジェクトに存在する種類として **Composition**、**Video**、**Audio**、**Image**、**Font**、**3D Model**、**LUT**、**Shader**、**IES Profile**、**File** を表示します。

| 状態 | 意味 |
| --- | --- |
| **Ready** | 読み込み中・不足・失敗の記録がなく、利用可能です。 |
| **Loading** | リソースを読み込み中です。 |
| **Missing** | 参照するファイルが利用できません。 |
| **Failed** | リソースの読み込みに失敗しました。 |

**Uses** は、閉じたコンポジション内も含めた参照数です。使用箇所にはクリップ、プロパティ、キーフレームがあります。閉じたコンポジション内の使用箇所には、そのコンポジションが表示されます。

## フィルターと検索

| フィルター | 内容 |
| --- | --- |
| **All** | すべての項目。 |
| **Used** | 参照が 1 つ以上ある項目。 |
| **Unused** | 参照がない項目。 |
| **Problems** | 不足するファイルと、参照が 1 つ以上ある読み込み失敗の項目。 |

**Type** は項目の種類を制限します。**Search** は名前、種類、状態、ソース、詳細内の単語を照合します。すべての検索語が一致する必要があります。フィルター、種類の制限、検索のいずれかを使うと、平坦な一覧になります。制限のない表示ではフォルダーが表示されます。

## 項目のコマンド

コマンドは、選択した項目に適用できる場合だけ有効になります。閉じたコンポジション内の使用箇所には手が届きません。スキップや報告の対象になるか、コンポジションを開く必要があります。

| コマンド | 結果 |
| --- | --- |
| **Import…** | ファイルをプロジェクトの項目として追加します。フッテージは Media パネルにも表示します。 |
| **Reveal in Timeline** | 編集可能な使用箇所を選択します。 |
| **Reload** | 置き換え先を選ばず、既存のリソースを再試行します。 |
| **Locate…** | 元の不足ファイルを再接続します。別のファイルを選んだ場合は、確認後に置き換え処理へ進めます。 |
| **Replace…** | 編集可能な使用箇所を同じ種類の別ファイルに置き換えます。 |
| **Download** | 利用可能なデータを別ファイルとしてダウンロードします。 |
| **Delete** | 未使用ファイルを削除するか、そのクリップとプロパティの使用箇所の削除を確認します。 |
| **Open Composition** | コンポジションのソースタイムラインを開きます。 |
| **Rename** | コンポジション名またはフォルダー名を変更します。 |
| **Duplicate** | 独立したコンポジションソースを作成します。 |

コンポジションの行にはコンポジション用のコマンドを使います。ファイルの再読み込みやダウンロードは適用しません。使用中のコンポジションは、参照元のクリップを削除するまで削除できません。

## フォントピッカーのプロジェクトフォント

Assets に読み込んだフォントは、すべての **Font** ピッカーに表示されます。対象はネイティブ Text、3D Text、Shape+ の **Font Family** と **Fallback Font**、Shader+ のテキストです。ピッカーは組み込みフォント、**Project fonts** の読み込み済みフォント、**custom...** の順に並べます。読み込み済みフォントはファミリー名順です。ボタンは選択中のプロジェクトフォントをその書体で表示します。プロジェクトフォントを選ぶと、既存のアセットキーを 1 回の Undo で保存します。解析に失敗したフォントはファイル名に **failed** バッジを付けて表示します。使用中のフォントを削除すると、プロパティに Missing 状態を表示します。パネルは動作を続けます。

## プロジェクトのコマンド

**Project commands** には次の操作があります。

| コマンド | 結果 |
| --- | --- |
| **New Folder** | 整理用のフォルダーを作成します。 |
| **Remove Unused Items** | 参照のないインポート済みファイルを削除します。確認は表示しません。Undo で復元できます。 |
| **Consolidate All Footage** | データが同一のファイルを統合します。 |
| **Collect Files…** | Assets ウィンドウのフォルダー構造で利用可能なファイルをまとめ、不足ファイルのレポートとともに ZIP をダウンロードします。`.pz` プロジェクトアーカイブではありません。 |
| **Resolve Fonts…** | 使用中の不足フォントや読み込み失敗のフォントを、組み込みフォントまたはフォントファイルに置き換えます。 |

ファイルの収集は不足するデータを修復しません。組み込み項目とプラグインの項目は、未使用ファイルとして削除されません。

## フォルダー、ラベル、ドラッグ操作

フォルダーは、ディスク上のファイルを変更せずにプロジェクトの項目を整理します。**New Folder Inside** は子フォルダーを作成します。**Delete Folder** はアセットを削除せず、内容を親フォルダーに移します。

**Label ▸** メニューは、項目とフォルダーに 16 色のラベルまたは **None** を設定します。フォルダー構造とラベルのメタデータはプロジェクトに保存します。

項目やフォルダーをフォルダーにドラッグすると、その中に移動します。一覧の空白にドロップするとルートに移動します。コンピューターからドロップしたファイルはインポートします。対応するフッテージはタイムラインにドラッグできます。互換性のあるアセット項目は、アセットプロパティの行にドロップできます。

## Undo の制限

インポート、置き換え、未使用ファイルの削除、統合、フォルダー編集、ラベル編集、アセットプロパティへの割り当ては取り消しできます。再読み込み、収集、ダウンロードは取り消しできません。

復旧手順は[アセットの修復](/docs/ja/how-to/repair-assets/)を参照してください。編集可能なアーカイブについては、[保存と復元ポイント](/docs/ja/development/project-saving/)を参照してください。
