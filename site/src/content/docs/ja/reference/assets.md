---
title: Assets
---
**Assets** タブとウィンドウは、プロジェクトのファイル、組み込みリソース、プラグインのリソース、埋め込みリソース、コンポジションを一覧表示します。

## 種類、状態、使用箇所

種類のフィルターには、プロジェクトに存在する種類として **Composition**、**Video**、**Audio**、**Image**、**Font**、**3D Model**、**LUT**、**Shader**、**IES Profile**、**File** を表示します。

| 状態 | 意味 |
| --- | --- |
| **Ready** | レジストリーが項目に読み込み中、不足、失敗の状態を記録していません。 |
| **Loading** | リソースを読み込み中です。 |
| **Missing** | 参照するファイルが利用できません。 |
| **Failed** | リソースの読み込みに失敗しました。 |

**Uses** は、閉じたコンポジション内も含めた参照数です。使用箇所にはクリップ、プロパティ、キーフレームがあります。一覧の使用箇所を選択できるのは、エディターがその箇所を表示できる場合だけです。閉じたコンポジション内の使用箇所には、それを含むコンポジションを示します。

## フィルターと検索

| フィルター | 内容 |
| --- | --- |
| **All** | すべての項目。 |
| **Used** | 参照が 1 つ以上ある項目。 |
| **Unused** | 参照がない項目。 |
| **Problems** | 不足するファイルと、参照が 1 つ以上ある読み込み失敗の項目。 |

**Type** は項目の種類を制限します。**Search** は名前、種類、状態、ソース、詳細内の単語を照合します。すべての検索語が一致する必要があります。フィルター、種類の制限、検索のいずれかを使うと、平坦な一覧を表示します。制限のない表示ではフォルダーを表示します。

## 項目のコマンド

コマンドは、選択した項目に適用できる場合だけ有効になります。

| コマンド | 結果 |
| --- | --- |
| **Import…** | ファイルをプロジェクトの項目として追加します。フッテージはネイティブの Media パネルにも表示します。 |
| **Reveal in Timeline** | 編集可能な使用箇所を選択します。閉じたコンポジション内の使用箇所は、そのコンポジションを開く必要があります。 |
| **Reload** | 置き換え先を選ばず、既存のリソースを再試行します。 |
| **Locate…** | 元の不足ファイルを再接続します。別のファイルは、確認後に置き換え処理へ進めます。 |
| **Replace…** | 編集可能な使用箇所を同じ種類の別ファイルに置き換えます。閉じたコンポジション内の使用箇所はスキップし、報告します。 |
| **Download** | 利用可能なデータを別ファイルとしてダウンロードします。 |
| **Delete** | 未使用ファイルを削除するか、そのクリップとプロパティの使用箇所の削除を確認します。閉じたコンポジション内の使用箇所は削除を妨げます。 |
| **Open Composition** | コンポジションのソースタイムラインを開きます。 |
| **Rename** | コンポジション名またはフォルダー名を変更します。 |
| **Duplicate** | 独立したコンポジションソースを作成します。 |

コンポジションの行にはコンポジション用のコマンドを使います。ファイルの再読み込みやダウンロードは適用しません。使用中のコンポジションは、参照するクリップを削除するまで削除できません。

## プロジェクトのコマンド

**Project commands** には次の操作があります。

| コマンド | 結果 |
| --- | --- |
| **New Folder** | 整理用のフォルダーを作成します。 |
| **Remove Unused Items** | 参照のないインポート済みファイルを削除します。確認は表示しません。Undo で復元できます。 |
| **Consolidate All Footage** | データが同一のファイルを統合します。閉じたコンポジション内の使用箇所により元の項目が残る場合は、その旨を報告します。 |
| **Collect Files…** | 利用可能なファイルを `Assets` 配下にまとめ、不足ファイルのレポートとともに ZIP をダウンロードします。`.pz` プロジェクトアーカイブではありません。 |
| **Resolve Fonts…** | 使用中の不足フォントや読み込み失敗のフォントを、組み込みフォントまたはフォントファイルに置き換えます。 |

ファイルの収集は不足するデータを修復しません。組み込み項目とプラグインの項目は、未使用ファイルの削除対象となる通常のインポート済みファイルではありません。

## フォルダー、ラベル、ドラッグ操作

フォルダーは、ディスク上のファイルを変更せずにプロジェクトの項目を整理します。**New Folder Inside** は子フォルダーを作成します。**Delete Folder** はアセットを削除せず、内容を親フォルダーに移します。フォルダーは自分自身や子孫に移動できません。

**Label ▸** メニューは、項目とフォルダーに 16 色のラベルまたは **None** を設定します。フォルダー構造とラベルのメタデータはプロジェクトに保存します。

項目やフォルダーをフォルダーにドラッグすると、その中に移動します。一覧の空白にドロップするとルートに移動します。コンピューターからドロップしたファイルはインポートします。対応するフッテージはタイムラインにドラッグできます。互換性のあるアセット項目は、アセットプロパティの行にドロップできます。

## Undo の制限

インポート、置き換え、未使用ファイルの削除、統合、フォルダー編集、ラベル編集、アセットプロパティへの割り当ては、プロジェクトの履歴を使います。再読み込み、収集、ダウンロードはリソースやファイルの操作であり、ソース編集の復旧用コピーではありません。

Precomp+ のコンポジションを切り替えると、Undo と Redo の履歴が消去されます。プロジェクトが一度も保持していないファイルは、Undo で復元できません。

復旧手順は[アセットの修復](/docs/ja/how-to/repair-assets/)を参照してください。編集可能なアーカイブについては、[保存と復元ポイント](/docs/ja/development/project-saving/)を参照してください。
