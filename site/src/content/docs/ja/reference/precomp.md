---
title: Precomp+
---
Precomp+ は、動画トラックと音声トラックを持つコンポジションをプロジェクトのメディアとして保存します。コンポジションクリップは、この共有ソースを参照します。

## コンポジションのコントロール

**Comps** には **Open Compositions**、**Pre-compose selection**、**New composition** があります。**Compositions** ウィンドウには Main、コンポジションの長さ、使用数、現在の編集場所を表示します。

| コントロール | 動作 |
| --- | --- |
| **Open** | 編集対象のタイムラインをソースコンポジションに切り替えます。ダブルクリックでも同じ操作を実行します。 |
| **Back to Main** | ソースの編集内容を保持し、メインのタイムラインに戻ります。 |
| **Name** | ソース名を変更します。名前は大文字と小文字を区別せず一意で、60 文字以内です。Main は使えません。 |
| **Duplicate** | 新しい識別子を持つ独立したコンポジションソースを作成します。 |
| **Delete** | Main または別のコンポジションから参照されている間は削除を拒否します。 |
| **New composition** | 空のソースを作成します。Main にクリップは配置しません。 |

別のコンポジションを開くか Main に戻ると、Undo と Redo の履歴が消去されます。ウィンドウを閉じるだけではタイムラインを切り替えません。

## 選択とタイミング

Pre-compose は、選択したクリップを新しいソースに移します。相対的なタイミングとソーストラックの順序は保持します。最も早い開始位置がソースのフレーム 0 になります。新しいコンポジションクリップは、最も早い開始位置から最も遅い終了位置までを覆います。

移動したトラックはトラックのスイッチを保持します。移動したクリップのリンクは解除します。動画を含む選択では、空き区間のある動画トラックで 1 つのコンポジションクリップに置き換えます。音声だけの選択では、代わりのクリップを作らずにソースを作成します。

コンポジション時刻は、親クリップ内のフレームに保存されたオフセットを加えた値です。ソースの長さは最後のクリップの終了位置から求め、最小値は 1 フレームです。

## 入れ子と音声

コンポジションにはコンポジションクリップを含められます。開いているコンポジションが入れ子の参照を通して自分自身を含むことになる移動は、Pre-compose が拒否します。描画とスケジュール走査も再帰的な参照を停止します。入れ子のガードは 16 階層です。

入れ子の動画はソースのトラック順を保持します。無効な動画トラックは描画しません。入れ子の音声は、クリップのタイミング、音量、パンを含む Main の通常の音声処理を使います。音声は、それを含むコンポジションクリップの時間範囲に制限します。

コンポジションクリップのない音声専用ソースは、Main の再生や書き出しには入りません。

## 再利用と削除

同じコンポジションを参照するクリップはソースの編集内容を共有します。**Duplicate** は独立したソースを作成します。タイムラインで複製したクリップは、元のソースを参照したままの場合があります。

削除時には Main とほかのコンポジションからの参照を報告します。その参照を削除すると、ソースを削除できます。プロジェクトにコンポジションがある間は Precomp+ を無効にできません。

## 書き出しと保存したプロジェクト

動画の書き出しとフレームキャプチャーでは、Main をアクティブなタイムラインにする必要があります。コンポジションを開いている場合、レンダリングを開始せず **Export Main** を表示します。

コンポジションを開いたまま保存すると、Main と現在のソースの編集内容をシリアライズします。保存したプロジェクトには Precomp+ の依存情報を記録します。古いコンポジションメディアは、安定したソース参照のモデルに移行できます。

プラグインを使えない場合も、未知のフィールドを保持する処理によって、後の保存に必要なコンポジションのメタデータを残します。データの保持だけでは機能を描画できません。

操作手順は[クリップのプリコンポーズ](/docs/ja/how-to/precompose/)を参照してください。[プロジェクトの互換性](/docs/ja/development/project-compatibility/)では、保持する拡張データを説明しています。
