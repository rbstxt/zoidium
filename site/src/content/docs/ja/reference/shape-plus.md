Shape+ の座標はコンポジションのピクセル単位です。原点は中央で、Y の正方向は上です。レイヤー変形は描画後のレイヤーに適用されます。— は宣言された範囲がないことを示します。


## Contents の順序とアニメーション

描画項目は、同じグループ内でその項目より上にある有効なパスを描画します。先行する入れ子のグループ内のパスも含みます。モディファイアは対象範囲の先行パスに作用します。

各項目には **Enabled** があります。選択肢は **off** と **on** で、初期値は **on** です。数値、ベクトル、色、グラデーションはアニメーションします。選択肢は固定です。

## 制限と関連リファレンス

パスの接線は各頂点からの相対値です。Contents から追加したパスは 4 頂点の長方形です。Pen で追加したパスは 1 頂点の開いたパスです。

SVG の読み込みとネイティブからの変換は、編集可能なベクトル項目を作成します。変換後の Shape+ の輪郭には Text+ の文字アニメーションに相当する機能はありません。

[Shape+ でパスを作成する](/docs/ja/features/shape-plus/)

離散的なテキスト設定はホールドキーと式に対応します。Style のアニメーションは、
独自のアニメーションがない軸に座標を設定します。アニメーション済みの軸は独自の値を保持します。

TTF、OTF、可変 TrueType、CFF2、WOFF1 に対応します。WOFF2 は非対応の状態を表示し、
フォントの参照を保持します。フォントがない場合は項目の横に状態を表示します。
暗黙のフォールバックはありません。日本語は選択したフォントの日本語グリフを使用します。

Box テキストはラテン文字を単語単位、CJK を書記素単位で折り返します。
幅を超えるラテン文字の単語は書記素単位で折り返します。改行は段落を開始します。
Box の高さを超える行は表示しません。Point テキストは折り返しません。
均等配置は空白を広げます。空白のない CJK の行は、余った幅を書記素間に配分します。
その他の空白のない行では元の送り幅を保持します。

追加のエンジンバンドルは、最初のテキスト使用時に読み込みます。Electron は未検証です。

## Text Animator

Text Animator は、同じグループ内で上にあるすべての Text 項目に作用します。
上にある入れ子のグループ内のテキストも含みます。アニメーターはリストの順序で上から下へ重なります。
上にテキストがないアニメーターは "No text above this animator" を表示します。
各アニメーションプロパティは neutral + (value - neutral) x s として適用されます。s は単位ごとのセレクター合成値です。
無効なプロパティは作用せず、行を非表示にします。アニメーターのコンテキストメニューの Add Property と Remove Property で切り替えます。
文字ごとの Opacity、Fill Color、Stroke Color、Stroke Width には未対応です。

| --- | --- | --- | --- |
| **Anchor Point** | 動的ベクトル | [0, 0] | 拡大・回転・スキューに使用するピボットのずれ。 |
| **Position** | 動的ベクトル | [0, 0] | グリフ位置に加算します。Y は上向きです。 |
| **Scale (%)** | 動的ベクトル | [100, 100] | 中立値は 100。 |

| **Tracking Amount** | 動的数値 | 0 | 作用する各文字の後に value x s x Size / 1000 を加算します。配置はこの移動の前に計算します。 |
| **Character Offset** | 動的数値 | 0 | a-z、A-Z、0-9 の範囲で文字をずらす整数。折り返します。合字はクラスタの全文字をずらして一体として整形し、先頭文字のセレクター値で移動します (AE は合字を分解します)。新しい送り幅が古い送り幅を置き換えます。カーニングは元のシェーピングのままです。 |

## Create Shapes from Text

プレビューの **Convert to Path** と Objects 行の **Create Shapes from Text** は、
現在のフレームで Text を文字のグループに置き換えます。各輪郭は個別の Path です。
空白にはグループを作成しません。合字の輪郭は先頭文字に属し、残りの文字には空の名前付きグループを作成します。
結合記号は基底文字の書記素グループに残ります。巻き方向と親のペイント順序を保持します。
1 件の履歴により、Undo でライブテキストを復元します。

変換は Text Animator を含む表示フレームを静的なパスに記録します。
アニメーターの項目はリストに残ります。

## Text cache limits

Text のレイアウトは、フォント、評価済みのテキストと段落設定、可変軸の値でキャッシュします。
フォントファイルを置き換えると、古い結果を再使用しません。レイヤーの変換だけが変わる場合は、
平坦化の許容値が変わらない限り、レイアウトとジオメトリを再使用します。

キャッシュの計上上限は、レイアウト、グリフのジオメトリ、グリフのペイントが各 8 MiB、
解析済み輪郭とシェーピング済みランが各 2 MiB、フォールバック判定が 512 KiB、
エンジンのシェーピング結果が 1 MiB、輪郭が 4 MiB です。ブラウザー全体のヒープ使用量ではありません。

接触または重複するグリフは複合フィルを使用します。斜線と曲線も、サブピクセルの
描画結果を維持するために複合配置を使用します。Trim の individual モードと、
変換された Repeater のビューは、グリフ単位のフィルの再使用を無効にします。

現在のフォントに存在しない軸は、保存データの `axisStore` に保持します。
同じタグの軸があるフォントに切り替えると、キーと式を復元します。
Style の選択は式で制御する軸を上書きせず、通知を表示します。
