---
title: 書き出しオプション
---
**Device** ページは動画を書き出します。**Single frame capture** は再生ヘッドのフレームを書き出します。コンポジションを開いている間は、Precomp+ がどちらの書き出しもブロックします。

## 形式とアルファ

| 出力 | 動画または画像のエンコード | 音声 | アルファ |
| --- | --- | --- | --- |
| **.mp4 (H.264 / AAC or Opus)** | H.264 動画 | AAC または Opus | なし |
| **.mkv (vp8/opus)** | VP8 動画 | Opus | アルファ保持の保証なし |
| **.webm (vp8/opus)** | VP8 動画 | Opus | アルファ保持の保証なし |
| **.png** | PNG 画像 | なし | 描画結果の透明なピクセルに対応 |
| **.jpg** | JPEG 画像 | なし | なし |
| **.webp** | WebP 画像 | なし | ブラウザーが WebP エンコードに対応する場合に保持 |

**black fill** は、PNG と WebP にも不透明な黒い帯を追加します。形式がアルファに対応していても、不透明なプロジェクト背景は透明になりません。

## フレームレート

**Frame rate** は 1～240 FPS の小数値に対応します。範囲外の値は制限され、それ以外は直前のレートを保持します。

出力レートは出力フレームの数と時刻を変更します。プロジェクトのフレームレートとシーケンスの長さは変わりません。

## 品質とビットレート

**Bitrate** の選択肢は **1x (default)**、**2x**、**4x**、**8x** です。この値はエンコーダーの目標動画ビットレートに掛ける倍率です。**1x (default)** は目標値を変更しません。

MP4 では **Quality** セレクターが無効になります。

静止画の **Quality** は **very low**、**low**、**good**、**very good**、**best** から選択できます。PNG エンコードは非可逆圧縮の品質値を使いません。

## 解像度とアスペクト比

**Resolution** のプリセットは 426×240、640×360、854×480、1280×720、1920×1080、2560×1440、3840×2160 です。フレームキャプチャーでは、プロジェクトの解像度がプリセットと異なる場合、その解像度も選択肢に残ります。

**Aspect ratio** は出力の幅と高さの比率を指定します。解像度の長辺を保持し、もう一方の辺を比率から求め、各寸法を偶数に丸めます。縦長の比率では長辺が垂直になります。奇数の寸法では MP4 に 1 ピクセルの黒い縁が付きます。

**Device** の初期値は 16:9 です。フレームキャプチャーの初期値はプロジェクトのアスペクト比です。

| **Aspect ratio mode** | 結果 |
| --- | --- |
| **crop** | 出力全体を埋めます。出力範囲外の内容は切り取ります。これが初期値です。 |
| **black fill** | プロジェクトの画像全体を出力内に収めます。余白は不透明な黒になります。 |

## MP4 の音声とストレージ

MP4 の音声は 48 kHz ステレオ、128 kbit/s で、AAC 優先、Opus フォールバックです。再生予定の音声がない場合、音声トラックは作成しません。

AAC の確認に失敗すると、Opus への切り替えは行わずに書き出しを停止します。MP4 内の Opus には対応プレーヤーが必要です。

## 失敗時の診断情報

書き出しエラーではクリップとフレームを示します。失敗した書き出しは再開しません。

**Single frame capture** の描画が失敗した場合は、**Render error** に診断情報を表示します。

復旧手順は[MP4 を書き出す](/docs/ja/features/mp4-export/)を参照してください。[フレームの書き出し](/docs/ja/how-to/export-frame/)は静止画のキャプチャーを扱います。[True datamosh の書き出し](/docs/ja/how-to/export-true-datamosh/)はオプションの WebM 処理を扱います。
