---
title: Shader プロパティ設定
---
Shader+ は、各カスタムプロパティの定義にコントロール設定を保存します。
設定、グループ、表示方法は、保存、再読み込み、複製、Undo、Redo で保持されます。

## リセットボタン

Shader エフェクトのネイティブな **Properties** の reset は、フラグメントシェーダーのコードを保持します。
Name や Enabled など、その他のネイティブプロパティはリセットします。

**Shader properties** の見出しにある **Reset custom properties to defaults** は、すべてのカスタムコントロールを 1 回の操作でリセットします。
After Effects の Reset に合わせて、キーフレームと式を削除し、フレーム 0 に静的な値を復元します。
Undo は、以前の値、キー、式のソースをまとめて復元します。

`zoidiumShader.default` がある場合、カスタムリセットはその値を使います。
それ以外の場合は、定義の値かネイティブの既定値を使います。
この動作は、ベクトルの成分と、Gradient、Curve、Palette、Text の JSON 値を含むすべての Shader+ の種類に適用されます。
リセットは、プロパティの定義、名前、グループを保持します。

## + リストの Group

**Shader properties** の **+** リストには、検索できる **Group** 項目があります。
選択したプロパティの行を、新しい名前のグループへまとめて移動します。Undo は 1 回分です。
少なくとも 1 つのプロパティを選択する必要があります。グループ名は未使用でなければなりません。
グループは所属するプロパティに保存されるため、空のグループには見出しがありません。
プロパティの編集、保存、再読み込み、複製でも、グループは保持されます。
別の Shader を削除した後も、新しいプロパティは既存のグループに所属しません。
ロック中のグループでは、プロパティを出し入れできません。

折りたたみ、ロック、表示順には、共通のグループ機能を使います。
ネイティブのプロパティ順とシェーダーの uniform 名は変わりません。
手順は[カスタムプロパティをグループに整理する](/docs/ja/how-to/organize-property-groups/)を参照してください。

## Visible when と Has value

**Visible when** は、同じエフェクト内の別のプロパティを選択します。
**Has value** には、完全一致の値と、次の数値条件を指定できます。

| 入力 | 一致する条件 |
| --- | --- |
| `> 5.5` | 5.5 より大きい |
| `>= 1` | 1 以上 |
| `< 0` | 0 より小さい |
| `<= 2` | 2 以下 |
| `!= 3` | 3 と異なる |
| `= 4` | 4 と等しい |
| `1..5` | 1 以上 5 以下 |
| `1; 2; > 5.5` | 1 または 2 と等しいか、5.5 より大きい |

セミコロンは候補を OR で結びます。
比較には、アニメーションや式を含むコントローラーの評価値を使います。
比較対象、演算子、範囲の順序が無効な場合、Apply で変更を保存する前にエラーを表示します。
既存の完全一致の保存値は、演算子の文字を含む文字列も含めて、厳密な一致を維持します。

Toggle または Dropdown の条件を満たす値がない場合、設定パネルに警告を表示します。
Apply は条件を保存し、パネルを開いたままにします。
警告の判定には、選択肢と保存されたキーの値を使います。
式と補間アニメーションは他の値を生成できるため、そのコントローラーにはこの警告を表示しません。

**Shader properties** の見出しにある目のアイコンの **Show hidden** ボタンは、**Visible when** で隠れた行とグループを表示します。
その行は薄く表示され、設定メニューを開けます。
このボタンは、折りたたまれたグループを展開しません。
Show hidden はパネルの状態です。プロジェクトには保存されず、Undo の操作も作りません。
古いプロパティ定義から継承された条件を含め、保存済みの表示条件は変更しません。

グループにも同じ条件を設定できます。グループに所属する行を右クリックして **Group settings…** を選択します。
コントローラーの一覧には、同じエフェクト内のグループに属さないプロパティだけが表示されます。
条件は所属するすべてのプロパティに保存されます。そのため、保存、再読み込み、複製、Undo、Redo でも条件は保持されます。
行が表示されるのは、自身の条件と所属グループの条件の両方を満たす場合だけです。
非表示のグループは、見出しとすべての子を隠します。

表示条件が影響するのはエディターの行だけです。
非表示のプロパティも、現在の値をシェーダー、Preview cache のフレーム、書き出しに渡します。

## Toggle の表示

Toggle の既定の表示は **Off/on menu** です。
**Property settings…** パネルの **Display** = **Checkbox** を選ぶと、1 回のクリックで切り替えられます。
両方の表示は、同じ NUMBER 値の 0 と 1 を書き込みます。新しいキーは Hold を使います。

Display を変更しても、値、キー、式、シェーダー出力は変わりません。
既存の小数値と補間は、そのままシェーダーに渡されます。
アニメーション中の式は、ネイティブメニューと同じく読み取り専用です。
Checkbox の表示は、どちらの状態でもエディターのテーマに従います。

## Minimum、Maximum、Step、Decimals、Snap

Slider、Seed、Time sample、Angle の設定には **Decimals** と **Snap** を表示します。
Time sample の設定には、**Minimum**、**Maximum**、**Step** も表示します。
Toggle と Dropdown の設定には、これらの項目を表示しません。

**Minimum** と **Maximum** は、行エディターの値を制限します。
**Step** は、ドラッグの倍率と矢印キーの増分です。
**Decimals** は、表示する小数点以下の桁数を 0 から 100 で指定します。
**Snap** は、確定する行の編集値を **Snap** の倍数に丸めます。
グリッドは **Minimum** の設定値から始まります。未設定の場合は 0 から始まります。
ちょうど中間の値は 0 から遠い方へ丸めます。
**Snap** が空欄または 0 の場合、その項目は定義から削除され、ネイティブの動作を維持します。
矢印キーは **Step** だけ移動してから丸めるため、**Step** が **Snap** を下回ると同じグリッド線に留まることがあります。
これらの項目は、行の編集方法だけを変えます。
行を編集しない限り、保存された値とキーフレームは変わりません。
Snap による編集は、グリッド値を確定し、他の編集と同じくキーを記録します。

他の種類から Time sample に変換すると、範囲の指定なしで単位の Step から始まります。
古い Slider の範囲が残るとオフセットが制限されるため、変換時にはこれらの項目を空にします。
Time sample に範囲を付けるには、Apply の前に値を入力します。
**Minimum** または **Maximum** が空の場合、制限を外します。
**Step** が空の場合、単位の既定値に戻ります。Frames は 1、Seconds は 0.01 です。
