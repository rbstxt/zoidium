Text+ はネイティブの 3D Text に 6 つの文字アニメーションモードと **Character Material** 親を追加します。ネイティブの 2D Text では **Character** カテゴリに同じアニメーションモードがあります。


## 2D Character カテゴリ

**Mode** は静的な選択肢です。初期値は **None** です。選択肢は **None**、**Character Transform**、**Gradient Transform**、**Character Shake**、**Selected Character Transform**、**Selected Character Shake**、**Random Scatter** です。

カテゴリは最大 3 つで、**Character**、**Character 2**、**Character 3** です。前のカテゴリまたは自身の Mode が有効な場合に、後続のカテゴリが表示されます。各カテゴリは直前の結果に順番に作用します。

2D では位置と拡大率に X と Y の成分があります。回転はレイヤー平面内の単一の角度です。**Rotation order** と **Axis** はありません。以下の表は 3D の親のコントロールを示します。


## Character Transform

Selected 版は **Characters** を追加します。初期値は `1` です。空欄の選択はどの文字にも作用しません。遅延と位相の順序は選択した文字だけを数えます。

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Characters** | テキスト | テキスト | `1` | 1から始まる文字番号です。空白も数えます。無効な入力は無視します。 |
| **Position** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 文字ごとの位置のオフセットです。 |
| **Scale** | 3D ベクトル | ≥ 0.001 | `[1, 1, 1]` | 文字ごとの拡大率です。 |
| **Rotation** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 文字ごとのオイラー回転です。度単位です。 |
| **Rotation order** | 選択肢 | **XYZ**, **YZX**, **ZXY**, **XZY**, **YXZ**, **ZYX** | **XYZ** | 3つの回転軸の適用順です。 |
| **Pivot** | 選択肢 | **Character**, **Text** | **Character** | 文字またはテキスト全体の回転と拡大縮小の基準点です。 |
| **Delay** | 数値 | ≥ 0 | `0` | 文字間の遅延です。フレーム単位です。 |
| **Delay order** | 選択肢 | **Forward**, **Reverse**, **Center out**, **Random** | **Forward** | 文字に遅延を割り当てる順序です。 |
| **Seed** | 数値 | 明示的な範囲指定なし | `1` | Random の遅延順に使うシードです。 |


## Gradient Transform

中間の文字は First と Last の値を線形に補間します。文字が1つの場合は First の値を使います。

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **First position** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 最初の文字の位置のオフセットです。 |
| **First scale** | 3D ベクトル | ≥ 0.001 | `[1, 1, 1]` | 最初の文字の拡大率です。 |
| **First rotation** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 最初の文字の回転です。度単位です。 |
| **Last position** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 最後の文字の位置のオフセットです。 |
| **Last scale** | 3D ベクトル | ≥ 0.001 | `[1, 1, 1]` | 最後の文字の拡大率です。 |
| **Last rotation** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 最後の文字の回転です。度単位です。 |
| **Rotation order** | 選択肢 | **XYZ**, **YZX**, **ZXY**, **XZY**, **YXZ**, **ZYX** | **XYZ** | 3つの回転軸の適用順です。 |


## Character Shake

Selected 版は **Characters** を追加します。初期値は `1` です。空欄の選択はどの文字にも作用しません。遅延と位相の順序は選択した文字だけを数えます。

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Characters** | テキスト | テキスト | `1` | 1から始まる文字番号です。空白も数えます。無効な入力は無視します。 |
| **Amplitude** | 数値 | 0 ～ 360 | `0` | 角度の変位の最大値です。度単位です。 |
| **Period** | 数値 | ≥ 0 | `24` | Phase の単位で指定する揺れの周期です。 |
| **Phase** | 数値 | 明示的な範囲指定なし | `0` | 揺れの進行量です。Phase が一定の場合は静止した姿勢になります。 |
| **Axis** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 1]` | 文字ごとの回転軸です。 |
| **Pivot** | 選択肢 | **Character**, **Text** | **Character** | 文字またはテキスト全体の回転と拡大縮小の基準点です。 |
| **Phase offset** | 数値 | ≥ 0 | `0` | 文字間の位相のオフセットです。 |
| **Offset order** | 選択肢 | **Forward**, **Reverse**, **Center out**, **Random** | **Forward** | 文字に位相のオフセットを割り当てる順序です。 |
| **Seed** | 数値 | 明示的な範囲指定なし | `1` | Random のオフセット順に使うシードです。 |

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Amount** | 数値 | ≥ 0 | `0` | 元のテキストからシード付きのランダムな変形へ補間します。 |
| **Pivot** | 選択肢 | **Character**, **Text** | **Character** | 文字またはテキスト全体の回転と拡大縮小の基準点です。 |
| **Min position** | 3D ベクトル | 明示的な範囲指定なし | `[-10, -10, -10]` | 文字のランダムな移動量の下限です。 |
| **Max position** | 3D ベクトル | 明示的な範囲指定なし | `[10, 10, 10]` | 文字のランダムな移動量の上限です。 |
| **Min rotation** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 文字のランダムな回転の下限です。度単位です。 |
| **Max rotation** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 文字のランダムな回転の上限です。度単位です。 |
| **Min scale** | 3D ベクトル | ≥ 0.001 | `[1, 1, 1]` | 文字のランダムな拡大率の下限です。 |
| **Max scale** | 3D ベクトル | ≥ 0.001 | `[1, 1, 1]` | 文字のランダムな拡大率の上限です。 |
| **Seed** | 数値 | 明示的な範囲指定なし | `1` | 再現可能な乱数のシードです。 |


## Character Material

**Characters** はテキストで、初期値は空欄です。空欄はすべての文字を選択します。空欄以外では `1,3,4` のような1から始まる文字番号を使います。

**Front material** と **Side material** はマテリアルのスロットです。初期状態では両方とも空です。Front material は両方のキャップに作用します。Side material は押し出しの壁とベベルに作用します。空のスロットは元の Text のマテリアルを使います。

文字を選択している最も近い Character Material 親が両方のスロットを制御します。他のオブジェクト型のマテリアルは変わりません。


## ネイティブの 3D Text への追加

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Horizontal spacing** | 数値 | -200 ～ 200 | `0` | 文字間の追加の水平間隔です。 |
| **Index offset** | 数値 | ≥ 0 | `0` | 共有する文字列内での、この Text の開始位置です。 |
| **Total characters** | 数値 | ≥ 0 | `0` | 遅延とグラデーションの計算に使う文字数です。0 はローカルの文字数を使います。 |
| **Bevel size** | 2D ベクトル | ≥ 0 | `[0.1, 0.5]` | ベベルの厚さと幅です。 |
| **Bevel side** | 選択肢 | **outside**, **inside** | **outside** | 輪郭に対するベベルの方向です。 |
| **Bevel subdivision** | 数値 | 1 ～ 100 | `3` | ベベルの分割数です。 |
| **Cap profile** | 選択肢 | **flat**, **round** | **round** | 平らまたは丸いキャップの形状です。 |
| **Bevel tension** | 数値 | 0 ～ 1 | `0.5` | 丸いベベルの輪郭の曲率です。 |
