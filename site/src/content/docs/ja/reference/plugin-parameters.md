## 範囲、初期値、時間

初期値は新しいコントロールの値です。プリセットと保存済みのプロジェクトは値を変更する場合があります。明示的な範囲指定なしは、プロパティのスキーマに下限も上限もないことを示します。レンダラーが値を制限または丸める場合はあります。

シーケンスのフレームレートの編集は、対応するクリップの境界、キー、時間のコントロールを秒単位で保持します。`frame` に基づく式はフレームごとの意味を保持します。

[タイミングを保ってフレームレートを変更する](/docs/ja/how-to/change-sequence-frame-rate/)
