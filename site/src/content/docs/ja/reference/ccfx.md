CCFX は単体エフェクトを 12 個、グループプリセットを 7 個登録します。単体エフェクトはシェーダーを 1 つ挿入します。グループは保存された子エフェクトの連なりを挿入します。

## 単体エフェクト

| エフェクト | ピッカーのカテゴリ |
| --- | --- |
| **Sunburst V2** | **BACKGROUNDS** |
| **Voronoi Cell Pattern** | **BACKGROUNDS** |
| **Puddle** | **DISTORT** |
| **Skew V2** | **DISTORT** |
| **Warp Waves** | **DISTORT** |
| **Wipe Checker** | **TRANSITIONS** |
| **Wipe Dots** | **TRANSITIONS** |
| **Wipe Rings** | **TRANSITIONS** |
| **Wipe Stripes** | **TRANSITIONS** |
| **CC Light Sweep** | **PART 2** |
| **Lens Flare Lite** | **PART 2** |
| **Plexus V1** | **PART 2** |

## プロパティと範囲

Sunburst V2 には **rotation**、**speed**、**scale**、**center** があります。CC Bend It グループには **Start**、**End**、**Bend** があります。

Sunburst V2 は時間とともにアニメーションします。他のプリセットでは、手動の値や別のタイミングを使う場合があります。パック全体に共通する時間コントロールはありません。
