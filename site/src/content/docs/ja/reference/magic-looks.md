ルックは最大 64 個のツールインスタンスを描画順に連ねます。同じ種類のツールを繰り返せます。移動後も各インスタンスは独自のアニメーションを保ちます。

表はインスタンス `1` の **Parameters** ラベルを示します。他のインスタンスは自分の番号を使います。割合のコントロールは `1` を 100% として表示します。

特に記載がない限り、**Exposure** は段数で明るさを変えます (**Boost** も同様)。**Mix** はツールの結果を合成します。**R/G/B** の行は色ホイールの RGB 成分を示します。HSL の **saturation** と **lightness** の行は名前で示す色相の範囲を調整します。**Size** はフィルターの範囲の広さです。**Show Threshold** はマスク表示を切り替えます。**Threshold** はフレアが付く明るさの下限です。**Reflection** は反射フレアの有無を切り替えます。**Contrast** はコントラストを調整します。**Pivot** はコントラストの中心となる輝度です。**Center X/Y** は領域の位置です。**Radius** は領域の大きさです。**Aspect** は領域の幅と高さの比率です。**Spread** は境界の幅を決めます。**Falloff** は減衰の形を決めます。

エフェクト全体の **Enabled** の選択肢は **off** と **on** で、初期値は **on** です。Off はルック全体を無効にします。


## チェーンとプリセット

**On**、**Off**、**Duplicate**、**Remove**、**Move up**、**Move down** は選択したインスタンスを編集します。Duplicate はインスタンスをコピーします。**Look** のプリセットはチェーンの設定を置き換えます。**Clear look** はチェーンを保持して設定をリセットします。
