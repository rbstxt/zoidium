Trapcode Particular はデザイナーとプロパティパネルにネイティブのプロパティを持つスイートのオブジェクトです。表はスキーマの初期値を示します。プリセットとピッカーの項目が初期値を変更する場合があります。


## Emitter

| コントロール | 型 | 範囲または選択肢 | 初期値 | 出力への影響 |
| --- | --- | --- | --- | --- |
| **Emitter type** | 選択肢 | **point**, **box**, **sphere** | **point** | 点、ボックス、または球から放出します。 |
| **Emitter behavior** | 選択肢 | **continuous**, **explode**, **burst** | **continuous** | 連続放出、1回の爆発、または繰り返すバーストです。 |
| **Emit from parent** | 選択肢 | **off**, **on** | **off** | 選択した親のシステムのパーティクルから放出します。 |
| **Parent system index** | 数値 | ≥ 0 | `0` | 0から始まる親のシステムのインデックスです。 |
| **Inherit parent velocity[%]** | 数値 | 0 ～ 100 | `0` | 発生時に継承する親の速度の割合です。 |
| **Particles/sec are % of primary** | 選択肢 | **off**, **on** | **off** | 放出率を主システムに対する割合として解釈します。 |
| **Burst interval** | 数値 | ≥ 0.05 | `1` | バースト間の秒数です。 |
| **Particles/sec** | 数値 | ≥ 0 | `100` | 1秒あたりの放出数です。 |
| **Burst count** | 数値 | ≥ 0 | `0` | バーストで放出するパーティクル数です。 |
| **Position** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | シーンの単位で指定する位置です。 |
| **Emitter size** | 数値 | ≥ 0 | `100` | 放出元の大きさです。 |
| **Direction** | 3D ベクトル | 明示的な範囲指定なし | `[0, 0, 0]` | 初速度の方向です。 |
| **Direction spread** | 数値 | ≥ 0 | `20` | 初期の方向の周囲への広がりです。 |
| **Velocity** | 数値 | 明示的な範囲指定なし | `100` | パーティクルの初速度です。 |
| **Velocity random** | 数値 | 0 ～ 100 | `20` | 初速度の変動の割合です。 |
| **Velocity distribution** | 数値 | 0 ～ 1 | `0.5` | 0.5未満では初速度の変動を遅い側へ、0.5超では速い側へ偏らせます。Velocity random が必要です。0.5では従来の広がりを保ちます。 |
| **Velocity from emitter motion** | 数値 | 0 ～ 100 | `0` | 放出元の移動から加える速度です。 |
| **Rotation** | 数値 | 明示的な範囲指定なし | `0` | 度単位の回転です。 |
| **Rotation random** | 数値 | ≥ 0 | `0` | スプライトの初期の角度の変動量です。 |
| **Rotation speed** | 数値 | 明示的な範囲指定なし | `0` | スプライトの初期の回転速度です。 |
| **Rotation speed random** | 数値 | ≥ 0 | `0` | スプライトの回転速度の変動量です。 |
| **Random seed** | 数値 | 明示的な範囲指定なし | `100000` | 再現可能な乱数のシードです。 |


## Particle

| **Life (seconds)** | 数値 | ≥ 0.01 | `3` | パーティクルの寿命です。秒単位です。CPU シミュレーションの上限は30秒です。 |
| **Life random** | 数値 | 0 ～ 100 | `0` | 寿命の変動の割合です。 |

| **Random rotation** | 数値 | 0 ～ 100 | `0` | 初期の回転の変動量です。 |

| **Opacity** | 数値 | 0 ～ 100 | `100` | パーティクルの不透明度です。割合で指定します。 |
| **Opacity random** | 数値 | 0 ～ 100 | `0` | シードに基づいて各パーティクルの不透明度を下げます。100では倍率が0から1の範囲になります。 |
| **Opacity over life** | 選択肢 | **off**, **on** | **off** | 正規化した寿命に対して Opacity curve を有効にします。 |
| **Opacity curve** | カーブ | 編集可能なストップ | 白 | 正規化した寿命に対する不透明度の倍率です。 |
| **Color** | RGB カラー | 0 ～ 1 | `[1, 1, 1]` | 基準の RGB カラーです。 |
| **Color over life** | グラデーション | 編集可能なストップ | 白 | 正規化した寿命に対して使うグラデーションです。 |
| **Color random** | 数値 | 0 ～ 100 | `0` | グラデーションと Color の積に、シードに基づく RGB カラーを混ぜます。アルファ値は保ちます。 |
| **Blend mode** | 選択肢 | **normal**, **add**, **screen**, **multiply** | **normal** | パーティクルの合成方法です。 |
| **Glow** | 数値 | ≥ 0 | `0` | パーティクルの明るさの倍率への寄与量です。 |
| **Random seed** | 数値 | 明示的な範囲指定なし | `0` | 再現可能な乱数のシードです。 |

## 保存する非表示の値

次のプロパティはプロジェクトに保存しますが、編集用のコントロールは表示しません。読み込みと保存で値を保ちます。

| プロパティ | 維持する動作 |
| --- | --- |
| Particle type | すべての値でテクスチャ付きのスプライトを描画します。 |
| Set color | グラデーションは常にパーティクルの寿命に従います。保存する初期値は at start ですが、この値による動作の切り替えはありませんでした。 |
| Enable flocking | 保存した on の値は CPU の評価を選びます。群れの力は加えません。 |
| Attract, Separate, Align, Range of view, Field of view | 力を加えません。 |
| Emitter type: light, layer, model, text | 保存したインデックス3から6では点から放出します。 |
| Disperse strength over: velocity, position | 保存したインデックス2と3では強度を一定にします。 |


## 評価と制限

CPU シミュレーションは固定の1/60秒の格子を使います。時刻の上限は600秒、寿命の上限は30秒です。各システムは新しいものから最大20,000個の生存中のパーティクルを保持します。親からの放出の深さの上限は2です。

音声解析はデコードしたアセットと明示的なメディアの時刻を使います。オフセットとトリムは秒単位です。同じ対象のリアクターは変調を乗算します。デコード待ちの解析レベルは中立の0.5です。音声の区間外では0です。
