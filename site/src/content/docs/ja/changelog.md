## 未リリース (ベータ)

最新の安定版リリース以降の新規追加と変更です。各項目は、目に見える変更を 1 行で説明します。

### 追加

- 組み込みフォントを追加しました。Geist、Geist Mono、Geist Pixel (Circle、Grid、Line、Square、Triangle)、Geist Serif (Square、Triangle、Heart の各スタイルを含む)、Inter、Paper Mono を、すべてのフォント選択欄で使用できます。Geist、Geist Mono、Inter は可変フォントのため、Shape+ Text ではフォントを読み込まずにウェイトをアニメーションできます。
- フォント選択欄のプレビュー画像を、フォント一覧から生成するようにしました。追加した組み込みフォントも、それぞれの書体で表示されます。
- Shape+ Text。Shape+ のコンテンツに置く、打ち直せるテキスト項目です。Fill、Stroke、グラデーション、パス修飾、Repeater、Merge Paths が、ほかのパスと同じように文字に効きます。Source Text、フォント、Fallback Font、サイズ、トラッキング、行送り、ベースラインシフト、比率、大文字、揃え、折り返し付きのボックステキストをアニメーションできます。プレビューでテキストをダブルクリックすると編集できます。
- Shape+ Text の可変フォント対応。フォントの各軸 (太さ、幅など) をアニメーションできるプロパティとして使用でき、**Style** でフォントの名前付きスタイルを適用できます。TTF、OTF、WOFF のフォントを使用できます。WOFF2 には未対応形式の通知を表示します。
- Shape+ の Text Animator。テキスト項目の下に置くと、選んだ文字を移動、拡大縮小、回転、傾斜、トラッキング、文字のずらしで動かし、可変フォントの軸を文字ごとにずらします。Range Selector (形、イーズ、モード、ランダム化) と、任意で追加する Wiggly Selector が、文字、単語、行の単位で対象を選びます。テキストの右クリックメニューから追加します。
- Shape+ の **Create Shapes from Text**。テキスト項目を、1 文字ずつのグループに分かれた編集できるパスに変換します。変換前のテキストと同じピクセルで描画します。
- Graph Editor 2 は、エクスプレッションの出力を編集できない破線の曲線で表示します。すべてのイージングプリセットを実際の形で描き、Custom easings で各プリセットの形をプレビューします。
- Graph Editor 2 は、ベクトルと色のプロパティを 1 行にまとめ、その下に X、Y、Z (または R、G、B、A) の行を表示します。軸ごとに表示、ソロ、編集ができます。**Link axes** は、ほかの軸の同じフレームのキーを時間方向に一緒に動かします。
- DaviFX による ExpressText+。3D Text の上に置くコンテナーで、Shake、Plain、Random、Formula、Delay、Spline、Orbit、Repeater、Twist、Wrap、Voronoi のエフェクターで文字を 1 つずつ動かします。
- After Effects 形式の Assets パネル。すべてのファイル、フォント、画像、モデル、コンポジションを 1 か所に集め、使用状況、見つからない項目、失敗した項目をバッジで示します。
- アセットコマンド。Import、Delete、Remove Unused Items、Replace、Reload、Relink、Resolve Fonts、Export を使用できます。
- ドラッグアンドドロップ対応のアセットフォルダーとラベル。Collect Files と Consolidate All Footage も使用できます。
- Assets の項目をアニメーション付きプロパティにドロップすると、そのプロパティにキーを設定します。
- Shape+ のベクトル編集。グループ化したパスキー、キャンバスツールを備えた Shape Editor、ジェスチャー履歴、ロスレスなトポロジーを使用できます。
- Shape+ のペイントとプロシージャルジオメトリ。ストローク、変形、ウィグル、オフセット、クリッピング、ネイティブ変換、SVG 貼り付けを使用できます。
- Expressions+。モダンなエクスプレッション、Sequence Controls、Graph Editor 2 での作成、同一フレームのワールドサンプリング、カメラヘルパー、シェーダーバインディングを使用できます。
- Shader+。テクスチャ種別 (ランプ、カーブ、テキスト)、ネイティブプロパティサイドバー内のエディター、フォント準備を使用できます。
- シェーダー作成ツール。確認済みテンプレート、独立した下書きチェック、補完、ヘルプ、検索、ローカル履歴、JSON 書き出しを使用できます。
- Node Effect グラフ。検証、ネイティブパラメーターのアニメーション、スターターレシピを使用できます。
- Node Material カタログ。ランプエディターとカーブエディター、サーフェストラック、レシピを使用できます。
- Constraints。Track To コンストレイントと依存関係の循環チェックを使用できます。
- Motion Paths ビューポートプラグイン。キーのドラッグ編集を使用できます。
- Theme Editor。パレット、取り消し、従来の Custom プロファイル同期を使用できます。
- ネイティブ MP4 書き出し。ストリーミングエンコード、品質管理、エラー回復を使用できます。
- Smart Motion Blur。オプティカルフローとシャッターサンプルの再構成、動きの診断表示を使用できます。
- Text+ のネイティブ 2D 文字アニメーション、面ごとの文字マテリアル、3 層の文字カテゴリを使用できます。
- Centered エディターレイアウト (Clipmaker 3 Centered、Video Editor 2 Centered、Video Editor 2 Centered 2)。パネル用の 2 つ目のサイドバーを備えます。
- Centered レイアウトでは、パネルタブを右クリックしてサイドバー内またはサイドバー間で移動できます。配置はエディター設定と共に記憶されます。
- エフェクトピッカーをカテゴリ別にグループ化し、件数と最近使用したエフェクトを表示します。
- エディターの外装とポップアップメニューがアクティブなテーマに従います。
- デバイスレンダーオプションに Export Bitrate 倍率を追加しました。
- 他のレイヤーのフレームを入力として読み取るエフェクトソースを使用できます。
- Particular Displace Spin のシード付き円軌道と、共有 Twist ピボットを使用できます。
- 開発者向けプレビュー（既定ではオフ）: ローカルのコミュニティエフェクトパッケージ（検証済みコントロール付き）、ローカルのパッケージ保存、他のフレームのローカル限定サンプリング、パッケージがなくても失われないプロジェクトのデータ。デスクトップ版では、パッケージがアプリのデータフォルダーに保存され、パッケージごとに分離されたセッションで実行されます。一般向けの機能ではありません。

### 変更

- Shape+ Text は、可変フォントの軸を "Weight (wght)" のような正式名で表示し、**Style** のすぐ下に並べます。静的フォントでは、行に "Static font: no variable axes" と表示します。
- Shape+ を高速化しました。塗りの三角形分割が最大で約 10 倍速くなり、Shape Editor はポインターの下を調べるときに遠い曲線を飛ばします。Wiggly Selector のない Text Animator は、毎フレームのテキストの作り直しをしなくなりました。出力は変わりません。
- Graph Editor 2 はマウスとトラックパッドの両方で操作できます。マウスホイールはポインターの位置を中心に時間方向をズームします。2 本指スクロールでパン、ピンチか Ctrl+ホイールで縦横にズームします。中ボタンのドラッグか Space+ドラッグでもパンできます。**?** ボタンを押すと操作の一覧が出ます。
- Graph Editor 2 のベジェハンドルをつかみやすくし、短いハンドルも見えるようにしました。Alt で接線を分割または再結合します。ドラッグの途中で押しても効きます。Shift で 45° 単位に、Ctrl か Cmd で水平または隣のキーの傾きに合わせます。ダブルクリックでハンドルをリセットします。プリセットのイージングのハンドルをドラッグすると、ベジェに変わります。
- Graph Editor 2 のツールバーを用途別にまとめ、横に広いウィンドウでは 1 行に収めました。使えないボタンは無効になり、ステータスバーにはポインターの下にあるものを表示します。軸の色はビューポートのギズモと同じ赤・緑・青にしました。複数の軸を選んで値をドラッグすると、どの軸も同じ量だけ動きます。
- Optical Flow を使う Smart Motion Blur で、不要な GPU の処理を省きました（1/8 品質で GPU 時間が約 6〜12% 減ります）。出力は変わりません。
- Shape+ のブーリアン演算、オフセット、ストロークの処理が速くなりました（ブーリアンの交差は約2倍）。生成される形は変わりません。
- 既存プロジェクトの見た目の変更。他のフレームを読み込むエフェクトで、柔らかい部分や半透明の部分（パーティクル、文字の縁、フェード中のレイヤー）が暗くならなくなりました。対象は Echo、CC Wide Time、Time Difference、Time Displacement、Optical Flow を使う Smart Motion Blur、Echo (Legacy)、VHS、Datamosh です。不透明な映像の描画は変わりません。
- 既存プロジェクトの見た目の変更。Trapcode Particular で、Velocity distribution、Aspect ratio、Opacity random、Color random、Air density、Drift X/Y/Z、Disperse strength over（life）とそのカーブ、Turbulence field affect size と affect opacity が描画に反映されます。これらは以前は効果がありませんでした。既定値のままのプロジェクトの描画は変わりません。
- Trapcode Particular で、効果のないコントロールを非表示にしました。対象は Particle type、Set color、flocking のコントロール、Emitter type の light/layer/model/text、Disperse strength over の velocity/position です。保存された値は残ります。Bounce height の名前は Bounce boost になりました。
- 既存プロジェクトの見た目の変更。3D Scene レイヤーでは、Smart Motion Blur の Automatic が Shutter Samples を使用し、それ以外では Optical Flow を使用します。Reconstruction の保存値がないプロジェクトは Automatic を使用します。3D Scene でフローベースのブラーを維持するには、Optical Flow を選択します。
- 既存プロジェクトの見た目の変更。Trapcode Particular と Form のシェーディングは、アンビエントライトとヘミスフィアライトを 2 回ではなく 1 回だけ半分の強さで適用するため、ライトが当たるパーティクルが明るく表示されます。
- 既存プロジェクトの見た目の変更。Drop Shadow は、保存された 0 の値を既定値で置き換えず、そのまま表示します。
- タイミング。シーケンスのフレームレートを変更しても、クリップとアニメーションのタイミングが秒単位で維持されます。Undo と Redo、小数位置の通知を備えます。
- プレビューキャッシュにセッションのメモリー上限、GPU 失敗時の処理、Settings での使用量のライブ表示を追加しました。
- Magic Looks にインスタンスモデル、セットアップウィンドウ、狭いレイアウト、キーボード操作、ルック保持を追加しました。
- エクスプレッション、コンストレイント、Motion Paths、Native FX、プロジェクトスキャナーの待機時と書き出し準備時のコストを削減しました。

### 修正

- 動画に Time Offset を掛け、`shake()` エクスプレッションなどでオフセットが飛ぶと、黒い画面や無関係なフレームが出る問題を直しました。再生中に再生ヘッドが逆戻りする問題も直しました。
- WebM クリップが、プレビューと書き出しのどちらでも、すべてのフレームの境目で正しいフレームを表示するようにしました。これまでは WebM が時刻をミリ秒単位でしか持たないため、1 つ前のフレームが出ることがありました。フレームレートが一定の WebM クリップの書き出し結果は、該当する箇所で元動画の 1 フレーム分変わることがあります。MP4 クリップは変わりません。
- Graph Editor 2 の曲線は、極端にズームしてもにじまなくなりました。キーの微調整や接線の変更を取り消すと、正確な値に戻ります。多数のキーを動かしてもグラフが遅くならず、削除したレイヤーの曲線が残らなくなりました。
- Voronoi Fracture は、複数の破片を同時に作り、結果が変わらない処理を省くようになりました。最初の割れたフレームや Cells・Seed の変更が、同じ結果のまま約 3〜5 倍早く表示されます。
- Collect Files は、ファイルとフォルダーが同じ名前になる ZIP を作らなくなりました。このような ZIP は、展開ツールによっては開けませんでした。
- Effector の準備中にシーンを削除しても、Fracture のデータがメモリに残らなくなりました。
- Shape Editor でドラッグしている途中に別のプロジェクトを開いても、そのドラッグが新しいプロジェクトの取り消し履歴に入らなくなりました。
- Voronoi Fracture の再生が再び滑らかになりました。破片がすでに作られているフレームは裏側の順番待ちをせずにその場で計算するため、再生中に同じ画像のまま止まらなくなりました。
- 割れた破片は、シェーダーを作り直す Node Material のグラフに追従します。割れた Text+ の Character Material のテキストは、UV を作り直し続けなくなりました。1 つのマテリアルを使う割れたメッシュは、割れる前と同じ Material+ の UV 配置を使います。
- Material+ は、奥行きのある押し出しの UV 配置をずっと速く計算します。結果は変わりません。
- ExpressText+ の Orbit と Spline は、フレームを最初に描いたときも、その後に描いたときも同じ結果になります。
- ExpressText+ の文字は、入れ子の Group の移動を 1 回だけ受け、別の Group へ移した Text に付いて動き、ExpressText+ から外したり無効にしたりしても最新の文字を保ちます。
- ExpressText+ の Formula と Shake は、シーケンスのフレームレートで秒を数えます。30fps のプロジェクトは見た目が変わりません。それ以外のフレームレートでは速さが変わります。
- シーケンスのフレームレートを変えると、ExpressText+ のフレーム単位の遅延も換算され、時間差の長さが秒で保たれます。
- Voronoi Fracture は破片を裏側で計算します。新しいフレームの準備ができるまで、エディターを止めずに直前の正確な画像を残し、「Fracturing...」と表示します。
- Fragment scale を 0 にすると、Randomness を使っていても、効果が完全にかかる破片はすべて大きさ 0 になります。Fragment scale と Randomness を組み合わせたプロジェクトでは、破片の大きさが変わります。
- 割れた破片は、面ごとのマテリアルを保ち、元のマテリアルのシェーダー値、テクスチャ、色の変更に後から追従します。
- 重なった破片を決まった順番で描くため、同じフレームは毎回同じ見た目になります。重なりの境目で数ピクセル変わることがあります。
- プロジェクトの保存中にページを閉じたり再読み込みしたりすると、確認が表示されます。保存が終わるまで「Saving...」の通知が表示されます。新しく選んだファイルへの保存に失敗した場合は、そのファイルが空になっている可能性があることをメッセージで伝えます。
- 空のプロジェクトファイルを開くと、保存が途中で止まった可能性があることを説明し、Restore points パネルを案内します。
- Effector のプレビューは、書き出しと同じく、常にそのフレームの正確な結果を表示します。重い Fracture では、前のフレームや割れていない形を表示する代わりに、再生が遅くなることがあります。
- Voronoi Fracture が、より大きなメッシュと断面の輪郭を扱えるようになりました。ベベル付きの 3D テキストも、断面を閉じた破片で割れます。
- Voronoi Fracture で閉じた破片は、元のマテリアルの面の表裏の設定を保ちます。止まっている破片は、割る前のオブジェクトと同じ陰影になります。
- Text+ の文字は、最初のフレームから Material+ のテクスチャの配置を使います。後の更新でテクスチャの見え方が変わらなくなりました。
- Voronoi Fracture を使う Effector で、再生中に「offset is out of bounds」のエラーが出てプレビューが止まる問題を修正しました。
- 画像テクスチャと Image レイヤーの画質を上げました。辺の長さが 2 の累乗でない画像は、もっとも近い 2 の累乗の大きさへ滑らかに変換してから使います。1920 ピクセルの画像は、1024 ではなく 2048 ピクセルで使われます。
- 入れ子のグループを持つプロパティグループを追加して取り消したあと、やり直すとエラーになる問題を修正しました。
- Shape+ の Offset Paths が開いたパスでも使えるようになりました。パスの両側を囲む輪郭を作ります。以前は、後に続くストロークが何も描きませんでした。
- 29.97 fps の映像で、プレビューキャッシュが一部のフレームで映像の準備を止めてしまう問題を修正しました。
- 一時停止中は、映像が表示されているプロジェクトでも、プレビューキャッシュが前方 30 フレームと後方 4 フレームまでを同じ正確なデコードで準備します。操作があるとすぐに中止します。
- 映像が表示されているプロジェクトでも、プレビューキャッシュが一時停止中のフレームを保存するようになりました。エディターの操作が少し止まると、Zoidium はそのフレームを正確にデコードしてキャッシュします。再生中のフレームは今までどおりその場で描画します。映像のフレームをキャッシュしない場合は、Settings にそのことが表示されます。
- プレビューキャッシュがフレームの準備に使う内部のコピーを、使い終わったら解放するようになりました。以前はメモリに残っていました。
- 下に不透明なものがない Adjustment レイヤーの Smart Motion Blur で、ブラーがかかるようになりました。以前は Optical Flow（Adjustment レイヤーでは Automatic も使用）がすべてのフレームをシーンの切り替わりと判定し、ブレのない画像を返していました。このような Adjustment レイヤーで他のフレームを読み込むエフェクトも、現在のフレームと同じ不透明な黒の背景を受け取ります。
- 使っていない無効なプラグインのダウンロードに失敗していても、プレビューキャッシュが働くようになりました。動画を含むプロジェクトでも、近くに動画がないフレームは事前に描画します。
- Trapcode Particular で、Air density が 1 以外のときに、アニメーションさせた Air resistance が 0 になっても粒子が飛ばなくなりました。
- Native FX、Text+、Effector、Trapcode、Optical Flares、CCFX パックを使うプロジェクトで、プレビューキャッシュが再び働くようになりました。承認済みの一覧がプラグインのバージョンに追いついていなかったため、これらのプロジェクトはキャッシュされていませんでした。承認したプラグインはすべて、キャッシュしたフレームとその場で描画したフレームが1バイトも違わないことを確かめています。
- プレビューキャッシュがフレームを保存しないとき、Settings にその理由（「Not caching:」に続く説明）を表示します。メモリー警告は Mac 専用の表現ではなくなりました。
- Smart Motion Blur の Shutter Samples で、パーティクルのような柔らかい部分や半透明の部分が暗くならなくなりました。以前は、サンプルを取り込むときにアルファを2回掛けていました。不透明な部分、Optical Flow、他のエフェクトの出力は変わりません。
- Zoidium のグラデーションエディターを使っているときに、マテリアルのパネルが空にならなくなりました。以前は、パネルを開いたまま PBR+ マテリアルを追加すると、マテリアルの読み込みが止まることがありました。その場合、見出しが「undefined」になり、値が空になりました。カスタムコントロールでエラーが起きたときは、パネルを止めずに標準のコントロールを表示します。
- UV Custom Material で **Wrap** を **none** にして保存したプロジェクトは、開き直しても **none** のままです。以前は、開き直すとテクスチャがタイル状に繰り返されました。
- デタッチされたテンポラルエフェクトを安全にスキップし、datamosh 書き出しのカット位置を維持します。カットのないカット限定書き出しも正常に動作します。
- フレーム取得で JPEG をエンコードし、フレーム書き出しの失敗から回復します。
- Trapcode のデコード済みオーディオは再生中も利用できるよう保持し、デコード済みレコードがソース再読み込み後も残ります。
- Shape+ レイヤーは削除、プレビュー、クリーンアップ中も安全に保たれ、Shader+ の非同期読み込みと Material+ の UV 状態は削除後も復旧します。
- 古い Shader+ フォント読み込みとデタッチされた Shape+ 変換を拒否またはロールバックします。
- セットアップ対象のプロジェクトがライブツリーから外れると、セットアップウィンドウを閉じます。
- プロジェクトの置き換え後にネイティブエフェクトが残らず、保留中のフィルター読み込みを取り消します。
- キュー内のエンコード要求は、ネイティブエンコード開始前に取り消せます。
- Effector の準備はオブジェクト削除後に回復し、遅延 LUT 読み込みはプロジェクトと共にクリーンアップされ、起動に失敗した場合は Web ステージをクリーンアップします。
- MP4 書き出しのクリーンアップ失敗は致命的になりません。
- Smart Motion Blur は、完全透明なテクセルと変位制限外の候補をスキップします。
- 書き出しに失敗してもシャッタークロックは正確に保たれ、プロシージャルフォールバックを使い、プレビューは取り消し後も残ります。
- 書き出し中のコンテキスト喪失では、破損フレームを作らず速やかに失敗します。
- Camera+ は登録済みトラックフィールドを復元し、共有カメラの検索更新を削減します。
