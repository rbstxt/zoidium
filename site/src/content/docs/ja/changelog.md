## 未リリース (ベータ)

最新の安定版リリース以降の新規追加と変更です。各項目は、目に見える変更を 1 行で説明します。

### 追加

- 2 つの映像トラック（または 2 つの音声トラック）の境目にクリップを落とすと、そこに新しいトラックを挿入できるようにしました。挿入位置に線が出て、ほかのクリップは上書きされず、1 回の Undo で元に戻ります。行の真ん中に落としたときは、これまでどおり上書きします。
- Player+ の品質メニューに、低品質プレビューの拡大方法を選ぶ **Upscale**（**Smooth** / **Sharp**）と、**Exact effects (full-resolution layers)** を追加しました。Exact effects はレイヤーとエフェクトをシーケンス解像度で描き、ビューアーだけを縮小するので、ピクセルを正確に読むシェーダーもどのプレビュー品質でも同じ見た目になります。どちらも既定はオフで、書き出しには影響しません。
- Effector に **Radial Repeater**（半径、平面、開始角度、角度の範囲を指定して円の上に並べ、外向きにそろえることもできる）と **Grid Repeater**（軸ごとの個数と間隔を指定して 3D の格子に並べる）を追加しました。Repeater を選んでいる間は、編集画面で各コピーの位置を点で示します。点はレンダーや書き出しには出ません。
- Effector に、Twist と Warp と並んで **Shear** を追加しました。メッシュを 1 つの軸に沿って斜めにずらします。フィールドと Delay も Twist と同じように効きます。
- Video と Single Color のマテリアルに **Render side**（表、裏、両面）を追加しました。球の内側に動画を映すときなどに使えます。既存のプロジェクトの見た目は変わりません。
- MP4 の書き出し中の画面に、直前に書き出し終えたフレームと、進み具合（割合、フレーム数、経過時間、残り時間の目安）を表示するようにしました。**Show preview** でオフにできます。どちらでも書き出されるファイルは同じです。
- Shape+ のグループに、見出しの **+** から独自のプロパティ（Slider、Toggle、Angle、Point、Color、Dropdown）を追加できるようにしました。ほかのプロパティと同じようにアニメーションでき、Expressions+ からどのレイヤーでも読み取れます。
- Player+ に **FPS meter** を追加しました（既定はオフ）。再生中のフレームレートをビューアーに表示し、リアルタイムに間に合わないと赤くなります。タイムラインには、プレビューキャッシュにあるフレームを示す緑のバーを表示します。
- 音声だけを書き出せるようにしました。**.wav**（16 bit PCM、48 kHz ステレオ）と **.m4a**（AAC。AAC が使えない環境では WAV を案内します）を選べます。MP4 の書き出しと同じミックスを使い、ミュート、音声のソロ、Precomp+ の音声も反映します。映像のフレームは描画しません。
- Shader+ のドキュメントに、Path プロパティで物をパスに沿わせる方法（`Points`）と、マスクとして使う方法（`Coverage`）の違いを追加しました。光と動く粒子の作例があります。
- 書き出しに **Transparent background** オプションを追加しました。PNG、WebP、WebM/MKV（アルファ付き VP8）で使え、透明や半透明のピクセルのアルファが書き出したファイルに残ります。既定はオフで、MP4 と JPEG では表示されません。
- タイムラインに **Render Time** 列を追加しました（既定はオフ）。直前のプレビューのフレームで各トラックとエフェクトの描画にかかった時間を、1 フレームの持ち時間と比べて色分けして表示するので、重いレイヤーがすぐ分かります。隠している間は何も計測しません。
- タイムラインのトラックに **Solo** と **Lock** のスイッチを追加しました。Solo にしたトラックだけがプレビューと書き出しに描かれ、Lock したトラックのクリップは編集できなくなります。表示、Solo、Lock のスイッチをドラッグすると、複数のトラックを undo 1 回分でまとめて切り替えられます。
- Player+ に **Show transparency grid** スイッチを追加しました。プレビューの透明な部分をチェッカー柄で表示します。書き出しには影響しません。
- Scene レイヤーに **Scene Backdrop** の設定を追加しました。**Transparent**（既定）か、**Backdrop Color** と **Backdrop Opacity** を使う **Solid Color** を選べます。
- Player+ にプレビュー品質の **Adaptive** スイッチを追加しました。再生中に描画が追いつかないとプレビュー品質を 1 段ずつ下げ（**Lowest** より下には下げません）、一時停止すると選んでいた品質に戻します。書き出しには影響しません。
- マスクと Shape+ のパスを、同じパス編集の仕組みで扱えるようになりました。Q（または P）がペンです。最初のクリックで、Scene か調整レイヤーを選んでいればマスク、Shape+ レイヤーを選んでいればパス、どちらでもなければ新しい Shape+ レイヤーを作ります。V で範囲選択と Shift による頂点の選択、ペン中に Ctrl/Cmd を押すと一時的に選択、Alt でハンドルの分割・変換ができます。Esc でパスを確定（もう一度押すと選択を解除）し、Enter は不要になりました。マスク名、Shape+ のパス、プレビュー上の輪郭をクリックすると編集が始まり、同じ場所を続けてクリックすると重なったパスを順に選びます。
- マスクの行を作り直しました。名前の変更、合成モード、反転、キーフレームの菱形、Edit、削除に加えて、開くと Feather、Opacity、Expansion（-128〜128 px）、枠線の色、ロック、複製、上下の並べ替えがあります。ロックしたマスクは形・キー・削除を変えられませんが、並べ替えはできます。Shift を押しながら名前をクリックすると、複数のマスクをまとめて編集できます。
- パスの編集をより正確にしました。ズームやレイヤーの変形に関係なく画面上 9 px 以内で頂点と線を拾い、ペンのカーソルがクリックの結果（閉じる・続ける・削除・追加）を表示します。選んだ頂点をまとめて移動・拡大縮小・回転でき、線をそのままドラッグして曲げられ、ほかの頂点・画面の端・軸にスナップします。Space を押しながらドラッグで画面の移動、ホイールでズーム、右クリックで Set First Vertex が使えます。頂点とハンドルの大きさは変えられます。
- マスクと Shape+ のパスのキーフレームが、タイムライン（Masks > 名前 > Mask Path）に菱形で表示されるようになりました。アニメーション中のパスを編集すると、その時点にキーを打ちます。頂点を足したり消したりしてもキーの間のアニメーションは保たれ、保証できない場合は理由を示して断ります。パスのコピー＆ペーストと、アニメーションを保ったままのマスク ⇄ Shape+ の変換ができます。
- ExpressText+ に Letters の設定を追加しました。Per text では、コンテナ内の各テキストを別々の文字の組として扱います。各テキストに同じ設定のコンテナを 1 つずつ付けたのと同じ結果になります。Across texts は今までどおり、すべてのテキストを通して文字に番号を振ります。新しく作るコンテナは Per text で始まり、既存のプロジェクトは Across texts で開くので見た目は変わりません。
- 3D Text の行に Split into letters を追加しました。テキストを、同じ位置に 1 文字ずつの Text を並べたグループに置き換えます。位置・回転・拡大縮小のキーフレームとエクスプレッションはグループに移ります。undo 1 回で元に戻ります。
- エフェクトの見出しに目のボタンを追加しました。エフェクトを消さずにオフにできます。オフにしたエフェクトはプレビューでも書き出しでも何もしません。時間系のエフェクト、エフェクトグループ（中のエフェクトもまとめて）、Layer Input が参照するエフェクトも同じです。設定、キーフレーム、Enabled の値はそのまま残ります。状態はプロジェクトに保存され、undo できます。既存のプロジェクトは、すべてのエフェクトがオンの状態で読み込まれます。
- タイムライン左上の現在時刻をクリックすると、フレーム番号かタイムコードを入力して Enter でその位置へ移動できるようになりました。Esc で取り消します。右クリックで切り替わる 3 つの表示形式のどれでも入力できます。
- Smart Motion Blur にキーフレームを打てる Enabled スイッチを追加し、エフェクトを消さずにオフにできるようになりました。既存のプロジェクトは Enabled がオンの状態で読み込まれます。
- Ctrl/Cmd+V で、クリップボードの画像・動画・音声を Project media に貼り付けられるようになりました。タイムラインを選んでいるときは再生位置にクリップを置きます。
- Native FX に Time Remap エフェクトを追加しました（調整レイヤーとクリップで使えます）。Speed モードはキーフレームできる Speed（%）で速度を変え、0 で静止、マイナスで逆再生します。Remap モードは Source time を直接指定し、値を固定すればフリーズフレーム、Easing+ のカーブでスピードランプになります。Frame mix は時刻がフレームの間に来たとき、近い 2 フレームを混ぜます。
- 寄稿された 2 つのエフェクトを追加しました（どちらも Zoidium 専用）。ZSMB（beta 1.0）はオプティカルフローによるモーションブラーで、Full と 1/2 の品質、Blur Amount、Motion Sensitivity、前後どちらのフレームを追うかを選べます。S_Glow（beta 1.0）は広がり・ブレンドモード・境界の拡張・大気表現を調整できるグローです。Plugins パネルで有効にします。
- Easing+ でカーブをコピー＆ペーストできるようになりました。カーブのウィンドウの Copy と Paste、またはウィンドウを選んだ状態で Ctrl/Cmd+C と Ctrl/Cmd+V を使います。貼り付けは `cubic-bezier(x1, y1, x2, y2)`、数字 4 つ、JSON の配列を受け付けます。
- Shader+ のカスタムプロパティに Rename when を追加しました。選んだプロパティの値が条件に合う間、別の名前を表示します。条件は Visible when と同じ書き方です。変わるのは表示名だけで、値やキーフレーム、シェーダーは変わりません。
- ライトのプロパティに Cast shadows のスイッチを追加しました。影が要らないライトでオフにすると、そのライトの影の計算がなくなります。影付きの点光源では、これが負荷の大部分です。スポット、ポイント、ディレクショナルと、Trapcode の Spot、Point、Infinite、Sun はオン、Trapcode の Area、Portal、IES はオフで始まるため、既存のプロジェクトの見た目は変わりません。このスイッチにはキーフレームを打てません。
- Scene と Adjustment のレイヤーに、Mask ペン（ツールバーの Q）でマスクを描けるようになりました。Add・Subtract・Intersect のモード、Feather、Opacity、Invert があり、パスはキーフレームで動かせます。Adjustment レイヤーでは、エフェクトがマスクの内側だけにかかります。マスクはレイヤーの Properties の Masks に並びます。
- Shader+ のカスタムプロパティに Path 型を追加しました。レイヤーのマスクや Shape+ のパスを読み、内側の範囲、パスに沿った 256 個の点、長さ、点の数をシェーダーに渡すので、パスに沿ったエフェクトが作れます。
- 3D オブジェクト（シェイプ、テキスト、ライト、パーティクル、モデル、Particular、Form、Plexus などのパックのオブジェクト）に、キーフレームを打てる Enabled を追加しました。オフの間は描画せず、影も光も出さず、計算も飛ばすので、重いオブジェクトもオフの間は時間を使いません。カメラにはまだありません。
- Scene を含むコンポジションのクリップのメニューに Edit 3D in comp を追加しました。コンポジションを開き、Scene を選んで 3D ビューにします。Comps の Back from 3D edit で元のコンポジションに戻ります。
- Shader properties の Slider、Seed、Angle、Time sample に Snap を追加しました。ドラッグ、矢印キー、入力した値が Snap の倍数（例: 0.00、0.50、1.00）にそろいます。空欄なら今までと同じです。
- Shader properties のグループに Visible when を追加しました。グループに所属する行のメニューの Group settings… で設定します。行は、自身の条件と所属グループの条件の両方を満たす場合だけ表示されます。
- Shader properties の Time sample の設定に Minimum、Maximum、Step、Decimals を追加しました。Slider、Seed、Angle にも Decimals を追加しました。
- Shader properties の見出しに Show hidden（目のボタン）を追加しました。Visible when で隠れているプロパティを薄く表示し、設定を開けます。Toggle や Dropdown が取らない値を条件にして Apply すると警告を出します（保存はされます）。
- Device render に Custom の解像度を追加し、幅と高さを直接指定できるようにしました。3440×1440 や 2560×1080 などで書き出せます。書き出しの設定は次の書き出しまで記憶されます。
- Constraints に Follow を追加しました。グループやオブジェクトが、別のシーンレイヤーのグループやオブジェクトの位置、回転、スケールに追従します。チャンネルごとのオン・オフ、オフセット、World と Local を選べます。
- Shader+ のカスタムプロパティに、Default の値に戻すリセットボタンを追加しました。キーとエクスプレッションも外し、取り消しは 1 回分です。
- Shader properties の「+」の一覧に Group を追加しました。選択中のプロパティを新しいグループにまとめます。
- Visible when で、`> 5.5`、`>= 1`、`!= 3` のような比較と、`1..5` のような範囲を使えるようになりました。
- Toggle を、ワンクリックで切り替えるチェックボックスとして表示できるようになりました。
- カスタムプロパティを、名前付きの折りたためるグループにまとめられるようになりました。プロパティのメニューの Group… を使います。グループの Settings で名前と Lock を設定でき、Lock すると行をドラッグできなくなります。3D グループには Objects パネルに Lock ボタンを追加しました。グループとロックはパネルにだけ効き、画には影響しません。
- Trapcode Form に粒子の回転を追加しました。Rotate X、Y、Z、Random rotation、Degrees/sec X、Y、Z、Random speed rotate、Random speed distribution を、パネルと Form Designer で設定できます。既存の Form の見た目は変わりません。
- ExpressText+ で、テキストを選択している間、各エフェクターの Field を 3D ビューにワイヤーの箱で表示します。箱は Preview cache と書き出しには含まれません。
- ExpressText+ のエフェクターを、行のドラッグで並べ替えられるようになりました。
- ExpressText+ の Shake に Mode を追加しました。これまでと同じ Sine と、Noise を選べます。
- Player+ に再生速度のメニューを追加しました。0.25x から 2x まで選べて、J、K、L と連動します。
- エクスプレッションで `fps`、シェーダーで `uniform float zFps;` として、プロジェクトのフレームレートを読めるようになりました。
- Graph Editor 2 をさらに拡大できるようになりました。時間方向に 200 倍、値の方向に 1000 倍まで近づけます。
- Delay に Spring damping と Spring cycles を追加し、バネの行き過ぎを大幅に強くできるようになりました。初期値では既存のプロジェクトは変わりません。
- プラグインのウィンドウを別のブラウザウィンドウとして開けるようになりました。Graph Editor 2、コードエディタ、Trapcode の Designer などを別のモニターに移せます。タイトルバーの Pop out を使います。別ウィンドウを閉じると、ツールはエディタに戻ります。
- Shader+ に Time sample プロパティを追加しました。シェーダーは入力を別の時間で最大 4 つ読めます。フレームまたは秒で指定し、キーフレームとエクスプレッションも使えます。モーションベクトルとタイムジッターのテンプレートとドキュメントがあります。
- ディスクに保存していない変更があると、Save ボタンに小さな点が付くようになりました。10 分たつとアクセントカラーに変わり、Save ボタンのツールチップに経過時間が表示されます。自動の復元ポイントは保存として数えません。時間の変更やオフは Restore パネルで設定できます。
- Shader+ にコードテンプレート「Velocity from a property」を追加し、別のプロパティの速度をシェーダーに渡す方法をドキュメントで説明しました。エクスプレッションで `thisComp.frameDuration` を使えます。
- Assets に読み込んだフォントが、すべてのフォント選択欄の **Project fonts** に、それぞれの書体で表示されます。組み込みフォントと同じように選択でき、キーフレームも打てます。フォント一覧で矢印キーと Enter が使えるようになりました。
- 組み込みフォントを追加しました。Geist、Geist Mono、Geist Pixel (Circle、Grid、Line、Square、Triangle)、Geist Serif (Square、Triangle、Heart の各スタイルを含む)、Inter、Paper Mono を、すべてのフォント選択欄で使用できます。Geist、Geist Mono、Inter は可変フォントのため、Shape+ Text ではフォントを読み込まずにウェイトをアニメーションできます。
- フォント選択欄のプレビュー画像を、フォント一覧から生成するようにしました。追加した組み込みフォントも、それぞれの書体で表示されます。
- Shape+ Text。Shape+ のコンテンツに置く、打ち直せるテキスト項目です。Fill、Stroke、グラデーション、パス修飾、Repeater、Merge Paths が、ほかのパスと同じように文字に効きます。Source Text、フォント、Fallback Font、サイズ、トラッキング、行送り、ベースラインシフト、比率、大文字、揃え、折り返し付きのボックステキストをアニメーションできます。プレビューでテキストをダブルクリックすると編集できます。
- Shape+ Text の可変フォント対応。フォントの各軸 (太さ、幅など) をアニメーションできるプロパティとして使用でき、**Style** でフォントの名前付きスタイルを適用できます。TTF、OTF、WOFF のフォントを使用できます。WOFF2 には未対応形式の通知を表示します。
- Shape+ の Text Animator。テキスト項目の下に置くと、選んだ文字を移動、拡大縮小、回転、傾斜、トラッキング、文字のずらしで動かし、可変フォントの軸を文字ごとにずらします。Range Selector (形、イーズ、モード、ランダム化) と、任意で追加する Wiggly Selector が、文字、単語、行の単位で対象を選びます。テキストの右クリックメニューから追加します。
- Shape+ の **Create Shapes from Text**。テキスト項目を、1 文字ずつのグループに分かれた編集できるパスに変換します。変換前のテキストと同じピクセルで描画します。
- Graph Editor 2 は、エクスプレッションの出力を編集できない破線の曲線で表示します。すべてのイージングプリセットを実際の形で描き、Custom easings で各プリセットの形をプレビューします。
- Graph Editor 2 は、ベクトルと色のプロパティを 1 行にまとめ、その下に X、Y、Z (または R、G、B、A) の行を表示します。軸ごとに表示、ソロ、編集ができます。**Link axes** は、ほかの軸の同じフレームのキーを時間方向に一緒に動かします。
- DaviFX による ExpressText+。3D Text の上に置くコンテナーで、Shake、Plain、Random、Formula、Delay、Spline、Orbit、Repeater、Twist、Wrap、Voronoi のエフェクターで文字を 1 つずつ動かします。
- After Effects 形式の Assets パネル。すべてのファイル、フォント、画像、モデル、コンポジションを 1 か所に集め、使用状況、見つからない項目、失敗した項目をバッジで示します。
- アセットコマンド。Import、Delete、Remove Unused Items、Replace、Reload、Relink、Resolve Fonts、Export を使用できます。
- ドラッグアンドドロップ対応のアセットフォルダーとラベル。Collect Files と Consolidate All Footage も使用できます。
- Assets の項目をアニメーション付きプロパティにドロップすると、そのプロパティにキーを設定します。
- Shape+ のベクトル編集。グループ化したパスキー、キャンバスツールを備えた Shape Editor、ジェスチャー履歴、ロスレスなトポロジーを使用できます。
- Shape+ のペイントとプロシージャルジオメトリ。ストローク、変形、ウィグル、オフセット、クリッピング、ネイティブ変換、SVG 貼り付けを使用できます。
- Expressions+。モダンなエクスプレッション、Sequence Controls、Graph Editor 2 での作成、同一フレームのワールドサンプリング、カメラヘルパー、シェーダーバインディングを使用できます。
- Shader+。テクスチャ種別 (ランプ、カーブ、テキスト)、ネイティブプロパティサイドバー内のエディター、フォント準備を使用できます。

### 変更

- Player+ の品質メニューで **Adaptive** を説明するようにしました。再生がリアルタイムに間に合わないときだけ品質を下げ、**Lowest** はその下限です。
- プロジェクトのフレームが進んでいない間の無駄なプレビュー描画を省き、一時停止中の待機時は編集、シーク、リサイズがあるまで再描画しないようにしました。動画テクスチャもディスプレイのリフレッシュごとではなく、シーケンスのフレームレートに合わせて更新します。
- 対応する動画クリップを共通の WebCodecs ストリームで先読みデコードし、上限付きのフレームキャッシュで再利用するようにしました。再生中のシーク待ちが減り、再生中も正確な動画フレームをプレビューキャッシュに保存できます。非対応のコーデックはブラウザの video 要素へ自動で戻ります。

- **Render Time** 列に CPU と GPU の時間を並べて表示するようにしました（`CPU 0.12 · GPU 1.30 ms`）。GPU のタイマーが使えないときは `GPU —` と表示し、理由をツールチップに出します。以前のように、CPU で描いているように見える表示にはなりません。ツールチップでは、それぞれの数字に何が含まれるかを説明します。
- 書き出しの **Bitrate** のツールチップとドキュメントで、値が目標であることを説明するようにしました。MP4 は可変ビットレートなので、単純な映像、暗い映像、動きの遅い映像は目標より低く、細かく速い映像は目標より高くなることがあります。

- Player+ のツールバーがはみ出さないようにしました。プレビュー品質、**Adaptive**、**Lowest** を 1 つの小さな品質ボタンのメニューにまとめ、再生速度のメニューも短くしました。ツールバーが狭いときは、使う頻度の低い Player+ のボタンが **⋯** メニューに移ります。

- ZSMB と S_Glow の表示を beta 1.1 にしました。不具合を報告するときに版を特定できます。古い名前で保存されたエフェクトは、プロジェクトを開いたときに新しい名前に変わります。

- Trapcode Particular で、Air density が 1 以外のときに、アニメーションさせた Air resistance が 0 になっても粒子が飛ばなくなりました。
- Native FX、Text+、Effector、Trapcode、Optical Flares、CCFX パックを使うプロジェクトで、プレビューキャッシュが再び働くようになりました。承認済みの一覧がプラグインのバージョンに追いついていなかったため、これらのプロジェクトはキャッシュされていませんでした。承認したプラグインはすべて、キャッシュしたフレームとその場で描画したフレームが1バイトも違わないことを確かめています。
- プレビューキャッシュがフレームを保存しないとき、Settings にその理由（「Not caching:」に続く説明）を表示します。メモリー警告は Mac 専用の表現ではなくなりました。
- Smart Motion Blur の Shutter Samples で、パーティクルのような柔らかい部分や半透明の部分が暗くならなくなりました。以前は、サンプルを取り込むときにアルファを2回掛けていました。不透明な部分、Optical Flow、他のエフェクトの出力は変わりません。
- Zoidium のグラデーションエディターを使っているときに、マテリアルのパネルが空にならなくなりました。以前は、パネルを開いたまま PBR+ マテリアルを追加すると、マテリアルの読み込みが止まることがありました。その場合、見出しが「undefined」になり、値が空になりました。カスタムコントロールでエラーが起きたときは、パネルを止めずに標準のコントロールを表示します。
- UV Custom Material で **Wrap** を **none** にして保存したプロジェクトは、開き直しても **none** のままです。以前は、開き直すとテクスチャがタイル状に繰り返されました。
- デタッチされたテンポラルエフェクトを安全にスキップし、datamosh 書き出しのカット位置を維持します。カットのないカット限定書き出しも正常に動作します。
- フレーム取得で JPEG をエンコードし、フレーム書き出しの失敗から回復します。
- Trapcode のデコード済みオーディオは再生中も利用できるよう保持し、デコード済みレコードがソース再読み込み後も残ります。
- Shape+ レイヤーは削除、プレビュー、クリーンアップ中も安全に保たれ、Shader+ の非同期読み込みと Material+ の UV 状態は削除後も復旧します。
- 古い Shader+ フォント読み込みとデタッチされた Shape+ 変換を拒否またはロールバックします。
- セットアップ対象のプロジェクトがライブツリーから外れると、セットアップウィンドウを閉じます。
- プロジェクトの置き換え後にネイティブエフェクトが残らず、保留中のフィルター読み込みを取り消します。
- キュー内のエンコード要求は、ネイティブエンコード開始前に取り消せます。
- Effector の準備はオブジェクト削除後に回復し、遅延 LUT 読み込みはプロジェクトと共にクリーンアップされ、起動に失敗した場合は Web ステージをクリーンアップします。
- MP4 書き出しのクリーンアップ失敗は致命的になりません。
- Smart Motion Blur は、完全透明なテクセルと変位制限外の候補をスキップします。
- 書き出しに失敗してもシャッタークロックは正確に保たれ、プロシージャルフォールバックを使い、プレビューは取り消し後も残ります。
- 書き出し中のコンテキスト喪失では、破損フレームを作らず速やかに失敗します。
- Camera+ は登録済みトラックフィールドを復元し、共有カメラの検索更新を削減します。
