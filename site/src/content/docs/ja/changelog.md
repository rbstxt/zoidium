## 未リリース (ベータ)

最新の安定版リリース以降の新規追加と変更です。各項目は、目に見える変更を 1 行で説明します。

### 追加

- After Effects 形式の Assets パネル。すべてのファイル、フォント、画像、モデル、コンポジションを 1 か所に集め、使用状況、見つからない項目、失敗した項目をバッジで示します。
- アセットコマンド。Import、Delete、Remove Unused Items、Replace、Reload、Relink、Resolve Fonts、Export を使用できます。
- ドラッグアンドドロップ対応のアセットフォルダーとラベル。Collect Files と Consolidate All Footage も使用できます。
- Assets の項目をアニメーション付きプロパティにドロップすると、そのプロパティにキーを設定します。
- Shape+ のベクトル編集。グループ化したパスキー、キャンバスツールを備えた Shape Editor、ジェスチャー履歴、ロスレスなトポロジーを使用できます。
- Shape+ のペイントとプロシージャルジオメトリ。ストローク、変形、ウィグル、オフセット、クリッピング、ネイティブ変換、SVG 貼り付けを使用できます。
- Expressions+。モダンなエクスプレッション、Sequence Controls、Graph Editor 2 での作成、同一フレームのワールドサンプリング、カメラヘルパー、シェーダーバインディングを使用できます。
- Shader+。テクスチャ種別 (ランプ、カーブ、テキスト)、ネイティブプロパティサイドバー内のエディター、フォント準備を使用できます。
- シェーダー作成ツール。確認済みテンプレート、分離した下書きチェック、補完、ヘルプ、検索、ローカル履歴、JSON エクスポートを使用できます。
- Node Effect グラフ。検証、ネイティブパラメーターのアニメーション、スターターレシピを使用できます。
- Node Material カタログ。ランプエディターとカーブエディター、サーフェストラック、レシピを使用できます。
- Constraints。Track To コンストレイントと依存関係の循環チェックを使用できます。
- Motion Paths ビューポートプラグイン。キーのドラッグ編集を使用できます。
- Theme Editor。パレット、取り消し、従来の Custom プロファイル同期を使用できます。
- ネイティブ MP4 エクスポート。ストリーミングエンコード、品質管理、エラー回復を使用できます。
- Smart Motion Blur。オプティカルフローとシャッターサンプルの再構成、動きの診断表示を使用できます。
- Text+ のネイティブ 2D 文字アニメーション、面ごとの文字マテリアル、3 層の文字カテゴリを使用できます。
- Centered エディターレイアウト (Clipmaker 3 Centered、Video Editor 2 Centered、Video Editor 2 Centered 2)。パネル用の 2 つ目のサイドバーを備えます。
- Centered レイアウトでは、パネルタブを右クリックしてサイドバー内またはサイドバー間で移動できます。配置はエディター設定と共に記憶されます。
- エフェクトピッカーをカテゴリ別にグループ化し、件数と最近使用したエフェクトを表示します。
- エディターの外装とポップアップメニューがアクティブなテーマに従います。
- デバイスレンダーオプションに Export Bitrate 倍率を追加しました。
- 他のレイヤーのフレームを入力として読み取るエフェクトソースを使用できます。
- Particular Displace Spin のシード付き円軌道と、共有 Twist ピボットを使用できます。
- 開発者向けプレビュー（既定ではオフ）: ローカルのコミュニティエフェクトパッケージ（検証済みコントロール付き）、ローカルのパッケージ保存、ほかのフレームのローカル限定サンプリング。一般向けの機能ではありません。

### 変更

- 既存プロジェクトの見た目の変更。Trapcode Particular で、Velocity distribution、Aspect ratio、Opacity random、Color random、Air density、Drift X/Y/Z、Disperse strength over（life）とそのカーブ、Turbulence field affect size と affect opacity が描画に反映されます。これらは以前は効果がありませんでした。既定値のままのプロジェクトの描画は変わりません。
- Trapcode Particular で、効果のないコントロールを非表示にしました。対象は Particle type、Set color、flocking のコントロール、Emitter type の light/layer/model/text、Disperse strength over の velocity/position です。保存された値は残ります。Bounce height の名前は Bounce boost になりました。
- 既存プロジェクトの見た目の変更。3D Scene レイヤーでは、Smart Motion Blur の Automatic が Shutter Samples を使用し、それ以外では Optical Flow を使用します。Reconstruction の保存値がないプロジェクトは Automatic を使用します。3D Scene でフローベースのブラーを維持するには、Optical Flow を選択します。
- 既存プロジェクトの見た目の変更。Trapcode Particular と Form のシェーディングは、アンビエントライトとヘミスフィアライトを 2 回ではなく 1 回だけ半分の強さで適用するため、ライトが当たるパーティクルが明るく表示されます。
- 既存プロジェクトの見た目の変更。Drop Shadow は、保存された 0 の値を既定値で置き換えず、そのまま表示します。
- タイミング。シーケンスのフレームレートを変更しても、クリップとアニメーションのタイミングが秒単位で維持されます。Undo と Redo、小数位置の通知を使用できます。
- プレビューキャッシュにセッションメモリ上限、GPU 失敗時の処理、Settings でのライブ使用量表示を追加しました。
- Magic Looks にインスタンスモデル、セットアップウィンドウ、狭いレイアウト、キーボード操作、ルック保持を追加しました。
- エクスプレッション、コンストレイント、Motion Paths、Native FX、プロジェクトスキャナーの待機時とエクスポート準備時のコストを削減しました。

### 修正

- UV Custom Material で **Wrap** を **none** にして保存したプロジェクトは、開き直しても **none** のままです。以前は、開き直すとテクスチャがタイル状に繰り返されました。
- デタッチされたテンポラルエフェクトを安全にスキップし、datamosh エクスポートのカット位置を維持します。カットのないカット限定エクスポートも正常に動作します。
- フレーム取得で JPEG をエンコードし、フレームエクスポートの失敗から回復します。
- Trapcode のデコード済みオーディオをライブ利用者向けに保持し、デコード済みレコードがソース再読み込み後も残ります。
- Shape+ レイヤーは削除、プレビュー、クリーンアップ中に安全に保たれ、Shader+ の非同期読み込みと Material+ の UV 状態は削除後に回復します。
- 古い Shader+ フォント読み込みとデタッチされた Shape+ 変換を拒否またはロールバックします。
- プロジェクト対象がライブツリーから外れると、セットアップウィンドウを閉じます。
- プロジェクト置き換え後にネイティブエフェクトが残らず、保留中のフィルター読み込みを取り消します。
- キューに入ったエンコード要求は、ネイティブエンコード開始前に取り消せます。
- Effector の準備はオブジェクト削除後に回復し、遅延 LUT 読み込みはプロジェクトと共にクリーンアップされ、失敗した起動は Web ステージをクリーンアップします。
- MP4 エクスポートのクリーンアップ失敗は致命的になりません。
- Smart Motion Blur は、完全透明なテクセルと変位制限外の候補をスキップします。
- 失敗したエクスポートは正確なシャッタークロックを維持してプロシージャルフォールバックを使用し、プレビューは取り消し後も残ります。
- エクスポートのコンテキスト喪失は、破損フレームを生成せず速やかに失敗します。
- Camera+ は登録済みトラックフィールドを復元し、共有カメラの検索更新を削減します。

### ドキュメント

- エディターと共に提供する新しいドキュメントサイト。日本語ロケール付きです。
- Native FX リファレンス。一覧、画像フィルター、時間、キーイング、ジェネレーター、トランジションを収録します。
- 機能ガイド。Effector、カーブエディター、Optical Flares、シェーダーパック、プレビュー、ライト、パーティクル、GIF、Graph Editor 2 を収録します。
- エディターのワークフローとエクスポートガイド (ビデオオプション、フレーム取得、datamosh) を両ロケールで収録します。
- 開発者リファレンスの日本語版。日本語リンクは翻訳済みアンカーを指します。
- Shader+ プロパティモデルから生成するシェーダー作成リファレンスを追加しました。
- タスクガイド。プリコンポーズ、アセット修復、レイヤー入力、レガシーエフェクト、重いプロジェクトのプレビューを収録します。
