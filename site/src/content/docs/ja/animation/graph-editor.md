**Graph Editor 2** (別名 **Graph+**) は、グラフパネルまたはフローティングウィンドウでネイティブのキーフレーム曲線を編集するツールです。
有効な間はネイティブのグラフパネルを置き換え、無効にするとフローティングウィンドウを閉じて元の動作へ戻ります。

## プロパティを開く・表示する

1. **Plugins** で **Graph Editor 2** を有効にします。
2. アニメーション可能なプロパティ行またはタイムラインラベルを右クリックし、**Show in Graph Editor** を選びます (フォーカス中の行では Alt+Shift+G でも開けます)。
3. フローティングウィンドウを直接開く・前面に出すには Ctrl+G を押すか、エディターのグラフボタンをクリックします。

ベクトルやカラーのプロパティは、すべての成分をまとめて表示します。

### 選択追従とピン留め

**Follow selection** は初期状態でオンになっており、設定はローカルに保存されます。

- **Follow selection** がオンのとき、プロパティを選ぶと表示中のカーブが切り替わります。オブジェクトやレイヤーを選ぶと、マテリアル・ジオメトリ・プラグインを含むアニメーション済みプロパティへ追従します。Ctrl クリックまたは Shift クリックで複数プロパティを追加できます。
- 別のオブジェクトを選びながら現在のカーブを固定したい場合は、**Follow selection** をオフにします。ピン留め中にカーブを差し替えるには **Show in Graph Editor** を実行します。

カーブの表示切り替えは Undo 履歴を増やしません。フローティングウィンドウの位置とサイズはローカルに記憶されます。

## キー、タンジェント、ベクトル軸を編集する

1. **Marquee** (または Shift ドラッグ) でキーを選択します。
2. **Linear**、**Step**、**Ease**、**Custom easings** を適用するか、ハンドルを直接操作する場合は **Bezier** を選びます。
3. 左右のハンドルを独立させるときは **Break Tangents**、滑らかに繋ぎ直すときは **Auto Tangents** を使います。
4. **Frame** (または `F`) をクリックすると、選択中のキーが画面に収まるようズームします。

### ベクトル・カラートラック

複数成分を持つプロパティは、親行と色分けされた軸行で表示されます。

- 軸行をクリックすると、その軸を表示してキーを選択します。Ctrl クリックまたは Shift クリックで複数軸を組み合わせ、親行をクリックすると全成分を選択できます。
- 目のアイコンでカーブの表示切り替え、**S** で軸の単独表示 (ソロ) ができます。表示状態はプロジェクトには保存されません。
- **Link axes** をオンにすると、同じフレームにある別軸のキーを水平移動で一緒に動かせます (値の上下ドラッグは選択した軸のみに効きます)。
- イージング、タンジェント、値変更、削除、コピー、貼り付けは選択した軸に適用されます。**+Key** は選択軸 (未選択時は表示中の軸) にキーを追加します。コピーと貼り付けでは軸名が保持されます。1 つの軸だけを別の軸へ貼り付けたい場合は、貼り付け先の軸だけを選択してください。

### エクスプレッション曲線を確認する

エクスプレッションが設定されたプロパティは、**Expression** ラベル付きの読み取り専用破線として表示されます。
**Fit** や **Frame** で評価結果の曲線を確認できます。負荷の高い式は複数回の再描画に分けて描かれ、**Fit** と **Frame** はサンプリング完了を待ってから表示を合わせます。キーを直接編集したい場合は先にエクスプレッションを削除してください。

1 区間のイン側イージングを手早く調整したい場合は [Easing+](/docs/ja/animation/easing-plus/) も使えます。どちらも同じネイティブのベジェハンドルを読み書きします。

## ツールバーとキーボードショートカット

ショートカットはグラフにキーボードフォーカスがある間だけ有効です (テキスト入力欄では通常の文字入力が優先されます)。macOS では Ctrl を Cmd に読み替えてください。

| ツールバー | ショートカット | 動作 |
| --- | --- | --- |
| **Linear** | — | 選択キーにリニアイージングを適用します。 |
| **Step** | — | 次のキーまで前の値を保持します。 |
| **Ease** | — | 3 次インアウトイージングを適用します。 |
| **Custom easings** | — | サムネイル付きでホストのイージングプリセットを表示します。 |
| **Break Tangents** | — | 選択キーのタンジェント方向を分離します。 |
| **Auto Tangents** | — | 選択キーのタンジェントを連続に戻します。 |
| **Bezier** | `I` | ベジェ補間とリニア補間を切り替えます。 |
| **Link** | `T` | タンジェントの連続性を切り替えます。 |
| **Flat** | `R` | 選択ハンドルをリセットします。 |
| **Pan** | `H` | 左ドラッグでグリッドをパンします (Space ドラッグでも可)。 |
| **Marquee** | `V` | 左ドラッグでキーを囲んで選択します (初期ツール。Shift ドラッグはどちらのツールでも有効)。 |
| **Fit** | `\` | すべてのカーブを画面に収めます。 |
| **Frame** | `F` | 選択キーを画面に収めます。 |
| **Norm** | `N` | 値を変えずにカーブの表示高さを正規化します。 |
| **Snap** | `S` | ドラッグ先を再生ヘッドや他キーへスナップします。 |
| **+Key** | `K` | 表示中のカーブの再生ヘッド位置にキーを追加します (グラフのダブルクリックでも追加)。 |
| **Del** | Delete / Backspace | 選択キーを削除します。 |
| **Copy**, **Paste** | Ctrl+C, Ctrl+V | 選択キーをコピーし、再生ヘッド位置へ貼り付けます。 |
| **Labels** | — | カーブラベルの表示を切り替えます。 |

そのほか、Ctrl+X で切り取り、Ctrl+A で全選択、矢印キーで 1 単位 (Shift 併用で 10 単位) の微調整ができます。水平方向はフレーム単位、垂直方向はグラフのピクセルを値に換算して移動します。

## マウス、トラックパッド、ハンドル操作

ツールバーの **?** をクリックすると、エディター内でジェスチャー一覧を確認できます。

| 操作 | 動作 |
| --- | --- |
| マウスホイール | ポインター位置を中心に X 軸をズームします。 |
| Alt + ホイール | Y 軸をズームします。 |
| Shift + ホイール | X 軸をパンします。 |
| トラックパッド 2 本指スクロール | 慣性付きで X / Y 軸をパンします。 |
| ピンチ / Ctrl + ホイール | ポインター位置を中心に X / Y 軸をズームします。 |
| Alt + ピンチ | Y 軸をズームします。 |
| 中ドラッグ / Space + ドラッグ | ビューをパンします。 |
| ルーラー上で左ドラッグ / グラフ上で右ドラッグ | 再生ヘッドをスクラブします。 |
| キードラッグ中に Ctrl | フレームを固定し、値のみ変更します。 |
| キードラッグ中に Shift | 値を固定し、フレームのみ変更します。 |

ルーラー上では Alt + ホイールを含め、すべてのホイール操作が X 軸ズームになります。

### ベジェハンドル操作

選択したキーにタンジェントハンドルが表示されます。短いハンドルには最小表示長が設けられますが、保存値自体は変わりません。

| 操作 | 動作 |
| --- | --- |
| ハンドルをドラッグ | ハンドルを調整します。プリセット区間をドラッグするとベジェへ変換されます。 |
| ドラッグ開始時またはドラッグ中に Alt | タンジェントを分離します。Alt を離すと再び連結されます。 |
| ドラッグ中に Shift | 角度を 45 度刻みに制限します。 |
| ドラッグ中に Ctrl / Cmd | 水平または隣接キーの傾き付近へスナップします。 |
| ハンドルをダブルクリック | 両方のハンドルを既定のフラットなイーズへリセットします。 |

ドラッグやハンドル操作はそれぞれ 1 つの Undo ステップになります。複数軸を選択した状態で値をドラッグすると、選択中の全キーに同じ変化量が適用されます。

## 表示スケール

**Fit** とホイールズームは共通のスケール上限を持ち、X 軸は CSS ピクセルあたり `0.0001` ～ `500` フレーム、Y 軸は `0.000001` ～ `10000` 表示単位です。
ルーラーとグリッドは同じ目盛り位置を使い、高倍率ズームでも小数フレームラベルを保持します。表示スケールの変更はキーフレームや保存データに影響しません。
