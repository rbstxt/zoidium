---
title: モーションパス
description: プレビュービューポート上でアニメーション付き Position のキーフレームとベジェハンドルを直接ドラッグ編集します。
---
**Motion Paths** (既定で有効) を使うと、アニメーション付きの **Position** 軌跡をメインプレビュー上に表示し、キーフレームとハンドルを直接ドラッグして調整できます。

## モーションパスを表示・編集する

**Position** には、エクスプレッションが設定されていないアニメーション済みの軸が少なくとも 1 つ必要です。

1. タイムラインでレイヤークリップを選択します (3D オブジェクトの場合は **Objects** でオブジェクトを選択します)。
2. 2D レイヤークリップの場合は **T** を押してレイヤートランスフォーム操作を表示します。
3. **O** を押すか、ビューポートの **motion paths** ボタンをクリックします。
4. パス上の四角いキーをクリックしてドラッグすると、キー位置を移動できます。
5. 黄色いタンジェントハンドルをドラッグして軌跡の曲がり具合を調整します。

## 操作一覧と上限

| 操作 | 動作 |
| --- | --- |
| `O` | モーションパスオーバーレイの表示を切り替えます。 |
| Shift + クリック | キーの選択状態を切り替えます。 |
| Shift + ドラッグ | 親空間の主軸に沿って移動を制限します。 |
| Alt + ドラッグ (ハンドル) | タンジェントの連続性を解除します。 |
| Alt + クリック (キー) | 隣接区間をリニアとベジェで切り替えます。 |
| Escape | 現在のドラッグをキャンセルします。 |

- エクスプレッションで駆動されている軸は読み取り専用または非表示になります。
- パスの描画は最大 `1500` セグメントで、区間が `900` フレームを超えるとフレームごとのドット表示を省略します。
