---
title: シェーダーの編集とチェック
description: Shader+ エディターで補完、診断、Declare、テンプレートを使用します。
---
Shader+ を有効にし、Custom Shader のコードエディターを開きます。

## シンボルを補完する

1. コードエリアに uniform またはヘルパーのプレフィックスを入力します。
2. 矢印キーを使用して補完候補を選択します。
3. Tab または Enter を押して、選択した名前を挿入します。

補完を閉じるには、Escape を押します。シグネチャを確認するには、シンボルにカーソルを合わせるか、関数呼び出し内にキャレットを配置します。例を確認するには、サイドリストの **?** をクリックします。対応するリファレンスアンカーを開くには、**Documentation** をクリックします。

## ドラフトのエラーを修正する

1. ドラフトを編集します。
2. 400 ms の一時停止の後、入力中のチェックを待ちます。
3. 診断結果をクリックして、そのソース行を選択します。
4. コードを修正します。

入力中のチェックでは使い捨てのプログラムがコンパイルされます。保存されたエフェクトとプレビューは、適用するまで変更されません。薄く表示される uniform のヒントは参考情報です。シェーダーが有効かどうかはコンパイラが判断します。プロパティに宣言がない場合は、**Declare** をクリックしてドラフトに宣言を挿入します。

## テンプレートから開始する

1. **New from template** を開きます。
2. テンプレートを選択します。
3. ドラフトの置換を確定します。
4. テンプレートにプロパティが必要な場合は、**Add properties** をクリックします。
5. **Apply** をクリックしてソースを保存します。

Add properties はプロジェクトの履歴エントリを 1 つ作成します。Apply は別のエントリを作成します。Animated noise には Expressions+ が必要です。Text overlay はプロジェクトのフォントを使用します。

## テキストを検索して編集する

コードエリアにフォーカスがある間は、次のショートカットを使用します:

- Ctrl または Cmd + F は文字列の検索と置換を開きます。
- Ctrl または Cmd + / は行コメントを切り替えます。
- Tab はインデントを追加し、Shift + Tab はインデントを解除します。
- Ctrl または Cmd + Z はドラフトの編集を元に戻します。
- Ctrl または Cmd + S、または Ctrl + Enter はドラフトを適用します。
- Ctrl または Cmd + Plus または Minus はコードのフォントサイズを変更します。

プロジェクトの「元に戻す」を実行すると、保存されたプロパティからドラフトが更新されます。フォントサイズはローカルに保持され、プロジェクトには保存されません。[エディターの互換性](/docs/ja/development/project-compatibility/#shader-editor-development-aids) を参照します。
