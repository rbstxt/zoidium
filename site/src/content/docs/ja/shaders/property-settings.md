**Shader+** (既定で有効) を使うと、ネイティブの **Custom Shader** エフェクトに型付きコントロールを追加し、折りたたみ可能なグループにまとめ、条件付き表示・動的ラベル変更・数値スナップを設定できます。
すべての設定・グループ・表示オプションは、保存・再オープン・複製・Undo・Redo を通じて保持されます。

## Shader+ コントロールを追加する

1. クリップにネイティブの **Custom Shader** エフェクトを追加します。
2. **Shader properties** を開いて **+** をクリックし、**ZOIDIUM** から種類を選びます。
3. プロパティ名を設定し、コードエディターで対応する GLSL uniform を宣言して **Apply** をクリックします。

- 種類メタデータのないネイティブ数値は、**Property settings** で **Minimum** / **Maximum** 付き **Slider** として表示されます (編集せず **Apply** を押すとそのまま保持)。他のネイティブ型は種類を選ぶまで **Native** と表示されます。
- **Expressions+** 有効時は `uniform float zFps;` でシーケンスのフレームレートを取得できます (書き出し時の FPS 上書きでは変わりません)。
- 各種類のエディターと保存形式は [プロパティの種類と形式](/docs/ja/development/shader-properties/)、コード例は [種類ごとの GLSL 例](/docs/ja/shaders/kind-examples/)、プラグイン互換要件は [保存プロジェクトの描画互換性](/docs/ja/development/project-compatibility/) を参照してください。

## プロパティをグループに整理する

グループ化は **Shader+** のほか **Custom properties** を持つオブジェクト・エフェクトでも使え、プロパティ名やシェーダーの uniform 名は変えません。

### グループの作成と追加

- **1 行から作成:** カスタムプロパティ行を右クリックして **Group…** を選び、**Group** 名を入力して **Apply** をクリックします。同じ名前を指定するか、ロック解除されたグループ見出し・行へドラッグして他のプロパティを追加できます。外すには **Group…** で名前を空にして **Apply** を押します。
- **複数選択から作成 (+ リスト):** 移動したい Shader プロパティ行を選択し、**Shader properties** 見出しの **+** をクリックして `group` を検索し、**Group** を選んで未使用の **Name** を入力して **Apply** をクリックします。1 回の Undo で選択行すべてが元に戻ります。

グループは所属プロパティに記録されるため、空になったグループの見出しは残りません。新規プロパティはグループ外に作成されます。

### 名前変更・並べ替え・折りたたみ・ロック

1. グループ見出し横の **Settings** をクリックし、**Name** の変更や **Lock** のオン/オフを設定して **Apply** をクリックします。
2. 見出しをクリックすると折りたたみを切り替えられます (Undo 履歴を増やさずプロジェクトに保存)。
3. ロック解除中の見出しをドラッグすると、ネイティブのプロパティ順や uniform 名を変えずに表示順だけ並べ替えられます。

ロック中のグループは、見出しドラッグやプロパティの出入りを拒否しつつ値の編集とアニメーションは許可します。行を移動するときは先にロックを解除してください。
**Objects** パネルで 3D オブジェクトグループをロックするには、行の **Lock** をクリックします (**Locked** で解除)。パネル上のドラッグとドロップをブロックしつつ描画とアニメーションは継続します。古いビルドはロックを強制せずにプロジェクトを開きます。

## リセットボタン

- Shader エフェクトのネイティブ **Properties** リセットは、フラグメントシェーダーコードを保持したまま他のネイティブ項目 (**Name** や **Enabled** など) をリセットします。
- **Shader properties** 見出しの **Reset custom properties to defaults** は、1 回の Undo ステップで全カスタムコントロールのキーフレームと式を削除し、フレーム `0` の静的既定値へ戻します。Undo で元の値・キー・式がまとめて復元されます。
- リセット値は `zoidiumShader.default` (未設定時は定義値またはネイティブ既定値) を使い、ベクトルや Gradient・Curve・Palette・Text の JSON 値にも対応します。プロパティ定義・名前・グループは維持されます。

## Visible when と Has value

**Visible when** を使うと、同じエフェクト内の別コントロールが **Has value** に一致するときだけプロパティやグループを表示できます。

| **Has value** 記法 | 一致条件 |
| --- | --- |
| `> 5.5`, `>= 1`, `< 0`, `<= 2`, `!= 3`, `= 4` | コントローラーの評価済み数値 (アニメーション・式を含む) との比較。 |
| `1..5` | 両端を含む数値範囲 (`1` ～ `5`)。 |
| `1; 2; > 5.5` | セミコロン区切りの OR 条件。 |

- 不正な演算子や逆転した範囲はエラーが出て **Apply** がブロックされます。既存の完全一致文字列は厳密一致を保ちます。
- 到達不能な Toggle / Dropdown 条件には警告が出ますが **Apply** で保存可能です (式や補間アニメーションがあるコントローラーは警告対象外)。
- **Shader properties** 見出しの **Show hidden** (目アイコン) をオンにすると、非表示の行やグループが薄く表示され設定を開けます (折りたたみは展開しません。ローカル状態で保存・Undo 対象外)。
- **グループの表示条件:** グループ内の行を右クリックして **Group settings…** を開くと、同じエフェクト内のグループ外プロパティをコントローラーに指定できます。行は自身の条件とグループ条件の両方を満たすときだけ表示されます。グループへ移動するとグループ条件が付き、外すと外れます。コントローラーが削除・改名された場合、**Show hidden** をオンにするまで非表示になります。
- 表示条件はエディター表示のみに作用し、非表示のプロパティもシェーダー・プレビューキャッシュ・書き出しへ現在の値を渡し続けます。

## Rename when

**Rename when** は、uniform 名・保存値・キーフレーム・式・リンク・書き出し結果を一切変えずに、行の表示ラベルだけを条件付きで切り替えます。

- **Visible when** と同じコントローラーピッカーと **Has value** 記法を使い、上から最初に一致したルールのラベルを採用します (一致なし、またはコントローラー欠落時は元のプロパティ名を表示)。**Move up**、**Move down**、**Remove** でルールを管理します。
- 現在フレームの評価値に追従し、`zoidiumShader.renameWhen` として保存されます (古いビルドはこのキーを無視します)。

## Toggle の表示形式

**Toggle** は既定の **Off/on menu** に加え、**Property settings…** で **Display = Checkbox** を選んでワンクリック切り替えにできます。
どちらもネイティブの `NUMBER` (`0` / `1`、新規キーは Hold) を書き込み、既存の値・小数キー・エクスプレッションを保持し、エディターテーマに従います。

## Minimum、Maximum、Step、Decimals、Snap

- **Slider**、**Seed**、**Time sample**、**Angle** は **Decimals** (表示小数桁 `0` ～ `100`) と **Snap** を持ち、**Time sample** はさらに **Minimum**、**Maximum**、**Step** も表示します。**Toggle** と **Dropdown** ではこれらは非表示です。
- **Minimum** と **Maximum** は行編集値をクランプし、**Step** はドラッグ倍率と矢印キーの増減幅になります。
- **Snap** は確定した行編集値を **Minimum** (未設定時は `0`) 起点の **Snap** 倍数へ丸めます (中間値は 0 から遠い側へ丸め)。空欄または `0` で無効になります。矢印キーは **Step** で動かしてからスナップするため、**Step** が **Snap** より小さいと同じグリッド線にとどまる場合があります。
- これらは行編集時のみ作用し、保存済みの値やキーフレームを遡って変更しません。
- 別種類から **Time sample** へ変換すると古い数値範囲はクリアされ、単位の既定 **Step** (Frames は `1`、Seconds は `0.01`) になります。**Minimum** / **Maximum** を空欄にすると制限解除、**Step** を空欄にすると単位既定値へ戻ります。
