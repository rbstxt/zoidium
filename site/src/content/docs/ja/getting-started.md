CM3 を取り巻く Zoidium の外部拡張レイヤーを準備し、ワークスペースを整えてプロジェクトを保存するまでの手順です。

## エディターを開く

Web 版は [エディターを開きます](/)。デスクトップ版は Zoidium アプリケーションを起動します。
`.pz` ファイルの関連付けやコマンドラインからの開き方は、[デスクトップアプリ](/docs/ja/development/desktop-app/) を参照してください。

## レイアウトとテーマを選ぶ

1. **Settings** を開きます。
2. **Editor layout** を選びます。
3. Zoidium を再読み込みしてレイアウトを反映します。

**Clipmaker 3**、**Clipmaker 3 Centered**、**Video Editor 2**、**Video Editor 2 Centered**、**Video Editor 2 Centered 2** から選択できます。
**Centered** が付く 3 つのレイアウトは右側にもタブサイドバーを追加し、2 列のパネルの間にプレビューを配置します。
**Video Editor 2 Centered 2** では、右サイドバーがタイムラインの横まで伸びます。

**Centered** レイアウトでパネルを並べ替えるには、パネルのタブを右クリックし、**Move to top**、**Move up**、**Move down**、**Move to bottom**、または **Move to right sidebar** (右サイドバー内では **Move to left sidebar**) を選びます。
各サイドバーには必ず 1 つ以上のタブが残ります。並べ替えの結果は他のエディター設定と一緒にローカルへ保存されます。

**Settings** では、テーマ、UI フォント、グラデーションエディター、新規プロジェクトの既定フレームレート、[プレビューキャッシュの上限メモリー](/docs/ja/workflow/preview-and-cache/) も設定できます。

## エディターウィンドウを別のモニターへ移動する

**Graph editor**、**Shader**、**Expression**、**Trapcode Designer** などのフローティングウィンドウは、編集内容を保ったまま別ウィンドウへ切り出せます。

1. 対象のエディターウィンドウを開きます。
2. タイトルバーの **Pop out** をクリックします。
3. ブラウザーがポップアップをブロックした場合は、このサイトのポップアップを許可してから **Pop out** をもう一度クリックします。
4. 開いたブラウザーウィンドウを目的のモニターへドラッグします。

元のエディターに戻すには、ポップアップのタイトルバーで **Return to editor** をクリックするか、OS のウィンドウを閉じます。
フローティングウィンドウは元の位置とサイズに戻ります。次回 **Pop out** するときは、ブラウザーが許可する範囲で前回のポップアップ位置とサイズを再利用します。

エディター自体を閉じるには、タイトルバーの **Close** をクリックします。メインの Zoidium ページを閉じると、すべてのポップアップも閉じます。
編集中のエフェクトを削除したり、プロジェクトを切り替えたりした場合も、対応するウィンドウは閉じます。
ウィンドウを移動しても、未適用のテキストはエディター内に残ります。シェーダーやエクスプレッションの編集をプロジェクトへ反映するには、**Apply** をクリックします。

## プラグインを有効にする

1. サイドバーの **Plugins** を開きます。
2. カテゴリ内から目的のプラグインを探します。
3. プラグインをオンにします。
4. 対応するピッカーから、追加されたオブジェクト、エフェクト、マテリアルを配置します。

いくつかのプラグインは既定で有効になっています。すべてのプラグインとカテゴリの一覧は [プラグイン一覧](/docs/ja/plugins/) で確認できます。

プラグインを無効にする前に、そのプラグインに依存するプロジェクト要素を取り除いてください。
復元ポイントの保存を求められた場合は、先にその手順を完了します。有効化と無効化のルールは [プラグインマネージャー](/docs/ja/development/plugin-manager/) にまとめています。

## プロジェクトを開いて保存する

1. プロジェクトツールバーの **Open** をクリックするか、Ctrl+O を押します。
2. `.pz` アーカイブを選びます。
3. プロジェクトに必要なインストール済みプラグインの有効化を求められた場合は、そのプラグインをオンにします。
4. プロジェクトを編集します。
5. **Save** をクリックして `.pz` ファイルをダウンロードします。
6. 重要な作業データは、必ず手元にダウンロードしたコピーを残してください。

ローカルの自動バックアップ、保存リマインダーのドット表示、欠落アセット、破損したアーカイブの扱いは [保存と復元ポイント](/docs/ja/development/project-saving/) で説明しています。
ブラウザーのサイトデータを消去するとローカルの復元ポイントが消えることがあります。問題が起きたときは [トラブルシューティング](/docs/ja/troubleshooting/) を確認してください。
