**Animated GIF** を使うと、透過やインターレースを含む GIF87a / GIF89a 画像アセットをデコードし、画像レイヤー、画像マテリアル、エフェクトテクスチャとして再生できます。
このプラグインは GIF の入力専用であり、GIF 形式の書き出し機能は追加しません。

## アニメーション GIF を追加する

サイズの大きい GIF は、読み込み前に下のデコード上限を確認してください。

1. **Plugins** で **Animated GIF** を有効にします。
2. GIF ファイルを画像アセットとして読み込みます。
3. 画像レイヤー、画像マテリアル、またはエフェクトの画像テクスチャ項目にそのアセットを割り当てます。
4. 再生ヘッドを動かしてフレームの変化を確認します。

## 再生タイミングを調整する

デコードされた GIF は、負のメディア時間を含めて連続ループします。
クリップ内では、オフセットやリタイミングを含むそのクリップのメディア時間に応じてフレームが選ばれます。

1. GIF を使っているクリップを選択します。
2. クリップの **Time** プロパティにキーフレームを打って、速度変更や停止を行います。
3. ループ境界の前後や前のフレームへ戻って、タイミングが再現されることを確認します。

クリップに属さない場所では、GIF はプロジェクト時間に追従します。書き出し時は、フレーム取得前に GIF のデコード完了を待ちます。

GIF のフレーム遅延は 1/100 秒単位です。保存値が `0` または `1` の遅延は `0.10` 秒として扱われます。`2` 以上は記録された値そのままになります (たとえば `2` は `0.02` 秒です)。

## デコード上限

| 項目 | 上限 | 上限に達したときの動作 |
| --- | --- | --- |
| フレーム数 | `512` | 上限フレームでデコードを停止します。 |
| キャンバス面積 | `67,108,864` ピクセル | これより大きいキャンバスはデコードに失敗します。 |
| 累積フレーム面積 | `67,108,864` ピクセル | 各フレームはキャンバス全体サイズをこの枠から消費します。残りが 0 以下になるとデコードを停止します。 |

動画や静止画の書き出し形式については [動画とフレームの書き出し](/docs/ja/workflow/export/) を参照してください。
