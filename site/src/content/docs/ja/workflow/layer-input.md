---
title: Layer Input
description: 別のビデオトラックや画像をエフェクト、ディスプレイスメントマップ、3D マテリアル、Custom Shader の入力として使う手順です。
---
**Layer Input** (**Plugins** の **Experimental** カテゴリ) を使うと、別のトップレベルビデオトラックや静止画像を、エフェクト、ディスプレイスメントマップ、3D マテリアル、Custom Shader へ入力できます。
対象となるのはトップレベルのビデオトラックであり、3D シーン内の個別オブジェクトは指定できません。

## ソーストラックを合成する

1. **Plugins** で **Layer Input** を有効にし、実験的機能の警告を承認します。
2. 入力元にしたいコンテンツを別のビデオトラックへ配置します。
3. 適用先のクリップを選択します。
4. **Layer Input** エフェクトを追加します。
5. **Source Layer** で入力元トラックを選びます。
6. **Source Opacity** を調整します。

- 入力元トラックをメインタイムライン上で非表示にしても、アクティブなクリップは取得されます。
- 入力元レイヤー上でヘッダーの目のボタンをオフにしたエフェクトやエフェクトグループはスキップされます。詳しくは [エフェクトのバイパス](/docs/ja/effects/bypass/) を参照してください。
- 自分自身のトラックや、循環参照になるトラックは選択できません。
- トラック参照はトラックの並べ替え後も維持されます。ピッカーに **(Missing source)** と表示された場合は、利用可能なトラックを選び直してください。

## ディスプレイスメントマップや 3D マテリアルに使う

- **ディスプレイスメントマップ:** **Layer Input Displacement Map** を追加し、**Displacement Map Source** でトラックを選んで各コントロールを調整します。
- **3D マテリアル:** 3D オブジェクトのマテリアル種類を **Layer Source** にし、**Source Layer** でトラックを選んで **Opacity** を調整します。
- **画像ソース:** トラックの代わりに静止画を使うには、ソースピッカーで **Image** を選び、**Source Image** にファイルを指定します。画像はプロジェクトアセットとして保存されます。画像が未設定の場合、エフェクトは入力を変えず、マテリアルは透明になります。

## Custom Shader にトラックを入力する

1. 適用先クリップの **Custom Shader** エフェクトを選択します。
2. 種類が **Layer Input** のカスタムプロパティを追加し、シェーダーの uniform 名に合わせます。
3. プロパティのピッカーで入力元トラックを選びます。
4. 隣のセレクターで取得段階を **Source**、**Masks**、**Effects & Masks** (既定) から選びます。
5. GLSL コード内に対応する `sampler2D` uniform を宣言します。

| 取得段階 | 取得される内容 |
| --- | --- |
| **Source** | エフェクトとマスク適用前のレイヤー。 |
| **Masks** | マスクエフェクトのみを適用したレイヤー。 |
| **Effects & Masks** | 最終的なレイヤー出力 (既定)。 |

各シェーダー入力はそれぞれ独立して取得段階を保持します。Custom Shader の Layer Input プロパティはトラック選択専用です。静止画を入力したい場合は、シェーダー標準の画像入力を使ってください。

書き出し前に、無効または循環参照になっているソースを解消してください。確認には [プレビューとキャッシュ](/docs/ja/workflow/preview-and-cache/) の **Render once** が便利です。シェーダーの基本は [はじめてのシェーダー](/docs/ja/shaders/basics/) を参照してください。
