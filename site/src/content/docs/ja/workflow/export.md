動画や音声の書き出しには **Export > Device** を使います。再生ヘッド位置の静止画を保存するには **Export > Single frame capture** を使います。
**Precomp+** のコンポジションを開いている間は両方の書き出しがブロックされるため、先に **Back to Main** で **Main** へ戻ってください。

## 動画を書き出す (MP4 / WebM / MKV)

**MP4 Export** は既定で有効です。ブラウザーまたはデスクトップアプリで WebCodecs エンコーダーが利用可能である必要があります。

1. **Export** から **Device** を開きます。
2. **Format** で **.mp4 (H.264 / AAC or Opus)**、**.webm (vp8/opus)**、または **.mkv (vp8/opus)** を選びます。
3. **Resolution**、**Aspect ratio**、**Aspect ratio mode** を設定します。
4. **Frame rate** を `1` ～ `240` FPS の範囲で設定します。
5. **Bitrate** (**1x (default)**、**2x**、**4x**、**8x**) を選びます。各選択肢に表示されるのは、選択した解像度とフレームレートに応じた目標ビットレートであり、保証値ではありません。
6. **Start** をクリックします。
7. **Render complete** が表示されたら **Download your video** をクリックします。

MP4 では **Quality** プリセットは無効化されます。画質調整には **Bitrate** を使ってください。
H.264 MP4 はアルファチャンネルを持ちません。奇数の出力寸法が MP4 エンコーダーに渡された場合、右端または下端に 1 ピクセルの黒余白が追加されます。

### MP4 の進行プレビュー

MP4 を書き出している間、進行ページには直前に完了したフレームと、`percent% (n of N)`、**Elapsed**、**Remaining** を示すステータス行が表示されます。**Remaining** は 5 フレーム完了するまで `—` と表示されます。

**Show preview** のチェックを外すと、書き出し中のプレビューをオフにできます。この選択はローカルに保存され、**Show preview** のオン・オフに関係なく書き出される MP4 ファイルは完全に同一です。この進行プレビューは MP4 の書き出し専用です。

## 音声のみを書き出す

**MP4 Export** は WAV と M4A の形式を **Device** に追加します。

1. **Export** から **Device** を開きます。
2. **Format** で **.wav (16-bit PCM)** または **.m4a (AAC)** を選びます。
3. **Start** をクリックします。
4. **Render complete** が表示されたら **Download your audio** をクリックします。

どちらの形式も 48 kHz ステレオです。WAV は非圧縮の 16 ビット PCM を書き出します。M4A は AAC が必要で、128 kbit/s でエンコードします。ブラウザーで AAC エンコードを開始できない場合は **.wav (16-bit PCM)** を選びます。

音声書き出しでは、MP4 と同じ範囲とミックスを使い、トラックのミュート、音声ソロ、Precomp+ の音声を反映します。書き出し範囲に音声がない場合は、その長さの無音を書き出します。

## 1 フレームを静止画として書き出す

1. 書き出したいフレームに再生ヘッドを合わせます。
2. **Export** から **Single frame capture** を開きます。
3. **Resolution** (初期値はプロジェクト解像度) と **Aspect ratio** (初期値はプロジェクト比率) を設定します。
4. 出力全体を満たして端を切り抜くには **Aspect ratio mode** を **crop**、映像全体を残して黒帯を付けるには **black fill** にします。
5. **Format** で **.png**、**.jpg**、または **.webp** を選びます。
6. **.jpg** または **.webp** の場合は **Quality** (**very low**、**low**、**good**、**very good**、**best**) を設定します (PNG では非可逆品質は使われません)。
7. **Start** をクリックし、完了後に **Download your image** をクリックします。

これらのサイズ設定は静止画書き出しのみに適用され、プロジェクト解像度は変更しません。ダウンロードは現在のエディタータブ内で直接行われます。

## 背景を透明にして書き出す

1. **Export** から、静止画の場合は **Single frame capture**、動画の場合は **Device** を開きます。
2. **Format** で、静止画の場合は **.png** または **.webp** を選びます。動画の場合は **.webm (vp8/opus)** または **.mkv (vp8/opus)** を選びます。
3. **Transparent background** が表示されたら、チェックを入れて **Start** をクリックします。

設定画面を開くたびに、チェックボックスは未選択になります。シーンの単色背景や不透明なレイヤーは、その背後のピクセルを覆います。**black fill** は不透明な黒帯を追加します。

## 形式、アルファ、音声

| 形式 | 映像・画像エンコード | 音声 | アルファ (透過) |
| --- | --- | --- | --- |
| **.mp4 (H.264 / AAC or Opus)** | H.264 動画 | AAC 優先、Opus フォールバック | なし |
| **.mkv (vp8/opus)** | VP8 動画 | Opus | VP8 アルファのエンコードに対応している場合に **Transparent background** で有効 |
| **.webm (vp8/opus)** | VP8 動画 | Opus | VP8 アルファのエンコードに対応している場合に **Transparent background** で有効 |
| **.wav (16-bit PCM)** | なし | 16 ビット PCM | なし |
| **.m4a (AAC)** | なし | AAC | なし |
| **.png** | PNG 画像 | なし | **Transparent background** で有効 |
| **.jpg** | JPEG 画像 | なし | なし |
| **.webp** | WebP 画像 | なし | WebP のエンコードに対応している場合に **Transparent background** で有効 |

透過 MKV または WebM を書き出すには **MP4 Export** を有効にします。VP8 の圧縮でアルファ値が変わる場合があります。透過を確認するには、VP8 アルファに対応したプレーヤーまたはエディターを使います。
- **MP4 音声:** 48 kHz ステレオ、128 kbit/s で書き出されます。スケジュールされた音声がない場合は音声トラックを作成しません。AAC が使えない環境では Opus へ切り替わります (再生プレーヤーが MP4 内 Opus に対応していない場合は別プレーヤー、MKV、WebM を試してください)。AAC のタイミング校正チェックに失敗した場合は Opus へ自動切り替えせず停止するため、デスクトップアプリや MKV / WebM を試してください。音声アセット自体がデコードできない場合は WAV へ変換し、[アセット](/docs/ja/workflow/assets/) から置き換えてください。

## 解像度、アスペクト比、フレームレート、ビットレート

- **プリセット:** 426×240、640×360、854×480、1280×720、1920×1080、2560×1440、3840×2160。Single frame capture では、これらと異なるプロジェクト解像度も選択肢として保持されます。設定履歴がない場合、**Device** は 1920×1080・16:9 で始まります。
- **カスタム解像度 (Device):** **Resolution** で **Custom** を選ぶと、**Output size (px)** に `3440×1440` や `2560×1080` のような任意の幅と高さを指定できます。縦横とも `2` ～ `8192` の偶数整数で、総ピクセル数は最大 `33,554,432` です。無効な値を入力するとメッセージが出て **Start** がブロックされます。実際の対応上限はブラウザー、形式、フレームレートにも依存します。
- **アスペクト比:** **Resolution** の長辺を基準に短辺を算出し、偶数へ丸めます。縦長の比率では長辺が縦になります。**Custom** では幅と高さから比率が決まり、**Aspect ratio** を編集すると同じ長辺から新しいカスタム寸法が再計算されます。
- **Aspect ratio mode:** **crop** (既定) は出力全体を満たしてはみ出た端を切り抜きます。**black fill** は映像全体を収めて余白を不透明な黒で埋めます。
- **設定の保持:** Device ページの解像度、カスタムサイズ、アスペクト比、アスペクト比モードはブラウザーに記憶されますが、保存済みプロジェクト自体は変更しません。
- **フレームレート:** `1` ～ `240` FPS の小数を受け付けます (範囲外はクランプされ、数値以外は前回の値を維持します)。書き出しフレームレートを変えても、シーケンスのフレームレート・長さ・`fps`・`zFps` は変わりません。
- **ビットレート:** **1x (default)**、**2x**、**4x**、**8x** は目標ビットレートに倍率を掛けます (例: 1920×1080・30 fps で **1x (default): 9 Mbps target**)。解像度やフレームレートを変えるとラベルも即時更新されます。

MP4 書き出しは可変ビットレートを使うため、**Bitrate** で設定するのは保証値ではなくエンコーダーの目標値です。単純な映像、暗い映像、動きの少ない映像は目標を大きく下回り、細部が多く動きの速い映像は目標を超えることがあります。目標 128 Mbps の設定では、暗い背景にゆっくり動く図形は約 6 Mbps でエンコードされ、画面全体の動くノイズは約 233 Mbps に達します。設定を上げると細部の多いフレームに使えるデータが増えますが、必要のないフレームにデータが足されることはありません。そのため、単純な映像でメディア情報ツールが目標より低いビットレートを示すのは正常です。

## True datamosh で書き出す (WebM)

**True datamosh** は、書き出し後の WebM ファイルから映像キーフレームを除去してカット間で動きを引き伸ばす処理です。[OpenZoid Legacy](/docs/ja/effects/openzoid-legacy/) のプレビュー用 **Datamosh** エフェクトとは独立しています。
VP8 / VP9 の WebM に対応します (**Device** では VP8 を出力)。H.264 MP4 は処理できません。モッシュ後の動画はシーク精度が落ちるため、正確なシークが必要な場合は通常の書き出しも残してください。

1. **Plugins** で **OpenZoid Legacy** を有効にします。
2. コンポジションを開いている場合は **Main** に戻ります。
3. **Export** から **Device** を開きます。
4. **Format** を **.webm (vp8/opus)** にし、その他の書き出し設定を整えます。
5. **True datamosh** を **full video** (最初のキーフレームだけ残し以降を除去) または **at clip cuts** (ビデオクリップの開始・終了から 300 ms 以内の後続キーフレームを除去) に設定します。通常のクリーン出力に戻すときは **off** にします。
6. **Start** をクリックし、レンダリングと **True datamosh...** パスの完了を待ちます。
7. 結果メッセージを確認してから **Download your video** をクリックします。

- **成功時:** ファイル名は `video-moshed.webm` になり、`TRUE MOSH: dropped` で始まるメッセージに除去したキーフレーム数が表示されます。`0` の場合は **full video** を試すかクリップ境界を調整してください。
- **カットが見つからない場合:** **at clip cuts** で対象カットがないと元のファイル名・クリーン映像のまま出力され、`True mosh: no clip cuts to mosh. Clean render delivered.` と表示されます。
- **処理失敗時:** 失敗理由のメッセージと共に元のクリーンなレンダリング結果が提示されます。
- **キャンセル時:** パス実行中に **Cancel** を押すと、ファイルは出力されず完了画面も開きません。

## キャンセル、一時ストレージ、エラーからの復旧

- **キャンセル:** **Cancel** をクリックし、後処理が終わるまで待ってから次の書き出しを始めてください。キャンセルした書き出しからは完成ファイルは生成されません。
- **一時ストレージ:** MP4 書き出しはエンコード中にメモリーまたはディスクの一時領域を使い、完了・キャンセル・失敗の後に自動削除します。短い書き出しでも長い音声ソースがあると多くのメモリーを消費します。不足エラーが出た場合は他のプロジェクトを閉じるか解像度を下げてください。
- **H.264 が利用できない:** **Resolution** または **Frame rate** を下げるか、Chrome、デスクトップアプリ、MKV、WebM を試してください。
- **`WebGL context lost at output index`:** 出力インデックス、プロジェクトフレーム、時刻、ステージを控えてください。エディターを再読み込みする前にプロジェクトを保存し、新しく書き出しをやり直します (失敗した書き出しは再開できません)。繰り返す場合は出力サイズやシーン負荷を下げてください。
- **`Video decode failed for clip`:** クリップ名、要求メディア時刻、出力フレーム、ステージを確認し、[アセット](/docs/ja/workflow/assets/) でそのソースを再読み込みまたは置き換えてから再実行してください。
- **単一フレームキャプチャのエラー:** 失敗すると診断情報付きの **Render error** が開きます。指定されたソースを修復してからやり直してください。
