**Assets** パネルは、プロジェクト内のファイル、フォント、画像、動画、音声、3D モデル、LUT、シェーダー、IES プロファイル、コンポジションを一覧表示します。各アイテムの使用箇所を確認し、見つからないファイルや読み込みに失敗したファイルを修復できます。

**Assets** は既定で有効です。サイドバーの **Assets** タブを開き、**Open Assets** をクリックすると専用ウィンドウが開きます。

## ファイルのドロップと貼り付けで読み込む

PC から Zoidium へファイルを直接ドラッグ&ドロップしたり、クリップボードから貼り付けたりできます。

| ドロップ先 | 動作 |
| --- | --- |
| **Media** パネル (空白部分を含む) | プロジェクトメディアとしてファイルを読み込みます。 |
| **タイムライン** | ファイルを読み込み、ポインター下のトラックのドロップ位置フレームにクリップを配置します。 |
| **プレビュー** | ファイルを読み込み、最上段に新しいトラックを作って再生ヘッド位置にクリップを配置します。 |

ポインター下のトラックに別のクリップがある場合は、新しいトラックへ配置されます。外部ファイルのドロップは、メディアタイルやクリップ、レイヤー行など内部ドラッグの挙動を変えません。

対応形式は画像、動画、音声、フォント、`.pz` プロジェクトです。
`.pz` ファイルをドロップすると、**Import** と同様にメディアアイテムとして読み込まれます (開いているプロジェクトは置き換わりません)。非対応ファイルは読み込みエラーを表示してスキップされます。複数ファイルは順番に読み込まれます。

Ctrl+V (macOS は Cmd+V) で、クリップボードの画像・動画・音声ファイルを貼り付けられます。テキスト入力欄では通常の貼り付けが優先されます。ファイル名のないビットマップ画像は `Pasted image 1.png`、`Pasted image 2.png` のように保存されます。タイムラインにフォーカスがある状態で貼り付けると、再生ヘッド位置に配置されます。

## フォントピッカーでのプロジェクトフォント

**Assets** に読み込んだフォントは、ネイティブ Text、3D Text、Shape+ の **Font Family** / **Fallback Font**、Shader+ テキストのすべての **Font** ピッカーに表示されます。

- ピッカーには、組み込みフォント、名前順の **Project fonts** (読み込んだフォント)、**custom...** の順で並びます。
- ボタンには選択中のプロジェクトフォントがその書体で表示されます (Shader+ テキストではファイル名が表示されます)。
- プロジェクトフォントの選択は 1 回の Undo ステップでアセットキーを保存します。
- 解析に失敗したプロジェクトフォントは、ファイル名と **failed** バッジを表示します。
- 使用中のフォントを削除してもパネルは壊れず、該当プロパティが **Missing** 状態になります。

## 見つからないアセットや失敗したアセットを修復する

書き出しや新規保存の前に、問題のあるファイルを再接続してください。

### 問題のあるアイテムを探す

1. **Assets** を開き、**Open Assets** をクリックします。
2. 使用状況フィルターを **Problems** に切り替えます。
3. アイテムを選び、ステータスと使用箇所一覧を確認します。

**Missing** はファイル本体がプロジェクトにない状態、**Failed** は読み込みに失敗した状態です。**Problems** にはすべての欠落ファイルと、使用箇所が 1 つ以上ある失敗アイテムが表示されます。

使用箇所へ移動するには、使用箇所一覧を開くか **Reveal in Timeline** を選びます。
閉じている Precomp+ コンポジション内の使用箇所はコンポジション名が表示され、**Compositions** からそのコンポジションを開くまで編集できません。

### ファイルを再指定・置換・再読み込みする

- **Locate…** (**Missing** アイテム向け): ディスク上の元のファイルを選び、ステータスが **Ready** になることを確認します。元のファイルと内容が異なる場合は **Replace** が提案されるため、編集可能な全使用箇所を差し替えてよい場合だけ承認してください。
- **Replace…**: 編集可能なすべての使用箇所を、同じ種類の別ファイルに置き換えます。実行前に使用箇所を確認してください。閉じたコンポジション内の使用箇所はスキップされて結果に一覧表示されるため、各コンポジションを開いて個別に置き換えます。
- **Reload**: アイテムの識別子を変えずに、読み込み失敗やネットワーク失敗後の再読み込みを試します。

置換結果が意図と異なる場合は、**Undo** で元に戻せます。

### 不足・失敗したフォントを解決する

1. Assets のプロジェクトメニューから **Resolve Fonts…** を選びます。
2. 各フォントについて **Replace with** から組み込みフォントを選ぶか、**Font file…** でローカルフォントを指定します。
3. そのまま残すフォントは **Keep as is** を選びます。
4. **Replace** をクリックし、テキストのレイアウトと改行を確認します。

読み込みに失敗した組み込みフォントを差し替えずに再試行したい場合は、そのフォント行で **Reload** を使います。

### 修復したプロジェクトを保存する

1. フィルターを再び **Problems** にし、未解決の項目が残っていないことを確認します。
2. 通常の **Save** で新しい `.pz` アーカイブを保存します。
3. 修復後のコピーを確認するまで、元のアーカイブも残しておきます。

**Collect Files…** は利用可能なアセットファイルと欠落レポートを ZIP にまとめますが、編集用の `.pz` プロジェクトアーカイブの代わりにはなりません。アーカイブの保存と復元は [保存と復元ポイント](/docs/ja/development/project-saving/) を参照してください。

## 種類、ステータス、フィルター、検索

**Type** フィルターには、プロジェクト内に存在する場合に **Composition**、**Video**、**Audio**、**Image**、**Font**、**3D Model**、**LUT**、**Shader**、**IES Profile**、**File** が表示されます。

| ステータス | 意味 |
| --- | --- |
| **Ready** | 読み込み中・欠落・失敗ではなく利用可能な状態です。 |
| **Loading** | リソースを読み込み中です。 |
| **Missing** | 参照先のファイルが利用できません。 |
| **Failed** | リソースの読み込みに失敗しました。 |

**Uses** は閉じたコンポジション内を含め、クリップ・プロパティ・キーフレームからの参照数を合計します。

| 使用状況フィルター | 表示対象 |
| --- | --- |
| **All** | すべてのアイテム。 |
| **Used** | 参照が 1 つ以上あるアイテム。 |
| **Unused** | 参照がないアイテム。 |
| **Problems** | 欠落ファイル、および参照が 1 つ以上ある失敗アイテム。 |

**Search** は名前、種類、ステータス、ソース、詳細を対象に単語一致で絞り込みます (入力した全単語に一致する必要があります)。フィルターや検索を適用するとフラットな一覧になり、すべて解除するとフォルダー階層が表示されます。

## アイテムコマンド

コマンドは選択中のアイテムに適用できる場合だけ有効になります。閉じたコンポジション内の使用箇所はスキップまたは報告されるか、先にそのコンポジションを開く必要があります。

| コマンド | 動作 |
| --- | --- |
| **Import…** | ファイルをプロジェクトアイテムとして読み込みます。フッテージは Media パネルにも表示されます。 |
| **Reveal in Timeline** | 開いているタイムライン上の編集可能な使用箇所を選択します。 |
| **Reload** | 置換ファイルを選ばず既存リソースを再読み込みします。 |
| **Locate…** | 欠落した元ファイルを再接続します (別ファイルの場合は確認後に置換フローへ進みます)。 |
| **Replace…** | 編集可能な使用箇所を同じ種類の別ファイルに置き換えます。 |
| **Download** | 利用可能なバイトデータを単独ファイルとしてダウンロードします。 |
| **Delete** | 未使用ファイルを削除します。使用中の場合はクリップやプロパティ参照の削除を確認します。 |
| **Open Composition** | コンポジションのソースタイムラインを開きます。 |
| **Rename** | コンポジションまたはフォルダーの名前を変更します。 |
| **Duplicate** | 独立したコンポジションソースを複製します。 |

コンポジション行ではコンポジション向けコマンドを使います。Reload と Download は対象外で、参照中のクリップが残っているコンポジションは削除できません。

## プロジェクトコマンド

| コマンド | 動作 |
| --- | --- |
| **New Folder** | 整理用フォルダーを作成します。 |
| **Remove Unused Items** | 参照のない読み込み済みファイルを確認なしで削除します。Undo で復元できます。 |
| **Consolidate All Footage** | 内容が完全に一致する読み込み済みファイルを 1 つに統合します。 |
| **Collect Files…** | Assets 内のフォルダー構造のまま利用可能なファイルと欠落レポートを ZIP でダウンロードします。欠落データの修復や `.pz` の代わりにはなりません。 |
| **Resolve Fonts…** | 使用中の欠落・失敗フォントを組み込みフォントまたはフォントファイルで置き換えます。 |

組み込みアイテムやプラグインアイテムは **Remove Unused Items** では削除されません。

## フォルダー、ラベル、Undo の範囲

- フォルダーは Assets ウィンドウ内での整理用であり、ディスク上のファイルは変更しません。**New Folder Inside** で子フォルダーを作り、**Delete Folder** を実行すると中身は削除されず親階層へ移動します。
- **Label ▸** メニューで、アイテムとフォルダーに 16 色のラベルまたは **None** を設定できます。フォルダー構造とラベルはプロジェクトと一緒に保存されます。
- アイテムやフォルダーを別フォルダーへドラッグして移動し、空白領域へドロップするとルート階層へ戻せます。対応フッテージはタイムラインへ、対応アイテムはアセットプロパティ行へドロップできます。
- **Undo 対応:** 読み込み、置換、未使用アイテム削除、統合、フォルダー操作、ラベル変更、アセットプロパティ割り当て。
- **Undo 非対応:** Reload、Collect Files、Download。
