title: Precomp+ コンポジション
description: タイムライン上のクリップを再利用可能なネストコンポジションにまとめ、内部の 3D シーン編集や Main からの書き出しを行う手順です。
---
**Precomp+** を使うと、選択したクリップをプロジェクトメディアとして保存される再利用可能なコンポジションへまとめられます。各コンポジションは独自のビデオ・オーディオトラックを持ち、コンポジションクリップはその共有ソースを参照します。

## 選択クリップをプリコンポーズする

1. **Plugins** で **Precomp+** を有効にします。
2. タイムラインでビデオクリップ、オーディオクリップ、または両方を選択します。
3. サイドバーの **Comps** を開きます。
4. **Pre-compose selection** をクリックします。
5. 一意の **Name** を入力します (大文字・小文字の区別なしで一意、最大 60 文字、**Main** は不可)。
6. **Pre-compose** をクリックします。

- 選択にビデオが含まれる場合、現在のタイムラインの空いているトラックに、選択範囲全体を覆う 1 つのコンポジションクリップが配置されます。選択外のクリップが区間を塞いでいる場合は、先に移動してください。
- オーディオだけの選択では、元のタイムラインに置き換えクリップは置かれません。その音声を **Main** の再生や書き出しに含めたい場合は、ビデオクリップも一緒に選択してください。

プリコンポーズでは、選択クリップの相対タイミング、トラック順、トラックスイッチが維持されます。最も早い開始位置がソースのフレーム `0` になります。移動されたクリップのリンクは解除されます。ソースの長さは最後のクリップ終了位置に一致します (最小 `1` フレーム)。

## コンポジションを開いて編集する

1. **Comps** で **Open Compositions** をクリックします。
2. コンポジションを選び、**Open** をクリックするかダブルクリックします。
3. タイムラインでクリップを編集します。
4. 終わったら **Compositions** ウィンドウの **Back to Main** をクリックします。

タイムライン上のコンポジションクリップを右クリックして **Open source composition** を選ぶことでも開けます。

### コンポジション切り替えと Undo

別のコンポジションを開く操作や **Main** に戻る操作は、それぞれ 1 つの **Undo** ステップとして記録されます。

- **Main** に戻った後でコンポジション内の編集を取り消すには、1 回目の **Undo** でコンポジションを再び開き、2 回目の **Undo** で編集を戻します。
- **Redo** は編集とタイムライン切り替えを元の順序でやり直します。
- すでに開いているタイムラインを再度開いても Undo ステップは増えません。**Compositions** ウィンドウを閉じるだけではタイムラインは切り替わりません。

## コンポジション内の 3D シーンを編集する

1. Scene クリップを含むコンポジションクリップを右クリックします。
2. **Edit 3D in comp** を選びます。複数の Scene クリップがある場合はメニューから対象を選びます。
3. グリッド、ビューコントロール、オブジェクトプロパティを使って Scene を編集します。
4. **Comps** を開き、**Back from 3D edit** をクリックして元のコンポジションへ戻ります。

切り替え自体も 1 つの Undo ステップになるため、戻った後に 3D 編集を取り消すには **Undo** を 2 回押します。

## 再利用、ネスト、削除

| コントロール | 動作 |
| --- | --- |
| **Open** | 編集中のタイムラインをソースコンポジションへ切り替えます (ダブルクリックでも同じ)。 |
| **Back to Main** | ソースへの編集を保持したままメインタイムラインに戻ります。 |
| **Name** | ソース名を変更します (大文字・小文字を区別せず一意、最大 60 文字、**Main** 不可)。 |
| **Duplicate** | 新しい識別子を持つ独立したコンポジションソースを作成します。 |
| **Delete** | **Main** や他のコンポジションから参照されている間は削除を拒否します。 |
| **New composition** | 空のコンポジションソースを作成します (**Main** にクリップは配置されません)。 |

- **編集の共有:** 同じコンポジションを参照する複数のクリップは、ソースへの編集を共有します。独立した別コピーが必要な場合は **Compositions** の **Duplicate** を使ってください。タイムライン上でクリップを複製しただけでは元のソースを参照し続けます。
- **ネスト:** コンポジション内に別のコンポジションクリップを入れられます (最大 `16` 階層)。自己参照ループを作る移動は拒否され、描画側でも再帰経路を停止します。
- **音声とトラック:** ネストされた映像は元のトラック順を保ち、無効なビデオトラックは描画しません。ネストされた音声はクリップタイミング、音量、パンを含めて Main の通常オーディオ経路で再生され、親コンポジションクリップの時間範囲に収まります。コンポジションクリップを持たない音声専用ソースは Main の再生や書き出しには流れません。
- **削除とプラグイン無効化:** **Delete** は **Main** や他コンポジションに残る参照を報告します。先に参照クリップを削除してください。コンポジションが残っているプロジェクトでは **Precomp+** を無効にできません。

## 保存と書き出し

- **書き出しは Main から実行:** ソースコンポジションを開いたままでは動画書き出しや単一フレームキャプチャは実行できません。**Export Main** が表示されたら書き出しページを閉じ、**Back to Main** で戻ってから再実行してください。詳しくは [動画とフレームの書き出し](/docs/ja/workflow/export/) を参照してください。
- **保存:** コンポジションを開いたまま保存しても、**Main** と現在のソース編集の両方が保存され、Precomp+ の依存関係が記録されます。プラグインが無効な環境でもコンポジションデータは再保存向けに保持されますが、描画は行われません。詳しくは [保存プロジェクトの描画互換性](/docs/ja/development/project-compatibility/) を参照してください。
