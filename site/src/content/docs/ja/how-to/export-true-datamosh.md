---
title: True datamosh で書き出す

  label: True datamosh の書き出し
---
レンダリングした WebM ファイルからキーフレームを削除し、カットをまたいで動きをにじませます。この処理は **Datamosh** プレビューエフェクトとは別です。

VP8 または VP9 の WebM を使ってください。現在の **Device** セレクターでは VP8 を選択できます。True datamosh は H.264 MP4 を処理しません。処理後のファイルでは正確なシークができないため、正確なシークが必要な場合は未処理の書き出しも残してください。

## 書き出し処理を有効にする

1. **Plugins** で **OpenZoid Legacy** を有効にします。
2. コンポジションを開いている場合は、**Main** に戻ります。
3. **Export** を開き、**Device** を選択します。
4. **Format** で **.webm (vp8/opus)** を選択します。
5. 他の[書き出しオプション](/docs/ja/reference/export-options/)を設定します。
6. **True datamosh** で **full video** または **at clip cuts** を選択します。未処理のまま書き出す場合は、**off** のままにします。
7. **Start** をクリックします。
8. レンダリングと **True datamosh...** の処理が終わるまで待ちます。
9. **Download your video** をクリックする前に、結果の注記を読みます。

**full video** は最初の動画キーフレームを残し、それ以降のキーフレームを削除します。**at clip cuts** は、動画クリップの開始位置と終了位置から 300 ms 以内にある、最初以外のキーフレームを削除します。

## 結果を確認する

成功した場合、ファイル名は `video-moshed.webm` です。注記は `TRUE MOSH: dropped` で始まり、削除したキーフレーム数を示します。削除数がゼロの場合は、**full video** を試すかクリップの境界を変更してください。

**at clip cuts** でクリップの境界が見つからない場合は、元のファイルとファイル名が渡されます。注記は `True mosh: no clip cuts to mosh. Clean render delivered.` です。

処理に失敗した場合、完了ページでは元のファイル名で未処理の動画をダウンロードできます。ダウンロードする前に失敗の注記を読んでください。未処理のファイルが必要な場合は、**True datamosh** を **off** にして再度書き出してください。

処理中にキャンセルするには、**Cancel** をクリックします。キャンセル後は、処理後のファイルも完了ページも渡されません。準備ができたら、新しく書き出してください。

## プレビューエフェクトを別に使う

ビューポートで再現可能なエフェクトを作るには、レイヤーに **Datamosh** を追加します。設定ウィンドウについては、[OpenZoid Legacy](/docs/ja/how-to/use-legacy-effects/)を参照してください。このエフェクトは **True datamosh** を有効にしません。書き出し処理もプレビューエフェクトを追加しません。
