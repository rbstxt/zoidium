編集中の内容を閉じずに、Zoidium のエディターウィンドウを別のモニターに移動します。

## ウィンドウを外に移動する

1. **Graph editor**、**Shader**、**Expression**、**Trapcode Designer** などのエディターウィンドウを開きます。
2. タイトルバーの **Pop out** をクリックします。
3. ブラウザーがポップアップをブロックした場合は、このサイトのポップアップを許可します。もう一度 **Pop out** をクリックします。
4. ブラウザーウィンドウを目的のモニターにドラッグします。

## ウィンドウを戻す

1. ポップアップのタイトルバーの **Return to editor** をクリックします。
2. OS の操作で戻す場合は、ブラウザーウィンドウを閉じます。

フローティングウィンドウは、移動前の位置とサイズに戻ります。ブラウザーが許可する場合、次のポップアウトではポップアップの最後の位置とサイズを使います。

## エディターを閉じる

1. エディター自体を閉じるには、タイトルバー内の **Close** をクリックします。
2. すべてのポップアップを閉じるには、Zoidium のメインページを閉じます。

編集中のエフェクトを削除した場合やプロジェクトを置き換えた場合も、対応するエディターを閉じます。ウィンドウ間を移動しても、未適用のテキストは編集中のエディターに残ります。シェーダーや式のテキストをプロジェクトに適用するには、**Apply** をクリックします。
