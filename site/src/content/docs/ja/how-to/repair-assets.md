---
書き出しや新しいアーカイブの保存の前に、プロジェクトに必要なファイルを再接続します。

## 問題のある項目を探す

1. タブがない場合は、**Plugins** で **Assets** を有効にします。
2. **Assets** を開き、**Open Assets** をクリックします。
3. 使用状況のフィルターを **Problems** に設定します。
4. 項目を選択し、状態と使用状況を確認します。

**Missing** はファイルがプロジェクトにない状態です。**Failed** は項目の読み込みに失敗した状態です。**Problems** は不足するすべてのファイルと、プロジェクトで使っている読み込み失敗の項目を含みます。

使用箇所を探すには、選択した項目の使用箇所一覧を開くか、**Reveal in Timeline** を選択します。閉じたコンポジション内の使用箇所は、先に **Compositions** でそのコンポジションを開いてください。コンポジションを切り替えると Undo と Redo の履歴が消去されます。

## 元のファイルを探す

1. **Missing** の項目で **Locate…** を選択します。
2. コンピューター上の元のファイルを選択します。
3. 項目の状態を再確認します。

元のファイルと異なる場合、Assets は **Replace** を提示します。置き換え可能なすべての箇所のソースを変えるつもりの場合にだけ承認してください。それ以外の場合はキャンセルし、元のファイルを選び直してください。

## ソースを置き換えるか再読み込みする

ソースを置き換える前に、使用箇所を確認してください。**Replace…** は、その項目の編集可能な使用箇所をすべて変更します。閉じたコンポジション内の使用箇所はスキップされることがあり、スキップ分は結果に表示します。そのコンポジションを開き、使用箇所を別に置き換えてください。

1. 項目を選択します。
2. 別の内容を使う場合は、**Replace…** を選択し、同じ種類のファイルを選びます。
3. 読み込みやネットワークのエラー後に既存のソースを再試行する場合は、**Reload** を選択します。
4. 結果の通知と描画内容を確認します。

置き換えの結果が意図と違う場合は、コンポジションを切り替える前に Undo を使ってください。

## 不足するフォントを解決する

1. Assets のプロジェクトメニューを開きます。
2. **Resolve Fonts…** を選択します。
3. 問題のある各フォントについて、**Replace with** で組み込みフォントを選ぶか、**Font file…** をクリックします。
4. フォントを変更しない場合は、**Keep as is** を選択します。
5. **Replace** をクリックします。
6. テキストの配置と改行を確認します。

失敗した組み込みフォントを同じフォントのまま再試行する場合は、その項目の **Reload** を使ってください。

## 修復したプロジェクトを保存する

1. フィルターを **Problems** に戻し、残りの項目を確認します。
2. 通常のプロジェクト保存操作で新しい `.pz` アーカイブを保存します。
3. 修復したコピーを確認するまで、以前のアーカイブを残します。

**Collect Files…** はアセットファイルとレポートをダウンロードします。編集可能なプロジェクトアーカイブの代わりにはなりません。アーカイブの復旧については、[保存と復元ポイント](/docs/ja/development/project-saving/)を参照してください。整理と削除のコマンドは、[Assets リファレンス](/docs/ja/reference/assets/)を参照してください。
