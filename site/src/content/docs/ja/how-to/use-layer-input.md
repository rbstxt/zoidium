---
title: トラックや画像を Layer Input に使う
sidebar:
  label: Layer Input を使う
---
別の動画トラックをエフェクトの入力やマテリアルのマップに使います。Layer Input は最上位の動画トラックを選択します。入れ子の個別オブジェクトは選択しません。

## ソーストラックを合成する

1. **Plugins** で **Layer Input** を有効にし、実験的機能の警告を承認します。
2. ソースの内容を別の動画トラックに配置します。
3. 合成先のレイヤーを選択します。
4. **Layer Input** エフェクトを追加します。
5. **Source Layer** でソーストラックを選択します。
6. **Source Opacity** を調整します。

ソーストラックはメインのタイムラインで非表示にしておけます。Layer Input はそのアクティブなクリップを引き続きキャプチャーします。合成先には、自分自身のトラックや循環参照になるトラックは選択できません。

ピッカーに **(Missing source)** が表示された場合は、利用可能なトラックを選択してください。トラックを並べ替えても参照は保持されます。

## ディスプレイスメントマップやマテリアルに使う

レイヤーを変位させるには、**Layer Input Displacement Map** を追加します。**Displacement Map Source** でトラックを選び、変位のコントロールを調整します。

3D オブジェクトにトラックを貼り付けるには、マテリアルの種類に **Layer Source** を選択します。**Source Layer** でトラックを選び、**Opacity** を調整します。

トラックの代わりに画像を使う場合は、ソースピッカーで **Image** を選択します。**Source Image** でファイルを選びます。プロジェクトは画像をアセットとして保存します。画像を指定していない場合、エフェクトは入力を変更せず、マテリアルは透明のままです。

## Custom Shader に入力を追加する

1. 合成先の **Custom Shader** エフェクトを選択します。
2. 種類が **Layer Input** のカスタムプロパティを追加します。
3. シェーダー入力に使うプロパティ名を付けます。
4. そのプロパティのピッカーでソーストラックを選択します。
5. 隣の入力モードセレクターで **Source**、**Masks**、**Effects & Masks** のいずれかを選択します。
6. 対応するシェーダー入力を `sampler2D` として宣言します。

**Source** はエフェクトとマスクの適用前をキャプチャーします。**Masks** はマスクエフェクトだけを適用します。**Effects & Masks** は最終的なレイヤー出力をキャプチャーする初期値です。各シェーダー入力は個別のモードを保持します。

シェーダー側の処理ではトラックピッカーを使います。Custom Shader で静止画像を使う場合は、シェーダーの画像入力を使ってください。

ソースが利用できない場合や循環参照する場合は、書き出す前に別のトラックを選択してください。[Render once](/docs/ja/how-to/preview-heavy-project/) で結果を確認してください。シェーダー入力については、[シェーダーの基本](/docs/ja/shaders/basics/)を参照してください。
