**Shape+** (既定で有効) を使うと、編集可能なパスやモディファイアを持つベクターシェイプレイヤー、**Scene** / **Adjustment** レイヤーのペンマスク、2D ベクターテキストのレイアウトとアニメーションを作成できます。
座標系は中央 `(0, 0)`、上方向を Y 正とするコンポジションピクセル単位です。ネイティブのレイヤートランスフォームは描画後のレイヤー全体に適用されます。

## ベクターシェイプレイヤーを作る

1. **Media** プリセットの **Shape+** をタイムラインへ追加し、クリップを選択します。
2. **Objects** を開き、**Contents** の **+** をクリックします。
3. **Rectangle**、**Ellipse**、**Polystar**、または **Path** を選び、プロパティを調整します。
4. **Contents** でパスを選択し、メインプレビューの選択ツールやペンツールで頂点・ハンドルを編集します。
5. パスをアニメーションさせるには、ネイティブの **Path** キーフレームをオンにして再生ヘッドを動かし、新しいフレームで形を編集します。

ペイント項目 (**Fill**、**Stroke**、**Gradient Fill**、**Gradient Stroke**) は、同じグループ内で自分より上にある有効なパスすべて (先行するネストグループ内を含む) を描画します。モディファイアもスコープ内の先行パスに作用します。
**Contents** 内の項目はドラッグで順序やグループを変更でき、目のアイコンで非表示にできます。
全項目に **Enabled** (既定 **on**) があります。数値・ベクトル・カラー・グラデーションはアニメーションでき、ドロップダウン選択肢は静的です。

## Scene または Adjustment レイヤーをマスクする

1. タイムラインで **Scene** または **Adjustment** クリップを選択します。
2. ツールバーの **Mask pen (q)** をクリックするか、`Q` を押してペンオーバーレイを開きます。
3. プレビュー内をクリックして頂点を打ち、Enter で確定します。
4. もう一度 `Q` を押すと頂点編集モードになります (アンカーをドラッグして変形、Ctrl+Z で取り消し)。3 回目の `Q` でマスク編集を終了します。
5. **Properties** のレイヤー下にある **Masks** グループで、モード切り替え (**Add**、**Subtract**、**Intersect**)、**Feather**、**Opacity**、反転・有効トグル、パスキーフレームトグル、**Edit**、**Delete** を操作します。
6. マスクをアニメーションさせるには、再生ヘッドを動かしてパスキーフレームトグルをオンにし、頂点を編集します。

マスク編集がオフの間は、プレビューのドラッグ操作は通常のビューポートカメラやトランスフォーム操作に戻ります。別のクリップを選ぶとマスク編集も自動で終わります。
マスクは全エフェクト適用後にカバレッジをアルファへ乗算します。**Scene** レイヤーでは透明に切り抜き、**Adjustment** レイヤーではエフェクトの適用範囲を限定します。開いたパスもカバレッジ計算では閉じた領域として扱われ、シェーダーサンプリングでは開いたまま保持されます。マスクはレイヤーと一緒に保存され、既存プロジェクトの描画には影響しません。

## 2D ベクターテキストを追加・編集・アニメーションする

1. **Shape+** クリップを選択し、**Objects** の **Contents +** メニューから **Text** を選びます。
2. **Font Family** を選び、Properties で **Source Text** を編集します (複数行入力欄はテーマに従い、入力に合わせて伸縮します)。
3. プレビュー上で直接編集するにはテキストをダブルクリックします。描画を保ったままキャレットと選択ハイライトが表示され、文字入力、Enter での改行、矢印キー・Home・End 移動、単語のダブルクリック選択ができます。Escape または外側クリックで 1 回の Undo ステップとして確定します。

- **フォント:** ピッカーには組み込みフォント、ファミリー名順の **Project fonts**、**custom...** の順に並びます。日本語には日本語グリフを含むフォントを選ぶか、欠落グリフ用に **Fallback Font** を設定します。
- **可変フォント:** 多くの組み込みフォントはスタティックフォントであり、**Objects** の項目横に `"Static font: no variable axes"` と表示されます。組み込みのうち **Geist**、**Geist Mono**、**Inter** はウェイト軸を、**Geist Serif** は `ELSH` 形状軸を持ちます。その他の可変フォントを使うには、[アセット](/docs/ja/workflow/assets/) に可変 TTF / OTF / WOFF1 を読み込んで **Font Family** で選んでください。**Style** の直下に **Weight (wght)** のような軸行が現れます。
- **段落テキスト:** **Text Mode** を **box** にし、**Box Size** で折り返し幅と高さを指定します。
- **Text Animator:** **Text** 項目を選び、プレビューのコンテキストメニューから **Add Text Animator** とプロパティを選びます。プロパティと **Range Selector** をアニメーションさせ、必要に応じて **Add Property** や **Add Wiggly Selector** を追加します。アニメーターは同じグループ内で上にあるすべての **Text** 項目に作用し、複数積むと上から順に合成されます。
- **パスへの変換:** **Text** 項目を選び、プレビューのコンテキストメニューで **Convert to Path** (または Objects 行の **Create Shapes from Text**) を実行します。Text Animator の結果を含む現在フレームの形状が文字ごとの **Group** と **Path** へ変換され、1 回の Undo でライブテキストへ戻せます。

#### Round Corners、Twist、Zig Zag、Pucker & Bloat

- **Round Corners:** **Radius** (≥ 0、初期値 `10` px)。
- **Twist:** **Angle** (度、初期値 `0`)、**Center** (2D ベクトル、初期値 `[0, 0]`)。
- **Zig Zag:** **Size** (≥ 0、初期値 `10` px)、**Points** (**corner** / **smooth**、初期値 **corner**)、**Ridges per segment** (`1` ～ `64`、初期値 `3`)。
- **Pucker & Bloat:** **Amount (%)** (`-100` ～ `100`、初期値 `0`)。パス中心に対し頂点を内側へ引くか外側へ膨らませます。

#### Wiggle Paths と Wiggle Transform

どちらも **Wiggles / second** (`0` ～ `100`、初期値 `1`)、**Correlation (%)** (`0` ～ `100`、初期値 `50`)、**Temporal phase (degrees)** (初期値 `0`)、**Spatial phase (degrees)** (初期値 `0`)、**Random seed** (初期値 `1`) を共通して持ちます。

- **Wiggle Paths** は **Size** (≥ 0、初期値 `10` px)、**Points** (**corner** / **smooth**、初期値 **corner**)、**Detail** (`1` ～ `100`、初期値 `5`) を追加します。
- **Wiggle Transform** は **Anchor offset** (`[0, 0]`)、**Position offset** (`[20, 20]`)、**Scale offset (%)** (`[0, 0]`)、**Rotation offset** (`0` 度) を追加します。

#### Offset Paths と Merge Paths

- **Offset Paths:** **Amount** (初期値 `10`)、**Join** (**miter** / **round** / **bevel**、初期値 **miter**)、**Miter limit** (`1` ～ `100`、初期値 `4`)。開いたパスは両側へオフセットされて閉じた輪郭になり (**round** は丸端、他は平端)、負の **Amount** も正と同じ結果になります。
- **Merge Paths:** **Mode** (**merge**、**add**、**subtract**、**intersect**、**exclude**、初期値 **add**)。**merge** は輪郭を保持し、他の 4 つはブール演算を行います。

SVG 読み込みやネイティブからの変換で編集可能なベクター項目が生成されます。ネイティブの Text+ 文字アニメーションは Shape+ 変換時には引き継がれません。

## Text と Text Animator リファレンス

### Text

**Text** は同じグループ内の後続モディファイアとペイントへグリフ輪郭を渡します。離散的な設定はホールドキーとエクスプレッションに対応します。

| コントロール | 型 | 初期値 | 動作 |
| --- | --- | --- | --- |
| **Source Text** | 動的テキスト | `Text` | 複数行文字列。ホールドキーと式に対応。 |
| **Font Family** | 動的フォントアセット | ネイティブ既定 | 主フォント参照。 |
| **Fallback Font** | 動的フォントアセット | なし | 未収録書記素クラスタ用の明示フォールバック (暗黙フォールバックなし)。 |
| **Style** | 動的選択 | Default | 名前付きインスタンスの軸値を書き込みます (式で駆動中の軸は維持して通知)。 |
| 可変軸 (例: **Weight (wght)**) | 動的数値 | フォント既定 | **Style** 直下に軸ごとに 1 行。上下限はフォント定義に従います。 |
| **Size** | 動的数値 | `100` | em あたりのコンポジションピクセル数。 |
| **Tracking** | 動的数値 | `0` | グリフ間隔 (**Size** の 1/1000 単位)。 |
| **Leading** | 動的数値 | `120` | ベースライン間隔 (px)。 |
| **Baseline Shift** | 動的数値 | `0` | 正の値で上へ移動。 |
| **Horizontal Scale (%)**, **Vertical Scale (%)** | 動的数値 | `100` | グリフ拡大率。 |
| **Caps** | 動的選択 | `normal` | `normal`、`all`、`small` (小文字を 75% の大文字表示)。 |
| **Position** | 動的ベクトル | `[0, 0]` | ベースライン原点。 |
| **Alignment** | 動的選択 | `left` | `left`、`center`、`right`、`justifyLeft`、`justifyCenter`、`justifyRight`、`justifyAll`。 |
| **Text Mode** | 動的選択 | `point` | `point` (折り返しなし) または `box`。 |
| **Box Size** | 動的ベクトル | `[600, 400]` | 折り返し幅と表示高さ (高さを超える行は非表示)。 |
| **First-Line Indent** | 動的数値 | `0` | 各段落 1 行目の字下げ。 |
| **Space Before**, **Space After** | 動的数値 | `0` | 段落前後の余白 (px)。 |

- **対応形式:** TTF、OTF、可変 TrueType、CFF2、WOFF1。WOFF2 は非対応ステータスを表示しつつ参照を保持します。欠落フォントは項目横に状態を表示します。
- **折り返し:** Box テキストはラテン語を単語単位 (幅超過時は書記素単位)、CJK を書記素単位で折り返します。改行で段落が分かれます。均等配置は空白を広げ、空白のない CJK 行では書記素間に幅を配分します。
- **可変軸:** アニメーション付きの **Style** は独自アニメーションを持たない軸に値を設定します。非アクティブな軸は `axisStore` に保存され、同じ軸タグを持つフォントへ戻すと復元されます。オプションのテキストエンジンバンドルは初回使用時に読み込まれます (Electron は未検証)。

### Text Animator

**Text Animator** は同じグループ内で上にあるすべての **Text** 項目 (先行ネストグループ内を含む) に作用し、上から順に合成されます。上にテキストがない場合は `"No text above this animator"` と表示されます。
有効な各プロパティは `neutral + (value - neutral) * s` (`s` は単位ごとのセレクター合成値) を適用します。プロパティの追加・削除はコンテキストメニューの **Add Property** / **Remove Property** で行います。文字単位の Opacity、Fill Color、Stroke Color、Stroke Width は未対応です。

| プロパティ | 型 | 初期値 | 動作 |
| --- | --- | --- | --- |

### パス変換とキャッシュ上限

- **Create Shapes from Text:** 現在フレームの **Text** を文字グループへ置き換えます (各輪郭が個別 **Path**。空白はグループなし。合字の輪郭は先頭文字へ入り残りは空グループ。結合記号は基底文字グループに保持)。巻き方向・親ペイント順・アニメーター行を保ち、1 回の Undo でライブテキストへ戻せます。
- **キャッシュ上限:** レイアウト・グリフジオメトリ・グリフペイント各 `8` MiB、解析輪郭・シェーピング結果各 `2` MiB、フォールバック判定 `512` KiB、エンジンシェーピング `1` MiB、輪郭 `4` MiB。接触・重複・斜線・曲線グリフは複合フィルを使い、**Trim Paths** の `Individually` モードや変形付き **Repeater** ではグリフ単位のフィル再利用が無効になります。
