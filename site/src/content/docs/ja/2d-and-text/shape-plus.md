**Shape+** (既定で有効) を使うと、編集可能なパスやモディファイアを持つベクターシェイプレイヤー、**Scene** と **Adjustment** レイヤーのアニメーション付きマスク、2D ベクターテキストのレイアウトとアニメーションを作成できます。
座標系は中央 `(0, 0)`、上方向を Y 正とするコンポジションピクセル単位です。ネイティブのレイヤートランスフォームは描画後のレイヤー全体に適用されます。

## ベクターシェイプレイヤーを作る

1. **Media** プリセットの **Shape+** をタイムラインへ追加し、クリップを選択します。
2. **Objects** を開き、**Contents** の **+** をクリックします。
3. **Rectangle**、**Ellipse**、**Polystar**、または **Path** を選び、プロパティを調整します。
4. **Contents** で **Path** をクリックするか、プレビュー上の輪郭をクリックして、選択ツール (`V`) やペンツール (`Q` または `P`) で頂点とハンドルを編集します。
5. パスをアニメーションさせるには、アニメーション切り替えのストップウォッチ (`⏱`) またはキーフレームのひし形をクリックして再生ヘッドを動かし、別のフレームで形を編集します。

プレビューから直接シェイプレイヤーを作ることもできます。対応するクリップを選んでいない状態で `Q` (または `P`) を押してプレビューをクリックすると、再生ヘッド位置の新しいビデオトラックに **Shape+** クリップが 1 回の **Undo** で追加されます。新しいクリップには最初のパス、既定の塗り、`2` px の線、既定長 `180` フレームが設定されます。

ペイント項目 (**Fill**、**Stroke**、**Gradient Fill**、**Gradient Stroke**) は、同じグループ内で自分より上にある有効なパスすべて (先行するネストグループ内を含む) を描画します。モディファイアもスコープ内の先行パスに作用します。
**Contents** 内の項目はドラッグで順序やグループを変更でき、目のアイコンで非表示にできます。
全項目に **Enabled** (既定 **on**) があります。数値・ベクトル・カラー・グラデーションはアニメーションでき、ドロップダウン選択肢は静的です。

## Scene または Adjustment レイヤーをマスクする

1. タイムラインで **Scene** または **Adjustment** クリップを選択します。プレビューが 3D のパースペクティブカメラ表示になっている場合は、`C` を押してコンポジット表示へ切り替えてください。
2. `Q` (または `P`) を押すか、ツールバーの **Mask pen (q)** をクリックしてペンツールを待機状態にします。`Q` を押しただけではマスクは作られません。
3. プレビュー内をクリックして頂点を打ちます。最初の頂点をクリックするとパスが閉じ、`Escape` または `V` で描画を終えられます。`Enter` を押す必要はありません。
4. 既存のマスクを編集するには、**Properties** の **Masks** でマスク名をクリックするか、**Edit** またはプレビュー上の輪郭をクリックします。
5. **Masks** の各マスク行で、合成モード、**Feather**、**Opacity**、**Expansion**、キーフレーム、ロック、重ね順を調整します。

マスクは全エフェクト適用後にカバレッジをアルファへ乗算します。**Scene** レイヤーでは透明に切り抜き、**Adjustment** レイヤーではエフェクトの適用範囲を限定します。開いたパスもカバレッジ計算では閉じた領域として扱われ、シェーダーサンプリングでは開いたまま保持されます。マスクはレイヤーと一緒に保存され、既存プロジェクトの描画には影響しません。

### マスク行のコントロール

**Properties** の **Masks** には、マスクごとに開閉式の行が表示されます (既定は展開状態)。`▾` や `▸` で詳細を折りたたみ・展開でき、一覧末尾の **+ Add mask** で新しいマスクを追加できます。

| コントロール | 範囲または選択肢 | 初期値 | 動作 |
| --- | --- | --- | --- |
| 有効化 (`●` / `○`) | オン / オフ | オン | マスクをカバレッジ計算に含めるか切り替えます。 |
| マスク名 | クリック / `Shift` クリック | `Mask 1`、`Mask 2` ... | クリックするとプレビューでそのマスクが編集対象になります。`Shift` クリックで複数選択できます。アクティブなマスクには `●` が付きます。 |
| 合成モード | **Add**、**Subtract**、**Intersect** | **Add** | 一覧の上から順にマスクを合成します。 |
| **INV** | オン / オフ | オフ | マスクのカバレッジを反転します。 |
| キーフレームのひし形 | `◇`、`◈`、`◆` | オフ (`◇`) | 白抜きはアニメーションオフ、枠強調 (`◈`) はアニメーションオンで現在フレームにキーなし、塗りつぶし (`◆`) は現在フレームにキーありを示します。クリックでアニメーションの有効化やキーの追加・削除を行います。 |
| ストップウォッチ (`⏱`) | オン / オフ | オフ | パスのアニメーションをオン・オフします。オフにすると現在フレームの形状が残ります。 |
| **Edit** | ボタン | — | マスクを選択し、プレビューの頂点編集へフォーカスを移します。 |
| 削除 (`×`) | ボタン | — | マスクを削除します。 |
| 前へ (`‹`) / 次へ (`›`) | ボタン | — | プロジェクト時間上で前後のパスキーフレームへ再生ヘッドを移動します。 |
| **Feather** | `0` ～ `500` px | `0` | マスク境界をピクセル単位でぼかします。 |
| **Opacity** | `0` ～ `100`% | `100`% | マスクの不透明度を調整します (保存データは `0` ～ `1`)。 |
| **Expansion** | `-128` ～ `128` px | `0` | フェザー・不透明度・反転・合成の前に、レイヤーピクセル単位で領域を拡張 (正) または縮小 (負) します。`0` では従来どおりの描画経路を使います。範囲外の値は無断で丸められずエラーとして拒否されます。 |
| **Outline color** | `#rrggbb` | `#58a6ff` から始まるパレット | プレビュー上の輪郭線カラーを変更します。 |
| **Name** | テキスト | `Mask 1` ... | 内部 ID や参照を変えずにマスク名を変更します。 |
| ロック (`🔓` / `🔒`) | オン / オフ | 解除 | 形状、頂点構成、キーフレーム、プロパティ変更、削除を禁止します。選択、ロック解除、順序変更 (`▲` / `▼`) はそのまま行えます。 |
| **Duplicate** | ボタン | — | 形状・キーフレーム・設定・合成モードを保ったまま、新しいマスク ID と頂点 ID で直後に複製します。 |
| 上へ (`▲`) / 下へ (`▼`) | ボタン | — | マスクの合成順を入れ替えます。ロック中のマスクも移動できます。 |

### 複数マスクをまとめて編集する

- **Properties** の **Masks** でマスク名を `Shift` クリックすると、同じレイヤー上のマスクを複数選択できます。
- 複数選択中も、ペン描画とタイムラインの基準になるアクティブマスク (`●`) は 1 つに保たれます。
- 選択ツール (`V`) で移動・拡大縮小・回転を行うと、選択中のロックされていない各マスクの選択頂点が 1 回の **Undo** でまとめて変形されます。ドラッグ中に `Escape` を押すと全体が元に戻ります。
- ロックされたマスクが選択に含まれていても、その形状・キーフレーム・設定は変更されません。
- 上へ (`▲`) または下へ (`▼`) をクリックすると、選択中のマスク同士の相対順を保ったまま合成順を 1 段移動します。
- アクティブなパスや複数マスクの選択状態はパネルを切り替えても維持され、プロジェクトを閉じると解除されます。

## プレビューでパスを描画・編集する

マスクと Shape+ のパスは共通のプレビューエディターで操作します。`Q` と `V` を切り替えたり、別パネルへ移ったりしても、アクティブなパスと頂点選択は保たれます。

### ペンツール (`Q` または `P`)

`Q` (または `P`) を押すとペンツールになります。`Q` は常にペンツールを選び、モードを巡回しません。`Q` を押しただけでは何も作成されず、キャンバスをクリックした時点で開始します。

最初のクリックで作られるものは、タイムライン上の選択状態によって決まります。

- **Scene または Adjustment クリップを選択中:** そのレイヤーに新しいマスクを開始します。
- **Shape+ クリップを選択中:** 開いたアクティブパスがあれば続きを描き、なければ選択中または親のグループ内に新しいパスを開始します。
- **クリップ未選択、複数選択、または非対応レイヤーを選択中:** 再生ヘッド位置の新しいビデオトラックに **Shape+** クリップを作成し、最初のパス、塗り、`2` px の線を 1 回の **Undo** で追加します。

ペンツールでの描画操作は次のとおりです。

- 空白をクリックするとコーナー頂点を打ち、ドラッグすると対称なベジェハンドルを引き出せます。
- 頂点の配置中やハンドル操作中に `Shift` を押すと、角度が 45 度刻みに制限されます。
- ハンドルを引き出しながら `Alt` (macOS では `Option`) を押すと、出力側ハンドルだけを切り離して動かせます。
- 開いたパスの最初の頂点をクリックするとパスを閉じます。描画を終えるために `Enter` を押す必要はありません (`Enter` も任意の終了操作として使えます)。
- 開いたパスの端点をクリックすると、その端から続きを描けます。描画していない開いたパスの始点から続ける場合は、パス方向が反転してから追記されます。
- 既存の頂点をクリックすると削除、セグメントをクリックすると頂点を挿入できます。
- ペン操作中に `Ctrl` (macOS では `Cmd`) を押し続けると、一時的に選択ツール (`V`) に切り替わります。キーを離すと描画中のパスを保ったままペンツールへ戻ります。

### ペンカーソル、マーカー表示、サイズ設定

ペンツールのホバー表示には、次の優先順位があります。

1. **パスを閉じる** (`o` バッジ、拡大リング): 描画中に頂点が 2 つ以上ある開いたパスの始点へ重ねたとき。
2. **描画を続ける** (`/` バッジ、拡大リング): 開いたパスの端点へ重ねたとき。
3. **頂点を削除** (`-` バッジ、赤い頂点ハイライト): 既存の頂点へ重ねたとき。
4. **頂点を追加** (`+` バッジ、セグメントのハイライト): 曲線セグメントへ重ねたとき。
5. **開始・追記** (クロスヘア、バッジなし): 空白へ重ねたとき。

ロックされたパスへペンを重ねると、操作不可カーソルが表示されます。

オーバーレイは色だけでなく形でも状態を区別します。

- **最初の頂点:** 二重リング (選択時は塗りつぶし)。
- **選択中の頂点:** 塗りつぶした四角形。
- **未選択の頂点:** 中抜きの四角形。
- **ベジェハンドル:** 円形 (選択時は塗りつぶし)。
- **開いたパスの向き:** 末尾セグメント付近の小さな矢印。

マーカーの大きさは、プレビューオーバーレイを右クリックして **Path Display Settings…** から変更できます。**Vertex size (px)** (初期値 `8` px) と **Handle size (px)** (初期値 `6` px) を `2` ～ `32` px の範囲で設定できます。設定はブラウザーのローカルストレージに保存され、表示サイズを変えてもクリック判定半径 (`9` CSS px) は固定のままです。

### 選択ツール (`V`)、輪郭クリック、重なり順の切り替え

`V` を押すか **Shape+ selection (v)** をクリックすると、頂点とハンドルの編集モードになります。アクティブなパスがないときは、通常のレイヤー選択とトランスフォームへ譲ります。

- **パスを選んで編集を始める:** **Properties** でマスク名をクリックするか、**Objects** で **Path** をクリックするか、プレビュー上で見えている輪郭をクリックします。マスク名をクリックすると、必要に応じてそのクリップが選択され、再生ヘッドがクリップ先頭へ移動します。
- **重なったパスを順に切り替える:** クリック判定はズーム倍率によらず `9` CSS px 固定で、ハンドル、アンカー、セグメント、手前のパスの順に優先されます。同じ場所 (`9` px 以内) を繰り返しクリックすると、アクティブなパスを含め重なったパスを手前から奥へ順に切り替えます。ポインターを `9` px 以上動かす、フレームを変える、プレビューから出る、パネルで別項目を選ぶと巡回はリセットされます。
- **頂点を選ぶ:** クリックで単一選択、`Shift` クリックで追加・解除します。`Ctrl+A` (macOS では `Cmd+A`) でアクティブなパスの全頂点を選択します。
- **マーキー選択:** パスがアクティブな状態で空白をドラッグすると矩形選択できます。通常ドラッグは選択を置き換え、`Shift` ドラッグはドラッグ開始時の選択に対して枠内の頂点を反転します。
- **ハンドルの切り離しと変換:** `Alt` (macOS では `Option`) を押しながらアンカーをクリックすると Corner と Smooth を切り替えます (`V` でのダブルクリックも同様です)。`Alt` を押しながらハンドルをドラッグすると、連動を切って片側だけ動かせます。右クリックメニューからは **Corner Points**、**Smooth Points**、**Symmetric Points**、**Independent Points**、**Open Path** / **Close Path**、**Reverse Path Direction** も実行できます。
- **矢印キーでの微調整:** 選択した頂点を矢印キーで `1` px、`Shift` 併用で `10` px ずつ移動します (1 回の **Undo** にまとまります)。

### 自由変形、セグメントドラッグ、スナップ

- **自由変形:** `V` でロックされていないパス上の頂点を 2 つ以上選択すると (複数選択したマスク間でも有効)、画面空間のバウンディングボックスが表示されます。枠内ドラッグで移動、角ハンドルで拡大縮小、回転ハンドルで回転でき、頂点とベジェハンドルが選択中心を基準にまとめて変形されます。グループやレイヤーの変形を逆変換して反映します。`Shift` を押すと、移動は 45 度刻み、拡大縮小は縦横比維持、回転は 15 度刻みに制限されます。
- **セグメントドラッグ:** `V` で曲線セグメント上を直接ドラッグすると、両端の頂点がハンドルベクトルを保ったまま一緒に移動します。
- **スナップ:** 頂点の配置や移動では `9` CSS px 以内でスナップが働きます。優先順位は、未選択の頂点 (ロック中のパス上の頂点を含む)、コンポジション枠の端、操作開始点を通る水平・垂直軸の順です。`Shift` による角度・比率制限が先に適用され、スナップ中は破線ガイドが表示されます。

### Set First Vertex (始点の変更)

プレビューでアンカーまたはハンドルを右クリックし、**Set First Vertex** を選びます。

- 閉じたパスでは、形状を変えずに頂点順と 6 チャンネル分のキーフレームブロックを回転させ、選んだ頂点を最初の頂点にします。
- 開いたパスでは、もう一方の端点だけを選べます。実行すると頂点順が反転し、イン側とアウト側のハンドルが入れ替わります。途中の頂点は拒否されます。
- ロックされたパスでは **Set First Vertex** は無効です。

### パン、ズーム、パースペクティブ表示

- **パンとズーム:** プレビューオーバーレイ上で `Space` を押しながらドラッグすると、コンポジット表示をパンできます。`Space` を離すかウィンドウからフォーカスが外れると、描画中のペンパスを崩さずに元のツールへ戻ります。マウスホイールを回すと、ポインター位置を中心に `0.25x` ～ `16x` でズームします。オーバーレイを閉じるとプレビューの位置と倍率は元に戻ります。
- **パースペクティブ表示 (`C`):** パス編集とパス転送には 2D コンポジット表示が必要です。3D **Scene** のパースペクティブカメラ表示中はデータを変更せず編集をブロックし、`C` でコンポジット表示へ戻すよう案内します。

### ショートカット、Escape の段階、Delete の範囲

パス用ショートカットは、プレビューまたはパス関連コントロールにフォーカスがあり、テキスト入力中でなく、IME 変換も行っていないときだけ動作します。**Graph Editor 2** にフォーカスがある間は `V` はグラフ側が優先されます。

| 操作 | 動作 |
| --- | --- |
| `Q`、`P` | モードを巡回せずペンツールを選択します。 |
| `V` | アクティブなパスがあれば選択ツール (`V`) に切り替え、なければネイティブのレイヤー選択へ譲ります。 |
| `Ctrl` または `Cmd` (ペン中に長押し) | 押している間だけ一時的に選択ツール (`V`) になります。修飾付きショートカット (`C`、`X`、`V`、`Z`、`Y`、`A`、`D`、`G`、`[`、`]` など) はそのまま各ハンドラーへ渡されます。 |
| `Alt` または `Option` | アンカーをクリックすると Corner と Smooth を切り替え、ハンドルをドラッグすると連動を切ります。 |
| `Escape` | ドラッグや矢印微調整中なら操作を取り消して元の状態へ戻します。ペン描画中なら描画を終えてパスと選択を保ちます。さらにもう一度押すと頂点選択を解除します。 |
| `Enter` | ペン描画を終えるための任意ショートカットです (必須ではありません)。 |
| `Delete`、`Backspace` | プレビューまたはパス関連コントロールにフォーカスがあり、ロックされていないパスで頂点が選択されているときだけ頂点を削除します。ロック中は解除を促すメッセージを表示します。それ以外はフォーカス中のネイティブパネルへ譲ります。全頂点を消すとパス自体が削除されます。 |
| `Space` + ドラッグ、ホイール | 編集中にコンポジットプレビューをパン・ズームします。 |
| `T`、`C`、`M` | ネイティブ動作を保ちます。`T` を押す (またはレイヤートランスフォームボタンを押す) と、パス選択を消さずにペンを一時停止してレイヤー変形へ操作を渡します。 |

## パスのアニメーションとタイムライン

パスキーフレームは、すべての頂点が持つ 6 チャンネル (`x`、`y`、`inX`、`inY`、`outX`、`outY`) を 1 つの論理キーとして扱います。

### パスキーフレームの操作

パスキーフレームのボタンは、**Properties** の各マスク行、**Objects** の **Path** プロパティ行、プレビューオーバーレイ右下の 3 か所にあります。

- **ひし形の表示状態:** 白抜き (`◇`) はアニメーションオフです。枠強調 (マスク行では `◈`、**Objects** とオーバーレイではアクセント色の `◇`) はアニメーションオンで現在フレームにキーがない状態です。塗りつぶし (`◆`) は現在フレームにキーがある状態です。
- **キーの追加と削除:** ひし形をクリックすると、オフ時はアニメーションを有効化し、オン時は現在フレームの論理キーを追加または削除します。各チャンネルに最低 1 つはキーを残す必要があります。
- **ストップウォッチ (`⏱`):** パスアニメーションのオン・オフを切り替えます。オフにすると、現在フレームで評価された形状が保持されます。
- **オートキー:** アニメーションがオンの状態でキーのないフレームを編集すると、既存の補間値で全チャンネルをサンプリングして 1 つの論理キーを挿入し、1 回の **Undo** として記録します。位置が変わらないドラッグではキーも **Undo** も増えません。
- **前後のキーへ移動:** 前へ (`‹`) や次へ (`›`) をクリックすると、クリップ開始位置とトリムオフセットを踏まえてプロジェクト時間上の最寄りキーへ移動します。

### タイムライン行

**Scene**、**Adjustment**、または **Shape+** クリップを 1 つ選択すると、タイムラインのキーフレームパネルに論理パス行が表示されます。

- マスクは **Masks > `<マスク名>` > Mask Path** として表示されます。
- Shape+ パスは **Shape+ > `<パス名>` > Path** として表示されます (ネイティブのチャンネル別トラックは非表示になります)。

パスのタイムライン行では次の操作ができます。

- ひし形をクリックすると、そのフレームへ再生ヘッドが移動し、対応するパスがアクティブになります。
- 同じ行のひし形を `Shift` クリックすると複数選択できます。
- 選択したひし形を左右へドラッグすると、1 回の **Undo** でキーのタイミングをずらせます。ドラッグ中に `Shift` を押すとフレームスナップを無効にでき、`Escape` でキャンセルできます。
- `Delete` または `Backspace` で選択したひし形を削除します (チャンネルの最後の 1 キーは削除できません)。
- マスク付きクリップの左端をタイムライン上でトリムすると、クリップ内ローカルフレームのマスクキーフレームもクリップ開始位置に合わせて移動し、プロジェクト時間上の位置が保たれます (**Undo** と **Redo** に対応)。

### アニメーション済みパスでの頂点追加と削除

セグメントへの頂点追加、端点の追記、頂点削除、反転、**Set First Vertex** は、すべてのキーフレームに対して 1 回の **Undo** で一括適用されます。

- 頂点挿入では、各キーフレームの 3 次ベジェ曲線を同じセグメントと曲線上パラメーターでド・カステリョ分割するため、キー上の曲線形状が正確に保たれます。
- 頂点削除では、該当頂点とそのチャンネルが全キーフレームから取り除かれます。
- アニメーション済みパスへの構成変更を書き込む前には、全フレームで補間結果が崩れないか検証します。正確な保持を保証できない場合は、理由を表示して変更を拒否し、元のデータをそのまま残します。

## パスのコピー、貼り付け、相互変換

### パスのコピー・切り取り・貼り付け

プレビューオーバーレイ、マスク行、または **Objects** の単一 **Path** にフォーカスがある状態で `Ctrl+C`、`Ctrl+X`、`Ctrl+V` (macOS では `Cmd`) を押すと、マスクと **Shape+** レイヤーの間、または同一レイヤー内でパスをコピー・切り取り・貼り付けできます。

- コピー対象は形状、頂点順と頂点モード、開閉状態、全チャンネルのキーフレームとイージングです。マスクの合成設定 (モード、**Feather**、**Opacity**、**Expansion**、**INV**) は含まれません。
- 貼り付け時は新しい ID が発行され、再生ヘッド時点でのアフィン変換を使ってコピー元レイヤー空間から貼り付け先レイヤー空間へ座標変換されます。ハンドルベクトルは平行移動を除いて変換され、キーフレーム時刻はクリップ内のローカルフレームとして保たれます。
- **Shape+** レイヤーへ貼り付けると既定の **Fill** を持つグループが追加されます。**Scene** または **Adjustment** レイヤーへ貼り付けると既定設定のマスクが追加されます。
- SVG テキストや Shape+ コンテンツの貼り付けも従来どおり動作し、該当しないクリップボード文字列はネイティブの貼り付けへ渡されます。

### Mask と Shape+ の相互変換

- **Mask から Shape+:** **Properties** の **Masks** でマスク行を右クリックし、**Convert to Shape+** を選びます。
- **Shape+ から Mask:** **Objects** の **Contents** で **Path** 項目を右クリックし、**Convert to Mask** を選びます。

変換には、再生ヘッド位置に対応する変換先クリップが必要です。該当するクリップが複数ある場合は **Choose destination clip** メニューから選べます。変換は変換先にパスを作ってから元を削除し、アニメーションを保ったまま 1 回の **Undo** にまとめます。**Mask から Shape+** では塗り付きグループが作られ、**Shape+ から Mask** では既定のマスク設定が使われます。変換に失敗した場合、元のパスは変更されません。

## 現在の制限と拒否される操作

データやアニメーションを意図せず壊すおそれがある場合、Zoidium は自動補正や無断クランプを行わず、理由を表示して操作を拒否します。

| 対象 | 動作と理由 |
| --- | --- |
| **3D パースペクティブ表示** | パスの編集・コピー・貼り付け・変換は拒否されます。`C` を押してコンポジット表示へ切り替えてください。 |
| **ロックされたマスク** | 形状、頂点構成、キーフレーム、プロパティ、切り取り、変換、削除はブロックされます。先にロックを解除してください。選択、ロック解除、順序変更 (`▲` / `▼`) は引き続き可能です。 |
| **特異なトランスフォーム** | レイヤーや親グループのスケールが 0 になるなど逆変換できない状態では、画面座標をパスローカル座標へ戻せないため、ポインター編集とパス転送がブロックされます。 |
| **エクスプレッション駆動のパス** | エクスプレッションが設定されたパスやチャンネルは、編集・構成変更・転送ができません。 |
| **アニメーション済みパスの構成変更** | カーブ制御トゥイーンや非対応トゥイーンを使うパスでは、頂点の追加・追記・削除・反転・**Set First Vertex** が拒否されます。チャンネル間でキー位置がずれていて補完によりイージング区間が変化する場合や、追加・追記時にチャンネル間でキースケジュールやトゥイーンが異なる場合も拒否されます。 |
| **パス転送と変換の拒否** | 回転・シアー・拡大縮小を伴うアフィン変換でカーブ制御トゥイーンや非対応トゥイーンを保てない場合、または回転・シアー下で混在キースケジュールを正確に同期できない場合は拒否されます。変換時に再生ヘッド位置へ対応クリップがない場合や、クリップボード文字列が `262,144` 文字 (`256` KiB) を超える場合も拒否されます。 |
| **開いたパスの Set First Vertex** | 開いたパスで途中の頂点を始点に選ぶ操作は拒否されます。もう一方の端点を選んでください。 |
| **最後のキーフレーム削除** | チャンネルに残る最後の 1 キーは削除できません。アニメーションを止める場合はストップウォッチ (`⏱`) をオフにしてください。 |
| **タイムライン上の衝突とコピー** | パス行のひし形を別の未選択キーと同じフレームへ重ねるドラッグは拒否されます。タイムライン上の個別ひし形に対する `Ctrl+C` / `Ctrl+X` コピー・切り取りは非対応のため、プレビュー・マスク行・**Objects** からパス単位でコピーしてください。 |
| **アニメーション済みプリミティブ** | **Convert to Path** は静的な **Rectangle**、**Ellipse**、**Polystar** だけに対応します。アニメーション付きパラメーターのベイクによる消失を防ぐためです。 |
| **個数と数値範囲の上限** | 1 パスあたり最大 `256` 頂点、1 レイヤーあたり最大 `32` マスクです。**Feather** は `0` ～ `500` px、**Expansion** は `-128` ～ `128` レイヤーピクセルです。 |

## 2D ベクターテキストを追加・編集・アニメーションする

1. **Shape+** クリップを選択し、**Objects** の **Contents +** メニューから **Text** を選びます。
2. **Font Family** を選び、Properties で **Source Text** を編集します (複数行入力欄はテーマに従い、入力に合わせて伸縮します)。
3. プレビュー上で直接編集するにはテキストをダブルクリックします。描画を保ったままキャレットと選択ハイライトが表示され、文字入力、Enter での改行、矢印キー・Home・End 移動、単語のダブルクリック選択ができます。Escape または外側クリックで 1 回の Undo ステップとして確定します。

- **フォント:** ピッカーには組み込みフォント、ファミリー名順の **Project fonts**、**custom...** の順に並びます。日本語には日本語グリフを含むフォントを選ぶか、欠落グリフ用に **Fallback Font** を設定します。
- **可変フォント:** 多くの組み込みフォントはスタティックフォントであり、**Objects** の項目横に `"Static font: no variable axes"` と表示されます。組み込みのうち **Geist**、**Geist Mono**、**Inter** はウェイト軸を、**Geist Serif** は `ELSH` 形状軸を持ちます。その他の可変フォントを使うには、[アセット](/docs/ja/workflow/assets/) に可変 TTF / OTF / WOFF1 を読み込んで **Font Family** で選んでください。**Style** の直下に **Weight (wght)** のような軸行が現れます。
- **段落テキスト:** **Text Mode** を **box** にし、**Box Size** で折り返し幅と高さを指定します。
- **Text Animator:** **Text** 項目を選び、プレビューのコンテキストメニューから **Add Text Animator** とプロパティを選びます。プロパティと **Range Selector** をアニメーションさせ、必要に応じて **Add Property** や **Add Wiggly Selector** を追加します。アニメーターは同じグループ内で上にあるすべての **Text** 項目に作用し、複数積むと上から順に合成されます。
- **パスへの変換:** **Text** 項目を選び、プレビューのコンテキストメニューで **Convert to Path** (または Objects 行の **Create Shapes from Text**) を実行します。Text Animator の結果を含む現在フレームの形状が文字ごとの **Group** と **Path** へ変換され、1 回の Undo でライブテキストへ戻せます。

- **Round Corners:** **Radius** (≥ 0、初期値 `10` px)。
- **Twist:** **Angle** (度、初期値 `0`)、**Center** (2D ベクトル、初期値 `[0, 0]`)。
- **Zig Zag:** **Size** (≥ 0、初期値 `10` px)、**Points** (**corner** / **smooth**、初期値 **corner**)、**Ridges per segment** (`1` ～ `64`、初期値 `3`)。
- **Pucker & Bloat:** **Amount (%)** (`-100` ～ `100`、初期値 `0`)。パス中心に対し頂点を内側へ引くか外側へ膨らませます。

#### Wiggle Paths と Wiggle Transform

どちらも **Wiggles / second** (`0` ～ `100`、初期値 `1`)、**Correlation (%)** (`0` ～ `100`、初期値 `50`)、**Temporal phase (degrees)** (初期値 `0`)、**Spatial phase (degrees)** (初期値 `0`)、**Random seed** (初期値 `1`) を共通して持ちます。

- **Wiggle Paths** は **Size** (≥ 0、初期値 `10` px)、**Points** (**corner** / **smooth**、初期値 **corner**)、**Detail** (`1` ～ `100`、初期値 `5`) を追加します。
- **Wiggle Transform** は **Anchor offset** (`[0, 0]`)、**Position offset** (`[20, 20]`)、**Scale offset (%)** (`[0, 0]`)、**Rotation offset** (`0` 度) を追加します。

#### Offset Paths と Merge Paths

- **Offset Paths:** **Amount** (初期値 `10`)、**Join** (**miter** / **round** / **bevel**、初期値 **miter**)、**Miter limit** (`1` ～ `100`、初期値 `4`)。開いたパスは両側へオフセットされて閉じた輪郭になり (**round** は丸端、他は平端)、負の **Amount** も正と同じ結果になります。
- **Merge Paths:** **Mode** (**merge**、**add**、**subtract**、**intersect**、**exclude**、初期値 **add**)。**merge** は輪郭を保持し、他の 4 つはブール演算を行います。

SVG 読み込みやネイティブからの変換で編集可能なベクター項目が生成されます。ネイティブの Text+ 文字アニメーションは Shape+ 変換時には引き継がれません。

## Text と Text Animator リファレンス

### Text

**Text** は同じグループ内の後続モディファイアとペイントへグリフ輪郭を渡します。離散的な設定はホールドキーとエクスプレッションに対応します。

| コントロール | 型 | 初期値 | 動作 |
| --- | --- | --- | --- |
| **Source Text** | 動的テキスト | `Text` | 複数行文字列。ホールドキーと式に対応。 |
| **Font Family** | 動的フォントアセット | ネイティブ既定 | 主フォント参照。 |
| **Fallback Font** | 動的フォントアセット | なし | 未収録書記素クラスタ用の明示フォールバック (暗黙フォールバックなし)。 |
| **Style** | 動的選択 | Default | 名前付きインスタンスの軸値を書き込みます (式で駆動中の軸は維持して通知)。 |
| 可変軸 (例: **Weight (wght)**) | 動的数値 | フォント既定 | **Style** 直下に軸ごとに 1 行。上下限はフォント定義に従います。 |
| **Size** | 動的数値 | `100` | em あたりのコンポジションピクセル数。 |
| **Tracking** | 動的数値 | `0` | グリフ間隔 (**Size** の 1/1000 単位)。 |
| **Leading** | 動的数値 | `120` | ベースライン間隔 (px)。 |
| **Baseline Shift** | 動的数値 | `0` | 正の値で上へ移動。 |
| **Horizontal Scale (%)**, **Vertical Scale (%)** | 動的数値 | `100` | グリフ拡大率。 |
| **Caps** | 動的選択 | `normal` | `normal`、`all`、`small` (小文字を 75% の大文字表示)。 |
| **Position** | 動的ベクトル | `[0, 0]` | ベースライン原点。 |
| **Alignment** | 動的選択 | `left` | `left`、`center`、`right`、`justifyLeft`、`justifyCenter`、`justifyRight`、`justifyAll`。 |
| **Text Mode** | 動的選択 | `point` | `point` (折り返しなし) または `box`。 |

| **Space Before**, **Space After** | 動的数値 | `0` | 段落前後の余白 (px)。 |

- **対応形式:** TTF、OTF、可変 TrueType、CFF2、WOFF1。WOFF2 は非対応ステータスを表示しつつ参照を保持します。欠落フォントは項目横に状態を表示します。
- **折り返し:** Box テキストはラテン語を単語単位 (幅超過時は書記素単位)、CJK を書記素単位で折り返します。改行で段落が分かれます。均等配置は空白を広げ、空白のない CJK 行では書記素間に幅を配分します。
- **可変軸:** アニメーション付きの **Style** は独自アニメーションを持たない軸に値を設定します。非アクティブな軸は `axisStore` に保存され、同じ軸タグを持つフォントへ戻すと復元されます。オプションのテキストエンジンバンドルは初回使用時に読み込まれます (Electron は未検証)。

### Text Animator

**Text Animator** は同じグループ内で上にあるすべての **Text** 項目 (先行ネストグループ内を含む) に作用し、上から順に合成されます。上にテキストがない場合は `"No text above this animator"` と表示されます。
有効な各プロパティは `neutral + (value - neutral) * s` (`s` は単位ごとのセレクター合成値) を適用します。プロパティの追加・削除はコンテキストメニューの **Add Property** / **Remove Property** で行います。文字単位の Opacity、Fill Color、Stroke Color、Stroke Width は未対応です。

| プロパティ | 型 | 初期値 | 動作 |
| --- | --- | --- | --- |
| **Anchor Point** | 動的ベクトル | `[0, 0]` | 拡大・回転・スキューのピボットオフセット。 |
| **Position** | 動的ベクトル | `[0, 0]` | グリフ位置への加算 (上向きが Y 正)。 |
| **Scale (%)** | 動的ベクトル | `[100, 100]` | 中立値は `100`。 |
| **Skew**, **Skew Axis** | 動的数値 | `0` | 度単位。拡大の後、回転の前に適用。 |
| **Rotation** | 動的数値 | `0` | 度単位。 |
| **Tracking Amount** | 動的数値 | `0` | 作用する各文字の後に `value * s * Size / 1000` を加算 (配置計算後に適用)。 |
| **Character Offset** | 動的数値 | `0` | `a–z`、`A–Z`、`0–9` 内で折り返し付き整数シフト。合字はクラスタ全体を先頭文字の重みで一体整形します。新しい送り幅が元の送り幅を置き換え、カーニングは元のシェーピング結果を保ちます。 |
| **Grouping Alignment (%)** | 動的ベクトル | `[0, 0]` | グループボックス比でのピボット移動 (水平は送り幅、垂直はアセント～ディセント)。 |
| 可変軸 (タグ) | 動的数値 | `0` | グリフの軸座標へ加算 (軸範囲にクランプ)。 |
| **Anchor Point Grouping** | 静的選択 | `Character` | ピボット単位: `Character`、`Word`、`Line`、`All` (最初のベースライン上の送り幅中央)。 |

### パス変換とキャッシュ上限

- **Create Shapes from Text:** 現在フレームの **Text** を文字グループへ置き換えます (各輪郭が個別 **Path**。空白はグループなし。合字の輪郭は先頭文字へ入り残りは空グループ。結合記号は基底文字グループに保持)。巻き方向・親ペイント順・アニメーター行を保ち、1 回の Undo でライブテキストへ戻せます。
- **キャッシュ上限:** テキストレイアウトキャッシュはフォント識別子、評価済みテキスト・段落プロパティ、可変軸座標をキーにします。フォントファイルを差し替えると古いキャッシュは無効化されます。レイヤー変形は平坦化許容誤差が変わらない限りレイアウトとジオメトリを再利用します。計算上の上限はレイアウト・グリフジオメトリ・グリフペイント各 `8` MiB、解析輪郭・シェーピング結果各 `2` MiB、フォールバック判定 `512` KiB、エンジンシェーピング `1` MiB、輪郭 `4` MiB です (ブラウザーのヒープ全体を測定するものではありません)。接触・重複グリフは複合フィルを使い、斜線・曲線輪郭もサブピクセル描画の精度を保つため複合スラブ配置を維持します。**Trim Paths** の `Individually` モードや変形付き **Repeater** ではグリフ単位のフィル再利用が無効になります。
