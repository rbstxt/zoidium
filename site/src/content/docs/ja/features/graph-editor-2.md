Graph+ とも呼ばれる Graph Editor 2 を使うと、グラフパネルや独立したグラフウィンドウで標準キーフレームを編集できます。

## プロパティを表示する

1. **Plugins** で **Graph Editor 2** を有効にします。
2. アニメーション可能なプロパティの行、またはそのタイムラインのラベルを右クリックします。
3. **Show in Graph Editor** を選択します。
4. 独立ウィンドウを直接開くには、Ctrl+G を押します。

フォーカスしているプロパティ行を表示するには、Alt+Shift+G を押します。ベクトルと色のプロパティでは、すべての成分をまとめて開きます。

## カーブを固定または選択に追従させる

**Follow selection** は初期状態でオンです。プロパティを選択すると、表示するカーブを置き換えます。

1. プロパティを選択して、そのカーブを表示します。
2. 別のプロパティを追加するには、その行を Ctrl キーまたは Shift キーを押しながらクリックします。
3. ほかのオブジェクトを選択しても表示中のカーブを保つには、**Follow selection** をオフにします。
4. 固定したカーブを明示的に置き換えるには、もう一度 **Show in Graph Editor** を使用します。

オブジェクトやレイヤーを選択すると、そのアニメーション中のプロパティ (入れ子になったマテリアルやジオメトリのプロパティを含む) を追従します。追従の設定はローカルに保存されます。

## キーと接線を変更する

1. ドラッグでキーを選択するには、**Marquee** を選択します。
2. 変更するキーを選択します。
3. **Linear**、**Step**、**Ease**、**Custom easings** のいずれかを選択します。
4. ハンドルを編集するには、**Bezier** を使用します。
5. 接線の方向を分離するには、**Break Tangents** を選択します。
6. 接線の連続性を戻すには、**Auto Tangents** を選択します。
7. 編集した範囲を確認するには、**Frame** をクリックします。

選択したキーに入る区間のカーブエディターには、[Easing+](/docs/ja/features/easing-plus/) を使用します。両方のツールは同じ標準 Bezier ハンドルを使用します。

ツールバーの意味、フォーカス中のウィンドウのショートカット、表示操作は [Graph Editor 2 リファレンス](/docs/ja/reference/graph-editor/)を参照してください。
