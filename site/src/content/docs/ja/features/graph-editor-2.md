Graph+ とも呼ばれる Graph Editor 2 を使うと、グラフパネルや独立したグラフウィンドウで標準キーフレームを編集できます。

## プロパティを表示する

1. **Plugins** で **Graph Editor 2** を有効にします。
2. アニメーション可能なプロパティの行、またはそのタイムラインのラベルを右クリックします。
3. **Show in Graph Editor** を選択します。
4. 独立ウィンドウを直接開くには、Ctrl+G を押します。

フォーカスしているプロパティ行を表示するには、Alt+Shift+G を押します。ベクトルと色のプロパティでは、すべての成分をまとめて開きます。

## カーブを固定または選択に追従させる

**Follow selection** は初期状態でオンです。プロパティを選択すると、表示するカーブを置き換えます。

1. プロパティを選択して、そのカーブを表示します。
2. 別のプロパティを追加するには、その行を Ctrl キーまたは Shift キーを押しながらクリックします。
3. 他のオブジェクトを選択しても表示中のカーブを保つには、**Follow selection** をオフにします。
4. 固定したカーブを明示的に置き換えるには、もう一度 **Show in Graph Editor** を使用します。

オブジェクトやレイヤーを選択すると、そのアニメーション中のプロパティ (入れ子になったマテリアルやジオメトリのプロパティを含む) を追従します。追従の設定はローカルに保存されます。

## キーと接線を変更する

1. ドラッグでキーを選択するには、**Marquee** を選択します。
2. 変更するキーを選択します。
3. **Linear**、**Step**、**Ease**、**Custom easings** のいずれかを選択します。
4. ハンドルを編集するには、**Bezier** を使用します。
5. 接線の方向を分離するには、**Break Tangents** を選択します。
6. 接線の連続性を戻すには、**Auto Tangents** を選択します。
7. 編集した範囲を確認するには、**Frame** をクリックします。

## ベクトルの軸を編集する

1. 軸の行をクリックして、その軸を表示し、キーを選択します。
2. 複数の軸を選択するには、Ctrl キーまたは Shift キーを押しながら別の行をクリックします。
3. すべての成分を選択するには、親の行をクリックします。
4. カーブを非表示にするには、目のボタンをクリックします。軸だけを表示するには、その軸の **S** ボタンをクリックします。
5. 同じフレームにある他の軸のキーをまとめて移動するには、**Link axes** をオンにします。

**Link axes** がオンの場合、横方向のドラッグと微調整は同じフレームにある他の軸のキーも移動します。値の変更は選択した軸だけに適用します。
コピーと貼り付けは軸の名前を保持します。単一の軸を別の軸に貼り付けるには、貼り付け先の軸だけを選択します。

## エクスプレッションを確認する

1. エクスプレッションがあるプロパティを表示します。
2. 評価結果を確認するには、**Fit** または **Frame** を使用します。
3. キーを編集するには、先にエクスプレッションを削除します。

エクスプレッションのカーブは破線と **Expression** ラベルで表示します。処理に時間がかかるエクスプレッションは、複数回の再描画に分けてカーブを表示する場合があります。

選択したキーに入る区間のカーブエディターには、[Easing+](/docs/ja/features/easing-plus/) を使用します。両方のツールは同じ標準 Bezier ハンドルを使用します。

ツールバーの意味、フォーカス中のウィンドウのショートカット、表示操作は [Graph Editor 2 リファレンス](/docs/ja/reference/graph-editor/)を参照してください。

## マウスまたはトラックパッドで表示を移動する

1. マウスでパンするには、中ボタンでドラッグするか Space を押してドラッグします。
2. X をズームするには、マウスホイールを回します。Y をズームするには、Alt を押します。
3. トラックパッドでは、2本指でスクロールしてパンします。両方の軸をズームするには、ピンチします。
4. 操作一覧を表示するには、**?** をクリックします。

## Bezier ハンドルを調整する

1. キーを選択してハンドルをドラッグします。プリセット区間はドラッグ時に Bezier に変わります。
2. 接線を分離するには、ドラッグ中に Alt を押すか、開始時から Alt を押します。接線を再結合するには、Alt を離します。
3. 角度を制限するには、ドラッグ中に Shift を押します。
4. 水平または隣のキーの傾き付近でスナップするには、ドラッグ中に Ctrl または Command を押します。
5. 両方のハンドルを初期値に戻すには、ハンドルをダブルクリックします。
