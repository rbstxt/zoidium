**Animated GIF** を使うと、画像レイヤー、画像マテリアル、エフェクトのテクスチャで GIF 画像アセットをアニメーションさせられます。このプラグインは GIF の読み込みに対応します。

## GIF 画像を追加する

大きな GIF の場合は、読み込む前に[デコーダーの制限](/docs/ja/reference/animated-gif/)を確認してください。

1. **Plugins** で **Animated GIF** を有効にします。
2. GIF を画像アセットとして読み込みます。
3. アセットを画像レイヤー、画像マテリアル、またはエフェクトの画像テクスチャ欄に指定します。
4. 再生ヘッドを移動して、異なるフレームを確認します。

## アニメーションの時間を調整する

GIF はループします。クリップ内では、GIF のフレームはそのクリップのメディア時間に従います。オフセットやリタイムも反映されます。

1. GIF を使用しているクリップを選択します。
2. クリップのメディア時間のアニメーションを調整して、GIF のタイミングを変更します。
3. ループの境界付近のフレームを確認します。
4. タイミングの再現性を確認するには、前のフレームに戻ります。

クリップのコンテキストがない場合、GIF のアニメーションはプロジェクト時間に従います。書き出しでは、画像の使用先の準備処理を通じて GIF のデコード完了を待ちます。

フレームの遅延、ループ、デコードの制限は [GIF リファレンス](/docs/ja/reference/animated-gif/)を参照してください。出力形式は[書き出しオプション](/docs/ja/reference/export-options/)で確認できます。
