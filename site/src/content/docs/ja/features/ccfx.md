CCFX Shader Pack は、背景、歪み、トランジション、光のエフェクトに使用できます。パックには単体シェーダーが 12 個、グループプリセットが 7 個あります。

## 単体エフェクトを追加する

1. **Plugins** で **CCFX Shader Pack** を有効にします。
2. エフェクトを適用するレイヤーを選択します。
3. エフェクトのピッカーを開きます。
4. **CCFX SHADER PACK** の下で **BACKGROUNDS** を開きます。
5. **Sunburst V2** を追加します。
6. エフェクトのカスタムプロパティで **rotation**、**speed**、**scale**、**center** を調整します。

ほかのエフェクトを選ぶには、[CCFX 一覧](/docs/ja/reference/ccfx/)を参照してください。プロパティ名はプリセットごとに異なります。大文字と小文字の使い方も、パック全体では統一されていません。

## グループプリセットを追加する

1. 対象レイヤーでエフェクトのピッカーを開きます。
2. **CCFX SHADER PACK** の下で **CC Bend It** を選択します。
3. グループの **Start**、**End**、**Bend** を調整します。
4. グループ内の構成を確認するには、子エフェクトを展開します。

グループプリセットは、保存された子エフェクトとプロパティを持つエフェクトグループを挿入します。グループ自体にコントロールを持つものもあれば、子のプロパティの編集も必要なものもあります。

既存の時間エクスプレッションを持つプリセットでは、タイミングを変更する意図がある場合を除き、その式を維持してください。たとえば Sunburst V2 は、**uTime** を `time` で駆動します。
