---
title: プレビューキャッシュ
---
Settings > Preview cache では、レンダリングが完了したエディターフレームのカウント対象メモリの最大値を設定します。デフォルトは 512 MiB で、0 に設定するとキャッシュが無効になります。設定可能な値は最大16384 MiB で、保持されるフレーム数は最大 8192 です。これは制限値であり、予約メモリではありません。

## キャッシュの対象

完全なフレームは GPU 上にコピーでき、同じフレームおよびプロジェクト状態で再表示できます。キャッシュミスが発生した場合はリアルタイムで描画されます。リソースの読み込み、プロジェクトの編集、解像度やプラグインの変更によって、関連する状態は無効化されます。書き出しやスポイトツールの描画は独自のパスを維持し、キャッシュによって保存されたプロジェクトの内容が変更されることはありません。

一時停止中でアイドル状態のとき、対象となるシーンはプライベートなプロジェクトのコピーを介して一定範囲を事前レンダリングします。動画プロジェクトや、同期描画に 50 ms 以上かかるシーンでは、この処理はスキップされます。通常どおり表示されたフレームは保持できます。

## プラグインの検証

プラグインの承認には、インストールされたバージョンと、ブラウザーの出力検証で使用したレンダリングソースのフィンガープリントを記録します。ランタイムソース、プラグインのマニフェスト、アセット、起動順序、有効化のデフォルト値、または検証用フィクスチャが変更されると、`pnpm run verify` は失敗します。デプロイ用のバージョン番号や再ビルドされたバンドルは、変更のない承認を無効にしません。

ブラウザーの出力検証では、GPU から読み取ったバイト列を、同じフレームで新しく読み込んだプロジェクトのライブ描画と比較します。検証項目には、順方向、逆方向、繰り返しのシーク、時間エフェクト、プライベートなコピーで事前レンダリングしたフレーム、短時間の **Full quality** 確認を含みます。フィクスチャが失敗したプラグインは、ライブプレビューを使用します。検証ツールの `--write` オプションは、全項目の検証後に承認を記録します。フィルターを指定した実行では、承認を更新できません。

## キャッシュが空の場合

プレビューフレームを保持または再利用できない場合、使用量の注記に **Not caching:** と現在の理由を表示します。メモリの上限を増やしても、これらの確認は省略されません。

- コミュニティコンテンツや、キャッシュの検証が済んでいないプラグインのバージョンは、ライブプレビューを使用します。注記には、必要なプラグインと、取得できる場合はそのバージョンを表示します。
- フレームサンプラーを使用しない時間操作は、ライブ評価を使用します。Smart Motion Blur 自体はキャッシュを無効にしません。ただし、プラグインのバージョンは検証に合格する必要があります。
- プラグインの読み込み中、またはプラグインのエラーがある場合は、キャッシュを停止します。使用していないプラグインのエラーも対象です。
- フレームを保持する前に、リソースの読み込み、フレームの準備、正確な動画フレームのデコードが完了する必要があります。
- プロジェクトの検証に 8 ms を超える時間がかかる場合、変更された状態の検証とキャッシュは、再生が停止して編集がアイドル状態になるまで待機します。
- 3D 編集カメラや、1 フレームより小さいメモリ上限も、新しいキャプチャを妨げます。

注記は次のプレビュー描画後に更新されます。**Pause drawing** は通常のプレビュー描画を停止し、描画せずに状態を表示します。描画を一時停止していても、**Render once** で完全なフレームをキャプチャできます。アイドル時の事前レンダリングは独自の条件で実行されます。

## メモリ制限

カウントされる RGBA8 バイト数には、ドライバーのオーバーヘッドやその他のレンダーターゲットは含まれません。割り当ての失敗またはコンテキストの喪失が発生すると、セッションの上限が引き下げられ、設定値を上げても上書きできなくなります。2 回目のコンテキスト喪失が発生すると、再読み込みするまでキャプチャが無効になります。正確な動作については、[プレビューキャッシュのメモリ](/docs/ja/development/project-compatibility/#プレビューキャッシュのメモリ)を参照します。

4096 MiB を超える場合、Settings は選択した量の空きメモリが GPU に必要であると警告します。内蔵 GPU は、どのオペレーティングシステムでもシステム RAM とメモリを共有します。
