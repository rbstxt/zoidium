title: 動くコンテンツにブラーを追加する

動く映像や **3D Scene** 内のオブジェクトには、**Smart Motion Blur** を使用します。
レイヤーの Position、Rotation、Scale による動きには、そのコンテンツの上に **Adjustment** レイヤーを配置します。

## エフェクトを追加する

1. Plugins で **Native FX** を有効にします。
2. 映像または **3D Scene** のクリップを選択します。レイヤーの変形による動きには、動くコンテンツの上にある **Adjustment** クリップを選択します。
3. Effects ピッカーの **NATIVE FX** から **Smart Motion Blur** を追加します。
4. コンテンツが動いているフレームに移動します。
5. ブラーを確認するには、**View** を **Result** に設定します。

取得される入力には、選択したレイヤーの最終合成時の変形が含まれません。
**Adjustment** レイヤーは、動くレイヤーを合成した後の動きを取得します。

## Reconstruction を選択する

**3D Scene** 内で回転するオブジェクトには、**Reconstruction** の **Automatic** を使用します。
シャッター区間内の小数時刻でシーンを取得するため、輪郭や押し出し面の見え方の変化も反映します。
映像では、**Automatic** はオプティカルフローを使用します。
**3D Scene** でオプティカルフローを使用するには、**Optical Flow** を選択します。
**Adjustment** レイヤーの下にあるレイヤー変形を直接取得するには、**Shutter Samples** を選択します。

## ブラーを調整する

- **Blur Amount** をシャッター角度を 360 で割った値に設定します。180 度のシャッターには 0.5 を使用します。
- **Optical Flow** で速い動きを追跡できない場合は、**Motion Sensitivity** または **Max Displacement (px/frame)** を上げます。変位の上限は、1 フレームあたりの予想移動量に近づけます。
- **Optical Flow** で近接する位置の動きの推定値の差を抑えるには、**Vector Smoothness** を上げます。別々のオブジェクトが異なる方向に動く場合は、この値を下げます。
- **Optical Flow** では、通常は **Analysis Frames** を **Both** に設定します。片側の隣接フレームを使用するには、**Previous** または **Next** を選択します。
- シャッターのサンプル数を増やすには、**Quality** を **High** に設定します。プレビューを速くするには、**Balanced** を使用します。
- **Shutter Samples** の出力は、**Blur Amount** と **Quality** で調整します。追跡用の設定は、この出力を変更しません。
- オプティカルフローの追跡を確認するには、**View** を **Motion Vectors** または **Confidence** に設定します。エクスポート前に **Result** に戻します。

## 追跡の制限に対処する

**Optical Flow** でカットを含む映像では、カットのフレームを確認します。隣接フレームが一致しない場合、エフェクトはブラーを省略することがあります。
オブジェクトの後ろから背景が現れる場合は、**Blur Amount** を下げて、その領域の乱れを抑えます。
繰り返し模様や似た色のオブジェクトが複数ある場合は、**Motion Vectors** で軌跡を確認します。

オプティカルフローでは、現在のフレームと隣接フレームに隠れている細部は復元できません。
**Shutter Samples** はシーンの遮蔽を直接取得します。ただし、非常に速い動きでは、有限のサンプル間に帯が生じる場合があります。
複雑なシーンほど取得時間が増えます。録画済みの映像には、元のフレーム間隔が残ります。
遠近変形を伴う動きには、追加の処理が必要です。
既定値、範囲、制限については、[プロパティリファレンス](/docs/ja/reference/smart-motion-blur/)を参照してください。
