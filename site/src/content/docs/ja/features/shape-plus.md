編集可能なパスとネイティブのアニメーションを備えた Shape+ レイヤーを作成します。

## シェイプを追加する

1. タイムラインに **Shape+** Media プリセットを追加します。
2. クリップを選択します。
3. **Objects** を開きます。
4. Contents の **+** メニューを開きます。
5. Rectangle、Ellipse、Polystar、または Path を選択します。
6. アイテムのプロパティを編集します。

## コンテンツを編集する

1. Contents でパスを選択します。
2. パスを編集するには、メインプレビューで選択ツールまたはペンツールを使用します。
3. パスを動かすには、ネイティブの **Path** アニメーションコントロールを有効にします。
4. 再生ヘッドを移動します。
5. パスを編集して次のキーポーズを作ります。

複数のパスをまとめてペイントするには、同じグループ内のそれらのパスの下に Fill または Stroke を配置します。コンテンツをドラッグして、順序やグループを変更します。アイテムを非表示にするには、目のボタンを使用します。

コントロールのリファレンス: [shape-plus](/docs/ja/reference/shape-plus/).

## テキストを追加して編集する

1. Shape+ レイヤーを選択します。
2. **Objects** を開き、Contents の **+** メニューを開きます。
3. **Text** を選択します。
4. Text 項目を選択し、**Font Family** を指定します。
5. ネイティブのプロパティパネルで **Source Text** を編集します。
6. プレビューで編集する場合は、テキストをダブルクリックします。
7. 改行する場合は Enter を押します。
8. Escape を押すかエディターの外側をクリックすると、1 回の undo 操作として確定します。

日本語を入力する場合は、日本語のグリフがあるフォントを選択します。
不足するグリフに別のフォントを使用する場合は、**Fallback Font** を設定します。

段落テキストを使用する場合は、**Text Mode** を **box** に設定し、**Box Size** を編集します。
可変フォントをアニメーションする場合は、**Style** を選択して各軸のプロパティをアニメーションします。
組み込みフォントはスタティックであるため、軸の行は表示されません。可変軸を使用する場合は、可変の TTF、OTF、または WOFF フォントを Assets に読み込み、**Font Family** で選択します。軸は **Style** の直下に **Weight (wght)** のような名前付きの行として表示されます。スタティックフォントの Text 項目には、**Objects** の横に "Static font: no variable axes" と表示されます。
対応する形式とレイアウト設定は、[Text](/ja/reference/shape-plus/#text) を参照してください。

## アニメーターでテキストをアニメーションする

1. Text コンテンツ項目を選択します。
2. プレビューのコンテキストメニューで **Add Text Animator** を選択し、プロパティを選びます。
3. プロパティと Range Selector の範囲をアニメーションします。
4. 別のプロパティを追加する場合は、アニメーターを選択して **Add Property** を選択します。
5. 値を時間で変化させる場合は、**Add Wiggly Selector** を選択します。

各アニメーターは、同じグループ内で上にある Text 項目に作用します。
複数のアニメーターを重ねると効果が組み合わさります。
プロパティ、グループ化、セレクターは [Text Animator](/ja/reference/shape-plus/#text-animator) を参照してください。

## テキストからシェイプを作成する

1. Text コンテンツ項目を選択します。
2. プレビューのコンテキストメニューで **Convert to Path** を選択します。
3. Objects の行を使用する場合は、**Create Shapes from Text** をクリックします。
4. 文字のグループを展開し、各輪郭を Path として編集します。

変換は現在のフレームを記録し、1 回の undo 操作を作成します。Text Animator が
ある場合、変換は表示中のアニメーションフレームをパスに記録します。
ライブテキストとそのアニメーションを復元する場合は、Undo を使用します。
