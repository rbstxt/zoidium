編集可能なパスとネイティブのアニメーションを備えた Shape+ レイヤーを作成します。

## シェイプを追加する

1. タイムラインに **Shape+** Media プリセットを追加します。
2. クリップを選択します。
3. **Objects** を開きます。
4. Contents の **+** メニューを開きます。
5. Rectangle、Ellipse、Polystar、または Path を選択します。
6. アイテムのプロパティを編集します。

## コンテンツを編集する

1. Contents でパスを選択します。
2. パスを編集するには、メインプレビューで選択ツールまたはペンツールを使用します。
3. パスを動かすには、ネイティブの **Path** アニメーションコントロールを有効にします。
4. 再生ヘッドを移動します。
5. パスを編集して次のキーポーズを作ります。

複数のパスをまとめてペイントするには、同じグループ内のそれらのパスの下に Fill または Stroke を配置します。コンテンツをドラッグして、順序やグループを変更します。アイテムを非表示にするには、目のボタンを使用します。

[Shape+ のソースコントラクト](https://github.com/rbstxt/zoidium/blob/dev/plugins/shape-plus/README.md)では、座標、ペイント範囲、モディファイア、保存データについて説明しています。

コントロールのリファレンス: [shape-plus](/docs/ja/reference/shape-plus/).
