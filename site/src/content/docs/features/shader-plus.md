---
title: Add shader controls with Shader+
sidebar:
  label: Shader+
---
Add a typed control to a native Custom Shader effect.

1. Enable **Shader+** in Plugins.
2. Add a native Custom Shader effect to a clip.
3. Open **Shader properties**.
4. Click **+**.
5. Choose a kind under **ZOIDIUM**.
6. Set the property's name.
7. Open the code editor.
8. Declare the matching uniform.
9. Click **Apply**.

For a first effect, follow [Write a passthrough shader](/docs/shaders/basics/).
For each control's declaration, read [Property kind examples](/docs/shaders/kind-examples/).
Use [Edit and check a shader](/docs/shaders/editor/) for completion, diagnostics,
Declare, and templates.

[Property controls](/docs/development/shader-properties/) describes settings and
saved formats. [Shader+ compatibility](/docs/development/project-compatibility/#shader-property-kinds)
describes plugin requirements for texture and array properties.
