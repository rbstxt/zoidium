title: Apply an AlipFX effect
sidebar:
  label: AlipFX shader pack
---
Add an effect from Afterzoid Shader Pack 5.

1. Enable **Afterzoid Shader Pack 5** in Plugins.
2. Select a clip.
3. Open the Effects picker.
4. Search for an effect in **ALIPFX · SHADER PACK 5**.
5. Add the effect.
6. Edit its native properties.

For a custom shader version, use [Shader+](/docs/features/shader-plus/).
To replace numbered colors with a Gradient, follow
[Port a shader to Custom Shader](/docs/shaders/porting/#replace-numbered-alipfx-colors).
Keep the original effect when exact pixel compatibility is required.
