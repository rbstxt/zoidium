# AfterClip

Optional AfterClip shader and group pack for Zoidium.

- Standalone shaders: 32
- Group presets: 11
- Excluded by design: Twitch and VHS
- Object overlays use premultiplied-alpha source-over compositing.
- Position, Rotation, Scale, and Opacity follow the Zoidium/panzoid-shader conventions.

The files are generated by `tools/build-afterclip-plugin.js` from the AfterClip `src/Shaders` and `src/Presets` trees.
