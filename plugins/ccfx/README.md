# CCFX Shader Pack

Optional CCFX shader effects and group presets for Zoidium.

- Standalone shaders: 12
- Group presets: 7
- Source author: CCFX

The generated files are built by `tools/build-ccfx-plugin.js` from the external CCFX Shader Pack source tree. The original source dump and project file are not included in the repository.
