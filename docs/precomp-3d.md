# Edit a Scene in a composition

1. Right-click a composition clip that contains a Scene clip.
2. Select **Edit 3D in comp**. If the composition has several Scene clips, select the Scene from the menu.
3. Edit the Scene using the grid, view controls, and object properties.
4. Open **Comps** and click **Back from 3D edit** to return to the previous composition.

Each composition switch is an undo step. To undo an edit after returning, use **Undo** twice.
