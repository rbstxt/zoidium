# プラグインマネージャー

サイドバーの **Plugins** ページで Zoidium プラグインを有効または無効にします。

## プラグインを有効にする

1. サイドバーの **Plugins** を開きます。
2. プラグインまたはグループを見つけます。
3. プラグインを有効にします。
4. 対応するピッカーから、そのオブジェクト、エフェクト、またはマテリアルを追加します。

## プラグインを無効にする

1. そのプラグインを必要とするプロジェクトのコンテンツを削除します。
2. **Plugins** でプラグインを無効にします。

無効化の前に現在のプロジェクトの復元ポイントを保存します。そのバックアップが失敗した場合、バックアップなしでの続行を選択しない限り、スイッチは有効のままです。プロジェクトがまだ使っているプラグインは、そのコンテンツを削除するまで無効にできません。保存済みのプラグイン設定はプロジェクトに残り、プラグインを再び有効にすると戻ります。
