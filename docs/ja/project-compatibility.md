# 保存済みレンダリングの互換性

Zoidium は CM3 を取り巻く外部の拡張レイヤーです。ホストが保存済みプロジェクトを読み込む前に、レンダリングモードを割り当てます。明示的なモードを持たない保存済みオブジェクトは、ファイルに記録されたプラグインバージョンにかかわらず、`legacy` として読み込まれます。明示的な `legacy` フィールドと `current` フィールドは常に優先されます。新しいオブジェクトは `current` を使用し、その選択をシリアライズします。新しい UI コントロールはありません。

## Expressions+

エクスプレッションは、ネイティブの動的プロパティにソース文字列のまま残ります。コンパイル済みコードはプロジェクトファイルに入りません。拡張構文/API は、機能 `expressions` を持つ `expressions-plus` 依存関係を追加します。スキャンには、保持されたプロジェクトレコードと入れ子のプロジェクトレコードを含めます。ソース文字列は、ネイティブのシリアライズ、アーカイブ保存、コピー/貼り付け、履歴を通じて損なわれません。古い Zoidium ビルドは、依存関係記述子から警告できます。バニラ CM3 はプラグイン依存関係を解釈できません。サポート外の構文/API に対して、ネイティブのエクスプレッションエラーを表示します。

コンストラクターとプロトタイプメンバーの読み取りは、計算済み読み取りを含め、CM3 の結果を維持します。セキュリティ上の例外は、あらゆる経路での Function ライクなコンストラクターまたは eval の呼び出しです。これには、`new`、別名、コールバック、Promise コールバック、文字列プロトコルメソッドによる呼び出しや、それらが作成した関数の呼び出しを含みます。これらの呼び出しは英語のエクスプレッションエラーを生成し、プロパティ自体の値を使います。不明な自由グローバル、`this`、async 構文、ジェネレーター構文は引き続き利用できません。コンパイルは、評価前に削除する一時的なサンドボックス化 iframe の Function コンストラクターを使います。ホストやレルムのオブジェクトを公開する新しい API ハンドルはありません。

Expressions+ 構文や API を使うプログラムには、外部評価ごとに 10,000,000 ループ/呼び出しステップと 256 ネスト呼び出しという決定的な上限があります。既存の CM3 互換プログラムは、無視される余分な引数を含む、無制限のループ動作とネイティブヘルパーシグネチャを維持します。AE オーバーロードは、拡張機能を必要とするプログラムにだけ適用します。上限違反やその他のエクスプレッションエラーは、プロパティのキー値にフォールバックします。これは CM3 の未定義エラー結果を置き換えます。レガシーエクスプレッションは、ネイティブシグネチャとデタッチ済みレルム組み込みの同一性を維持します。ネイティブコーパステストは、受け入れ済みリポジトリエクスプレッションをキャッシュ済み CM3 コンパイラーと比較します。CM3 コードや取得データを Git にチェックインしません。

MP4 Export はプロジェクトフィールドもレンダリングモードも追加しません。フォーマット、ビットレート、コーデックの決定は、現在の Device レンダーページに属します。プラグインを無効にしても、古いビルドでプロジェクトを開いても、そのレンダリングは変わりません。プラグインは同じ決定的フレームレンダラーとネイティブオフラインオーディオミキサーを使います。奇数の出力寸法には、レンダリング画像をリサイズせず、H.264 用に右または下へ黒パディングピクセルを 1 つ追加します。

| 動作 | シリアライズ済みフィールド | 所有者 |
| --- | --- | --- |
| PBR+ UV レイアウト | `zoidiumUvMode` | 各 PBR+ マテリアル |
| Text+ スケール合成 | `zoidiumTextScaleMode` | 各ネイティブ Text オブジェクト、種類 1 |
| エフェクタの分割 | `zoidiumSubdivisionMode` | 各 Twist または Warp オブジェクト。古い数値の種類 7 と 8 を含む |
| 時間プレフィックス量子化子 | `zoidiumTemporalMode` | 各フレームサンプリングエフェクト: Echo、Time Displacement、CC Wide Time、Time Difference |
| シャドウ品質 | `zoidiumShadowMode` | 各ネイティブ 3D Scene レイヤー、種類 4 |

`zoidium/project-compatibility.js` は、プラグイン依存関係検出とホストのデシリアライズの前に、マークのない保存済みレコードに注釈を付けます。埋め込みコンポジションと無効なプラグインペイロードも走査します。マイグレーションは入力を変更せず、変更のないアセットデータをコピーしません。シリアライザーは、保存/開く、コピー/貼り付け、複製、Undo/Redo を通じて明示的なモードを維持します。新しいプラグインバージョンで再保存しても、オブジェクトのレンダリングモードは変わりません。

## PBR+ UV レイアウト

レガシー PBR+ は、`09b7c04` 以前と同様に CM3 ネイティブの WorldUVGenerator 座標を維持します。別のマテリアルが以前に共有 Material+ レイアウトを適用していた場合は、その座標を復元します。現行 PBR+ は `plugins/material-plus/uv-layout.js` を使います。新しい PBR+ とその他の UV 読み取り Material+ マテリアルは、共有レイアウトを使います。

## Text+ スケール合成

レガシー Text は、文字階層の上にネイティブスケールを保持し、`a9007ee^` の文字トランスフォーム順序を使います。現行 Text は、不均一、負、ゼロのスケールでの文字回転に対する修正済み合成を使います。

モードがネイティブ Text に属する理由は、すべての祖先 Text+ コントローラーが 1 つの文字階層に作用するためです。スケール順序の異なるコントローラーは、それを一貫して共有できません。マークのない保存済み Text はすべてレガシーモードを取得します。これには、現在 Text+ コントローラー外にある Text を含みます。新規追加の Text は、古いコントローラー配下でも現行です。シリアライズは Text+ 無効時も動作します。

## エフェクタの分割

レガシー Twist/Warp は、隠し `curveQuality` 値と `polygonCount` 値を維持し、元のセレクターレベルである `zoidiumLegacySubdivisionLevel` をシリアライズします。そのレベルでは、`be6ea2b^` の正確な任意三角形数とトポロジーを使います。これには元の 2 三角形最小値を含みます。既存セレクターの他の値は、現行の均一分割を使います。Undo 経由を含め、元のレベルに戻すと元の数が復元します。プロパティの編集は、モードも元の数も書き換えません。ワーカーと同期のキャッシュキーには、有効モードを含めます。

## 時間プレフィックス量子化子

レガシーサンプラーは、`430a52c^` のタップマッピングを使います。各タップは、先行する Posterize Time 量子化子を再生せず、生の入力時刻を要求します。調整サンプラーは、元の制御クロックと調整スコープも維持します。現行サンプラーは、サンプル時刻ごとに順序付きプレフィックス量子化子を再生し、調整スコープを制限します。プロジェクトレート 30 では、5 fps の Posterize Time プレフィックス後のフレーム 1 への要求タップは、レガシーモードではフレーム 1 に留まり、現行モードではフレーム 0 にマッピングします。

各サンプリングエフェクトが自身の決定を所有する理由は、自身の入力タップを要求して合成するためです。プレフィックス演算子は共有のままです。古いサンプラーと新しいサンプラーはスタック内で共存できます。`defineFrameSampler()` は、各エフェクトのライフサイクル前後にモード永続化を設置します。これにより、Time Displacement のレイヤー入力のようなカスタムシリアライザーを保持します。時間入力リビジョンには、キャッシュキーがサンプリングエフェクト自体を省略する場合でも、サンプラーのモードと外側サンプラーのモードを含めます。完成フレームキーには、シリアライズ済みモードを含めます。

## シャドウ品質

レガシーシーンは、`17e05e6` 以前の CM3 オリジナル Three r91 深度パスを選択します。そのメッシュは Zoidium 既定の `customDepthMaterial` を受けません。そのため Three はネイティブ深度マテリアルと未変更 RGBA パッキングを選びます。現行シーンは、ポリゴンオフセット付き共有深度マテリアルと、`71bd922` のパック済み深度補正を使います。明示的なメッシュ深度マテリアルは、どちらのモードでも優先されます。点光源距離マテリアルは変更ありません。

ネイティブ 3D Scene レイヤーがモードを所有する理由は、そのメッシュが同じライト深度パスに寄与するためです。既定深度アクセサーは、ライブ Three シーン祖先を通じて所有者を解決します。生成メッシュと再親付けメッシュは、シーンに自動で追従します。各シーンは、合成やプロジェクト内で独自モードを維持できます。シーンのシリアライズは、モードを時間入力と完成フレームキャッシュキーへ運びます。

## 回帰の証拠

`test/fixtures/legacy-render-outputs.json` は、`09b7c04^`、`a9007ee^`、`be6ea2b^` からの数値出力を固定します。`test/fixtures/legacy-temporal-outputs.json` は、通常スタックと調整スタックについて、実際の `430a52c^` 実装からの要求フレーム、デコード済みフレーム、取得値を固定します。これらのフィクスチャに CM3 ランタイムコードやアセットは含みません。

互換性、レガシーレンダリング、時間サンプラー、プラグイン API、シャドウ品質、出力フレームの各テストは、バージョン検査なしのマイグレーション、明示的選択、新規オブジェクト、ラウンドトリップ、複製、履歴リロード、モード対応キャッシュキー、履歴出力比較をカバーします。

## Motion Paths

Motion Paths は、CM3 の既存 Position チャンネルとネイティブキーフレームフィールドにだけ編集を格納します。レンダリングモード、オブジェクト種類、空間パスフィールドは追加しません。古いビルドはプラグインなしでそれらの編集を評価できます。可視性とローカルパスキー選択はエディター状態であり、プロジェクトに保存しません。パスを表示しても既存アニメーションには触れません。軸キー実体化は、ホールド、リニア、ベジェカーブを保持します。その他のイージングプリセットは隣接トゥイーンを維持し、分割セグメント内でタイミングが変わる場合があります。時間ハンドルマッピングと上限は `plugins/motion-path/README.md` を参照してください。

## Track To コンストレイント

Constraints は、コンストレイント付き各ネイティブ 3D オブジェクトの `properties` 内に、任意の `zoidiumTrackTo`、`zoidiumTrackAxis`、`zoidiumUpAxis`、`zoidiumInfluence` キーを追加します。Influence は、キーフレームとエクスプレッションを含むホストの通常動的数値フォーマットを使います。トラック軸オプションはインデックス 0 から 5 で +X、+Y、+Z、-X、-Y、-Z です。上軸インデックス 0 から 2 は X、Y、Z を意味します。ターゲットとして使うオブジェクトにだけ、永続 UUID である `properties.zoidiumId` を受けます。空でないターゲットは、コンポジション内や保持ペイロード内で見つかった場合を含め、機能 `track-to` を持つ `constraints` プラグイン依存関係を追加します。

欠落フィールドはレンダリングを変えません。未編集オブジェクトは既定コンストレイントフィールドを省略します。以前保存した値をクリアする際は、明示的既定値がホストの保持不明フィールドを上書きします。欠落ターゲットとスキップ済みサイクルは、オブジェクト自体の評価済みポーズを使います。プラグインは Rotation キーフレームを書き換えません。UUID 衝突は、取り込みコピーの識別子を再生成します。コピーしたグループやシーンは、内部ターゲットリンクを 1 つの読み込みバッチとして再マッピングします。名前変更と並べ替えは識別子に影響しません。

Constraints なしのビルドはこれらのプロジェクトを開き、余分なキーを無視できます。ただしコンストレイントなしのキー付きポーズをレンダリングします。既存の不明フィールド保持を持つビルドは、再保存時にそれらのキーを維持します。ターゲットのない UUID だけではプラグインを必要としません。空でない Track to フィールドを持たないプロジェクトは既存レンダリングを維持するため、互換モードは不要です。Camera+ シーケンスカメラレイヤーは、同一シーンターゲット契約の対象外です。ライト規約は [Constraints guide](../plugins/constraints/README.md) を参照してください。

## エディターテーマ

Theme Editor の設定は、プロジェクトファイル、オブジェクトプロパティ、レンダリングモードに入りません。エディタークロームとタイムライン DOM 色だけを変更します。保存済みプロジェクトは既存のレンダリング出力を維持します。古いビルドは `zoidium.editor-settings` 内 `themeId` を無視し、保持された `theme`、`hue`、`saturation` プロファイルを使います。既存 Custom プロファイルは引き続きサポートします。

名前付きテーマは localStorage `zoidium.themes` に `{version:1,themes:[{id,name,main,overrides,clips}]}` として存在します。ID は `user:` で始まります。`main` と色値は 6 桁 hex 文字列です。`overrides` は `focus`、`link`、`clip`、`clipSelected`、`clipSelection` を受け付けます。欠落キーは Auto を意味します。`clips` は安定型キーを色にマッピングします。欠落キーはテーマクリップ色を使います。ネイティブレイヤーは `cm3:<numeric type>` を使い、音声は `audio` を使い、登録済みプラグインレイヤーは名前空間付き種類を使います。レガシー数値プラグインレイヤーは、登録 ID が名前空間付きの場合に `zoidium:<registration id>` を使います。これには Camera+ を含みます。登録済み数値別名は同じキーに解決します。プラグインを無効にしても、保存済みクリップ色エントリは後の再利用に残ります。

単一テーマ JSON ファイルは `{version:1,theme:{id,name,main,overrides,clips}}` 形式です。インポートはすべての色とキーを検証し、新しい ID を割り当て、衝突する名前に数値サフィックスを付けます。サポート外または破損したローカルテーマストレージは、ユーザーテーマを読み込みません。選択中テーマの欠落は Panzoid Classic にフォールバックします。インポートもエクスポートも、リソース取得やプロジェクトデータ送信を行いません。

Auto 色では、メイン色とオリジナル Classic パレットを HSL に変換します。パレットエントリ `p` と Classic フォーカス `f` に対して、`H = main.H + p.H - f.H`、`S = main.S * p.S / f.S`、`L = main.L + p.L - f.L` を計算します。色相を循環し、彩度/輝度をクランプしてから、RGB チャンネルをバイトに丸めます。フォーカスは正確なメイン hex 値です。Classic のメイン `#384668` はオリジナル 5 色をすべて正確に再現します。組み込みプロファイルは、変更なくオリジナル色相/彩度変換を使います。その複製は、チャンネル丸め差分の最小オーバーライドでバイト正確な色を保持します。カスタムクリップの選択色は、その HSL 輝度を白色方向へ 35% 移動します。そのラベルは、CM3 の `#2c323f` と `#f4f4f4` のうち WCAG コントラストが高い方を選びます。ネイティブプリセットラベルはオリジナルの色合いを維持します。

Theme Editor は、ネイティブカラーピッカーの 1 ジェスチャー全体を含め、確定済み設定編集ごとに Undo エントリを 1 つ保持します。その Undo/Redo ボタンとキーボードショートカットは、プロジェクト履歴とは分離し、テーマ設定にだけ作用します。Escape はピッカー操作を取り消します。Revert は、ウィンドウを開いた時点のテーマ設定をすべて復元し、それ自体も Undo できます。Delete は確認を求めます。ウィンドウジオメトリは共有 UI ウィンドウストレージに残り、プロジェクトファイル外です。

## プレビューキャッシュのメモリ

`previewCacheMiB` は、プロジェクトファイル外の localStorage `zoidium.editor-settings` に残ります。既定は 512 MiB のままで、既存の有効値は変更しません。受け入れ範囲は 0 から 16384 MiB です。古いビルドは読み取り時に 2048 MiB 上限を超える値をクランプします。プロジェクトフィールド、レンダリングモード、フレームキー、無効化規則の変更はありません。

ランタイムは、カウント済み RGBA8 バイトで制限し、最大 8192 完成プレビューフレームを保持します。ドライバーオーバーヘッドとその他のレンダーターゲットは別枠です。OUT_OF_MEMORY エラーは、セッション上限を現在の保持使用量の 90 パーセントに下げ、その上限まで追い出します。コンテキストロストは、死んだテクスチャを破棄せず全エントリを忘れ、上限を半減します。ホストレンダラーが正常に復旧すれば、その上限以下でキャッシュを再開できます。2 回目のコンテキストロストは、セッション残り時間のキャプチャを無効にします。1 つの通知が、最初のメモリ失敗またはコンテキストロストを報告します。これらの上限は、プロジェクト変更、キャッシュクリア、設定変更を超えて存続し、ページリロードでのみリセットします。Settings は、現在の描画バッファーサイズでのライブ使用量と、低下済みセッション上限を報告します。大きい方の設定は上限であり、GPU メモリの予約ではありません。十分な空き GPU または共有システムメモリを保証できません。

## Node Effect

Node Effect は、CM3 Custom Shader エフェクト種類 1 としてオーサリングします。`properties.fragShader` 内の実行可能 GLSL がピクセルを所有します。末尾の `// @zoidium-node-effect` 行は、ノード、リンク、位置、パラメーター設定、安定ノード ID を持つコンパクトなバージョン 1 グラフ JSON を含みます。パーサーは編集前にバージョン、構造、値、ポート、サイクル、サイズを検証します。グラフ検証やシェーダーリンクが失敗した場合、既存シェーダーは有効のままです。

公開チャンネルは、キーフレーム、タンジェント、エクスプレッションを含め、ネイティブ `customProperties` のままです。生成 uniform 名はノード ID をエンコードするため、パラメーターラベル変更はアニメーションを保持します。各ネイティブカスタムプロパティ定義内の任意 `zoidiumLabel` フィールドと `zoidiumDefault` フィールドはエディターメタデータです。古いビルドはそれらを無視します。パラメーター種類の変更は、そのチャンネルを新しい既定値で置き換えます。Time は、所有クリップの Time プロパティから評価するネイティブエクスプレッション `time` を持つネイティブ float チャンネルです。

ベア CM3 と Node Effect なしビルドは、グラフを評価せず、保存済みシェーダーとネイティブチャンネルを実行します。生成 uniform 名を表示できます。グラフコメントは、ネイティブシリアライズ、Zoidium アーカイブ保存、エフェクトのコピー/貼り付け、履歴スナップショットを通じて存続します。互換モードも既存エフェクトクラスへの変更も不要です。Node Effect なしのプロジェクトは既存レンダリングを維持します。上限とアルファ処理は [Node Effect](../plugins/node-effect/README.md) を参照してください。

## Magic Looks

Magic Looks は、プロジェクト全体の互換性注釈とは独立に、エフェクトローダーでレンダラーを選択します。新しいエフェクトはトップレベル `looksInstances: {version:1,nextId,order:[{id,tool}]}` を保存します。ID はエフェクト内でローカルであり、並べ替え後も存続します。パラメーターは、有効化、キーフレーム、タンジェント、エクスプレッション、カーブテキスト、インポート済み LUT アセット参照を含め、ネイティブプロパティキー `ml_<id>_<catalog property>` を使います。複製は別の ID を作り、完全なネイティブレコードをコピーします。構造編集、プリセット適用、Clear look はそれぞれ履歴エントリを 1 つ作ります。パラメーター行はネイティブ履歴を使います。

`looksInstances` を持たない保存済みエフェクトは、レガシーレンダラーを維持します。`properties.chainOrder` を持つレコードは、バージョン 15 の単一パスシェーダーとプロパティ更新を不変に保ちます。そのフィールドを持たないレコードは、不透明アルファ、オリジナルソース空間サンプリング、固定ツール順序、履歴グレーディング動作を含め、`f56811c` のオリジナル Davidium 実装を使います。その形式の再保存は `looksLegacyFormat: "davidium"` を追加します。これは後の読み込みで `chainOrder` の存在に優先します。プラグインバージョン推論は使いません。1 つのプロジェクトに 3 形式すべてを含められます。インスタンスへのインプレース変換は提供しません。

`chainOrder` を追加したリリースで再保存済みの Davidium エフェクトは、既にそのリリースのレンダリングに従います。その失われた来歴は推論しません。ネイティブエフェクト種類 `looks` は変更ありません。保存/再開、コピー/貼り付け、履歴は、スキーマとネイティブアニメーションを維持します。古いプラグインはインスタンスメタデータを無視し、未編集の中立レガシープロパティをレンダリングします。そのため新しいチェーンを再現できません。既存の不明フィールド保持は、それらのビルドがプロジェクトを再保存する際に新しいフィールドを維持します。古いプラグインは `looksLegacyFormat` も無視します。復元済み Davidium レンダラーを再現しません。Curve/S Curve 形状は、保持変更付きネイティブテキストスナップショットチャンネルのままです。数値インスタンスチャンネルは補間、エクスプレッション、Graph Editor 2 をサポートします。

`test/magic-looks-instances.test.js` は、識別子、順序、検証、シェーダー分離、パス予算、CPU 順序参照をカバーします。履歴シェーダーハッシュは別途固定します。GPU 互換性証拠は、現行単一パス出力を変更前ソースと比較し、Davidium 出力を `f56811c` と比較します。これには Lens Distortion と空間ツールを含み、シリアライズラウンドトリップ後に繰り返します。ピクセル同一保持はレガシーパスに適用します。新しいインスタンスチェーンは、レイヤーサイズ half-float 中間画像を使います。

Magic Looks バージョン 17 は、インスタンスラベルとセットアップレイアウトだけを変更します。ネイティブキーと完全プロパティレコードは変更ありません。テキスト/アセットストレージチャンネルは、インスタンス形式とレガシー形式の両方でネイティブ一覧から隠します。カーブと LUT エディターは、ネイティブ履歴を通じて同じチャンネルを編集します。この UI 改訂によるプロジェクトマイグレーションもレンダリング変更もありません。

## Sequence Controls

ネイティブシーケンス Properties レコードは、任意の隠しテキストフィールド `properties.zoidiumControls` を 1 つ持ちます。その JSON 値は `{version:1,nextId,controls:[nativePropertyRecord,...]}` です。各レコードは、通常値、キーフレーム、タンジェント、エクスプレッションソースを持つネイティブカスタム動的プロパティです。その種類は `zoidiumControlId` と `zoidiumControlKind` を運びます。Slider min/max/step または Angle 表示変換も加えます。ID はシーケンス内でローカルであり、コントロール並べ替えで変わりません。

ライブ Controls 一覧はシーケンスのネイティブ子であり、履歴とグラフ編集用のネイティブプロパティアドレスを持ちます。隠しテキストプロパティのシリアライザーはその一覧を読み取ります。一覧は 2 つ目のシリアライズ権威ではありません。シーケンス Properties の読み込みや貼り付けは、エディターが値を読む前に一覧を再構築します。空の未編集シーケンスはフィールドを省略します。Sequence Controls は Expressions+ 依存関係に機能 `sequence-controls` を追加します。

現行の不明フィールド保持はシーケンスプロパティを含むため、Expressions+ 無効化は再保存時にペイロードを維持します。保持がレイヤー、クリップ、メディアだけをカバーする旧ビルドは、再保存時にそれを落とす場合があります。元のファイルを残してください。バニラ CM3 はフィールドを無視します。これらのビルドはコントロールリンクを評価できません。生成リンクは、名前変更/並べ替え後も存続するよう `control(name, id)` を使います。手動の名前のみリンクは正確な名前に従います。ID 削除は、生成リンクを失敗させ、置き換えコントロールを選ばず自キー値を使います。

## Expressions+ シェーダー拡張とワールドリンク

ワールド/カメラリンクは、通常エクスプレッションソース文字列だけを追加します。保存済みプロジェクトに新しいトランスフォームフィールド、カメラコピー、フレームキャッシュはありません。

シェーダー include と自動 uniform 宣言は、ネイティブ `properties.fragShader` 文字列に残り、依存関係機能 `shader-extensions` を追加します。展開はコンパイル時にだけ発生します。展開済みライブラリコードとランタイム uniform 値はシリアライズしません。ネイティブカスタムプロパティは変更ありません。古いビルドは GLSL を開いて保持できます。ただし include コメントを展開せず自動 uniform を供給しないため、出力が異なるかコンパイルに失敗する場合があります。これらの拡張を選択しないシェーダーは、元のソースバイト、コンパイラーパス、uniform を維持します。

## Shader+ のプロパティ種類

カスタム定義は、ネイティブプロパティレコードに `zoidiumShader: {kind, ...}` と `zoidiumControl` を維持します。数値/ベクトル種類はネイティブストレージを保ち、Shader+ なしで同一にレンダリングします。メタデータのみの変更は、キー、トゥイーン、エクスプレッション、評価済み小数値を維持します。Checkbox/Dropdown エディターは整数値とホールドキーを作ります。古いキーは書き換えません。静的ドロップダウンはネイティブ静的 OPTION を使い、Shader+ なしでコンパイルします。ゼロは数値文字列 `"0"` として保存し、CM3 の falsy 静的値読み込みパスを回避します。GLSL には `0` として展開します。

Gradient、Curve、Palette、Text は JSON を含む静的ネイティブ TEXT を使います。これらは依存関係 `shader-plus` 機能 `shader-properties` を追加します。数値エディターメタデータだけでは依存関係を追加しません。バニラ CM3 と古い Zoidium は、これらの定義フィールドと JSON を維持して再保存します。プロパティバインドから throw する代わりに、テクスチャ/配列ペイロードへのネイティブシェーダーコンパイルエラーを出します。Shader+ テクスチャや配列は再現できません。古いビルドで編集する際は元のプロジェクトを残してください。Include は未展開シェーダー文字列に残り、レンダリング時に供給プラグインを必要とします。

Text JSON はフォントアセットキーを含みます。Shader+ はプロパティ読み込み中にそのアセットを保持し、エクスポート準備はフォントを待ちます。プリセットフォントパスは、無視されるランタイムキャッシュ内の外部 CM3 リソースのままです。インポート済みフォントはプロジェクトアセットです。テクスチャキャッシュと展開済みシェーダーコードは保存しません。5 エフェクト AlipFX コントロールマッピングは、ビルド時エディターメタデータだけを変更します。保存済みエフェクトは既存の定義とレンダリングを維持します。

## グラデーションとグラフエディターの拡張

ネイティブパーティクル Color/Size グラデーションと Shape+ グラデーション fill/stroke は、元の RGBA ストップ配列形式を維持します。エディターはネイティブフィールドもレンダリングモードも追加せず、開いただけでは値を書き込みません。未編集の小数色文字列は保持します。Shape+ はローカルフレームファサードとホールドキーを維持します。グラデーションエディター選択とユーザープリセットは localStorage に残り、プロジェクトファイル外です。Classic は CM3 オリジナル生成子を呼びます。

Shader+ Gradient JSON は任意でストップごとの `midpoint`、独立 `opacityStops`、`repetitions` を格納します。Curve ポイントは任意で `in`/`out` ベジェハンドル付き 4 要素目を持ちます。定義は任意で `zoidiumShader.editor`（`graph` または `curves`）と `axis` ラベルを運びます。メタデータだけではピクセルは変わりません。新しいグラデーションフィールドやカーブハンドルがなければ、ベイクは浮動小数カーブ値を含め前実装とバイト同一を維持します。既存ポイントは、表示しただけで明示ハンドルに変換しません。

古い Shader+ ビルドはこの TEXT JSON を保存時に維持します。ただし新しいサンプリングフィールドを無視するため、midpoint/opacity/repetitions 付きグラデーションや明示ハンドル付きカーブは異なるレンダリングになる場合があります。グラフスタイルと軸ラベルも無視します。ベア CM3 は引き続き既存テクスチャ種類シェーダーコンパイルエラーを報告します。これらの新規オーサリング機能を古いビルドで開く際は、元のファイルを残してください。

Shape+ のグラデーションファサードは、どちらのエディターにも作業コピーを返すようになりました。Classic ピッカーは `set` 呼び出し前に作業配列を変更します。ホールドキーの配列を直接返すと、新しいローカルフレームキー作成時に直前キーを変更する可能性があり、Undo 後もその変更が残ります。コピーがその漏れを防ぎます。既存の保存済みキーとそのレンダリング出力は、編集するまで変更ありません。新しい編集は意図したローカルフレームスナップショットにだけ影響します。

## 共有カーブ編集とコードウィンドウ

Color Curves と Shader+ は同じ正方形値列カーブウィジェットを使います。Color Curves サンプラー、LUT、シリアライズ値は変更ありません。Shader+ Graph/Curves はこのウィジェットの表示オプションです。どちらのビューを開いても、ハンドルを表示しても、値を書き換えません。シェーダー/エクスプレッションウィンドウジオメトリはローカルエディター状態であり、プロジェクトに入りません。Apply は元のネイティブプロパティアドレスと 1 つの履歴操作を使います。

既存 Shader+ カーブ JSON は、交差した明示ハンドルを含め、正確な前ベイクを維持します。ハンドル編集は、そのポイントの 4 要素目ハンドルオブジェクト内に `inIndependent: true` または `outIndependent: true` を追加します。隣接フラグのどちらかを持つセグメントは、各ハンドルを端点だけで制限します。これにより 2 つのハンドル先端が交差できます。マークのないセグメントは履歴順序ハンドルサンプリングを維持します。明示ハンドル付きポイント移動は、移動したハンドルにもマークを付けます。読み込み、保存、ビュー変更でマイグレーションは発生しません。

新しいマーク付きハンドル編集は、単一チャンネルと RGBA チャンネルで動作します。古い Shader+ ビルドは TEXT JSON を保持します。ただしこれらのフラグを無視して履歴順序複合ハンドルを使い、チャンネル別ハンドルを無視します。新規編集セグメントを異なるレンダリングにする場合があります。古いビルドで編集する際は元のプロジェクトを残してください。

## シェーダーエディターの開発支援

補完、ヘルプ、検索、スクラッチコンパイル、リントヒント、ドラフト Undo/Redo、フォントサイズは、プロジェクトフィールドを追加せず、ソースマイグレーションを行いません。スクラッチ検査は使い捨て GL プログラムと分離パイプライン状態を使い、ライブ uniform、テクスチャ、レンダリング出力に触れず、フォントサイズはローカル UI ストレージのみです。

確定済みテンプレート置換はドラフトだけを編集します。Add properties は 1 つの履歴エントリで通常ネイティブ Shader+ プロパティレコードを作ります。そのソース適用は別のネイティブ履歴エントリです。既存プロパティと値は変更ありません。テンプレートソースは `fragShader` 内で未展開のままです。Gradient、Curve、Text テンプレートは既存 Shader+ 互換規則を維持します。Animated noise は既存 Expressions+ include/time 要件を維持します。古いエディターは、これらすべてのネイティブソース文字列とプロパティレコードを保持できます。
