# デスクトッププロジェクトファイル

Zoidium は CM3 を取り巻く独立した外部の拡張レイヤーです。デスクトップビルドは、生成されたステージから CM3 リソースを Zoidium のコードとともにパッケージします。

インストーラーは `.pz` ファイルを **Zoidium Project** として宣言します。役割は macOS、Windows NSIS、および Linux で **Editor** です。Linux AppImage の関連付けには、AppImage の通常のデスクトップ統合が必要です。署名設定は追加しません。

アプリケーションは、最初のコマンドライン、2 回目の起動、および macOS の `open-file` イベントからプロジェクトファイルを受け付けます。エディターウィンドウを復元してフォーカスします。小文字/大文字を区別しない `.pz` 拡張子を持つ、空でない通常ファイルへの絶対パスのみを受け付けます。2 GiB マイナス 1 バイトより大きなアーカイブは無視し、転送入力を符号付き 32 ビットアドレス範囲内に保ちます。共有プロジェクト検証器は、展開済みアーカイブを 2 GB に制限します。より大きな入力はエラーを報告し、現在のプロジェクトを保持します。
無効なパスと無関係なコマンドラインフラグは無視されます。

起動中に受信したファイルは、CM3 初期化と Zoidium のプロジェクトローダー完了まで待機します。複数の要求は順番に開き、各インポートの完了を待ちます。ローダーは、ツールバーと同じ `editor.open()` パスを使用します。未保存変更の確認、アーカイブ検証、プラグイン有効化、アセット読み込み、プロジェクト名、およびエラーを含みます。置換前に検証済み復元ポイントを作成します。検証、バックアップ、または読み込みの失敗は、現在のプロジェクトを保持します。[保存と復元ポイント](project-saving.md)を参照してください。確認を取り消すと、現在のプロジェクトが残り、その開く要求を消費します。

サンドボックス化された preload は、ファイル通知と固定の ready/completed IPC チャンネルのみを公開します。メインプロセスは、ローカルのメインエディターフレームからのメッセージのみを受け付けます。ファイル通知は、ファイルシステムパスではなく、basename と一時的なランダム URL を含みます。ループバックサーバーは、現在キューにあるプロジェクトのみをストリーミングします。その URL は、レンダラーがインポートを完了または取り消した場合、またはレンダラーが移動またはクラッシュした場合に失効します。プロジェクトファイルがアップロードされることはありません。`nodeIntegration` は無効のまま、`contextIsolation` は有効のままです。

開発中にコマンドラインオープンをテストするには、投入済みリソースキャッシュを使用します:

```bash
node tools/start-electron.js /absolute/path/to/project.pz
```

開始スクリプトはユーザー引数を Electron に転送します。2 回目の呼び出しは、その引数を既存アプリケーションに送信します。各開発呼び出しは、現在のチェックアウトの拡張ファイルをステージングし、終了時に一時ステージを削除します。
